### 📌 AIをほとんどの人より先に進める唯一のセットアップ

誰もが私に「AIをもっと良くする方法」を尋ねる。その秘訣は、コンピュータ上にファイルシステムをセットアップすることだ。これはAIを使う大半の人より先に進むためにできる唯一のことだと思うが、このニュースレターできちんと説明したことがなかったことに気づいた。だから全員にセットアップしてもらいたい。

ChatGPTやClaudeが、すでに伝えたことを忘れることがあるだろう。組み込みのメモリが重要な部分を保持してくれると期待するが、記憶するものを選ぶのはAI側であり、必要なものが常に含まれるとは限らない。その結果、自分が誰で、どう働き、何を意図したかをまた説明することになる。

これは、それらの詳細情報をより良い場所に保存する仕組みだ。**コンピュータ上のファイルに保存された第二の脳**を構築し、AIが読んで更新できるノートを用意する。AIが覚えていたものに頼る代わりに、実際の好み、プロジェクトノート、過去の作業を指し示すことができる。

「ファイルシステム」がすでに混乱して聞こえても心配ない。完全なガイドと、手順を案内してファイルを構築してくれる「すぐ使えるセットアッププロンプト」を用意した。以下が、セットアップする内容とそれが重要な理由だ。

このセットアップはコンピュータ上のデスクトップアプリ用だ。スマートフォンでしかChatGPTやClaudeを使わない場合は、今は飛ばして構わない。しかしAIをさらに一歩進める準備ができているなら、これは私がまとめた中で最も重要なリソースかもしれない。始めるには2つのアプリのうち1つがあれば良い。

私がChatGPT WorkやClaude Coworkを試すよう勧める時、これが大きな理由の一部だ。これらのツールはコンピュータ上のフォルダ内で作業できる。AIに1つのフォルダへのアクセスを与えると、ファイルを読み、新しいファイルを作成し、完成した作業をそこに保存できる。あなたが承認しない限り、アクセスはそのフォルダに限定される。

私のものは「Maverick OS」と呼ばれている。あなたのものは、あなたの名前に続けて「OS」とすれば良い。それは自分についてのノート、作業中のもののための小さなフォルダ、そして結果を保存する場所を含む単なるフォルダだ。以下があなたのファイルの例だ：

**📁 Your Name OS**

- 📄 START-HERE.md（AIが開始すべき場所）
- 📄 AGENTS.md（AIがどう働くべきか）
- 📄 CURRENT.md（今作業中のこと）
- 📄 memory.md（システム全体で役立つ変更）
- 📁 resources
  - 📄 about-me.md
  - 📄 writing-style.md
- 📁 workspaces
  - 📁 work
  - 📁 travel（AGENTS.md、CURRENT.md、memory.md、resources、outputsを含む）
  - 📁 personal-admin

各ワークスペースは同じサポートファイルを持つ。ガイドではワークスペース指示をguide.mdと呼び、AGENTS.mdと同じ役割を果たす。

それらの.mdファイルは**単なるテキストファイル**だ。PDFを印刷されたページと考えれば、.mdファイルはその背後にある編集可能なノートだ。AIはPDFを読めるが、スキャンや複雑なレイアウトは余分な作業を追加する可能性がある。プレーンテキストは読みやすく更新しやすい。

例えば、ChatGPTに「11月に日本に行く予定。直行便が好ましい。予約前に確認して」と伝えたとする。あなたの旅行ファイルは次のようになる：

**AGENTS.md · 指示**
直行便を優先。何かを予約する前に尋ねる。

**memory.md · 記憶すべきこと**
9月23日：11月の日本旅行を計画中。まだ何も予約していない。

AGENTS.mdをアシスタントの職務記述書、memory.mdを彼らのノートと考えよう。セットアッププロンプトはこれらのファイルを作成し、すべてのタスク後に役立つ更新を保存するよう指示する。次回、関連するノートを最初に読む。そのメモリを自分で開いて修正することもできる。

セットアッププロンプトを貼り付け、音声ノートで質問に答える。エクスポートガイドを使って古いチャットを提供することもできるし、それなしで始めることもできる。

**ChatGPTの場合：**デスクトップアプリを開き、Workを選択し、プロジェクトまたはフォルダ選択ツールを使ってOSフォルダを接続する。今後の作業には同じローカルプロジェクトに戻る。セットアップチャットをRecentsにピン留めして再度見つけられる。

**Claudeの場合：**デスクトップアプリを開き、ProjectまたはFolder（下記参照）、または新しいインターフェースの「Work in a folder」を選択し、既存のOSフォルダを選ぶ。アプリにまだCoworkタブがある場合はそこから始める。3点メニューからプロジェクトをスターする。私は自分のもので確認した：スターしたプロジェクトはClaudeを開いた時に自動的に読み込まれるので、OSフォルダがすぐに使える。

別の場所で開く場合は、サイドバーでスターしたプロジェクトを選択する。いずれにせよ、開始前にOSフォルダが接続されているか確認する。

これを適切に行うには2時間ほど確保すること。大きな履歴インポートには時間がかかる可能性があり、一時停止して再開できる。次の6か月間、自分を繰り返すのを止めるために、その時間を費やす価値があると思う。

**プロのヒント：**セットアップには、ClaudeでOpus 5.5、またはChatGPT WorkでGPT-6 Astraを選ぶ。thinkingをExtra Highに設定するか、アプリが提供する最高のthinkingオプションを選ぶ。この最初のパスには、プランで利用可能な最強のモデルと思考設定を与える。

### 📌 Claudeが復活を遂げた

数週間前、Astraがトップだとあなたに伝え、Anthropicが何かを持って戻ってこないと驚くと言った。さて、それが来た。**Claude Opus 5.5が昨日ローンチ**され、私が興味を持っているのは試験で何点取ったかではない。実際にまた一緒に作業するのを楽しめるかどうかだ。

まず注目すべきは文章だ。Anthropicは、より早く要点に到達し、専門用語を減らし、あなたの文章ルールをより良く守ると述べている。賢い回答も、それを人間らしく聞こえるようにするために次の10分を費やすなら、あまり役に立たない。3回の「そのような書き方はやめて」なしに有用な下書きを得ることは、私が気にする種類の改善だ。

また、1つ以上の回答を必要とする仕事により適しているようだ。Lovableの初期テストでは、より少ない編集回数でアプリビルドを完了でき、Anthropicは調査のためにソースを掘り下げることが改善されたと述べている。だから、Claudeを使って自分の声で何かを書いたり、アプリを構築したり、大量の情報を処理したりする場合、それらが最初に試すべきことだ。

現在、**ProプランとMaxプラン、Teamプランでデフォルト**となっており、Coworkも含まれる。また、使用制限を増やし、必要な時のために保存できるリセットを加入者に提供している。これは、モデルがどれだけ賢いかを示す別のチャートよりもはるかに有用だ。

これらの企業が互いに強制的に改善し続けることが好きだ。私がしないことは、彼らの一方がラウンドに勝つたびに全体のセットアップを再構築することだ。最初のセクションのAI brainに、あなたの作業、好み、指示を入れ、そして仕事を最もうまくこなすものを使う。彼らにモデルをめぐって戦わせよう。あなたはメモリを保持する。

### 📌 保存する価値のある3つの画像コード

数週間前、billboard、time-machine、magazine-coverコードを紹介した。以下は写真を使う全く異なる方法を提供する3つだ。前回と同じアイデア：ChatGPTで画像を添付し、コードとその下の行を貼り付け、新しいバージョンを作らせる。

下の行が実際の指示なので、その部分もコピーする。特に販売しているものを使う場合は、被写体が適切に見える明確な写真から始める。

**/360-view**

```
/360-view この製品を6つの異なる角度から見せる1つの画像を作成。360度ターンテーブルのフレームのように。製品は清潔な白い背景で一貫性を保つ。
```

製品、靴のペア、または机の上の何かをアップロードし、通常なら歩き回って撮影する必要がある角度を要求する。これは静止コンタクトシートを提供するので、角度を並べて比較できる。写真に映っていない部分を想像する必要があるので、実際のリストで使用する前にそれらの詳細を確認する。

**/impossible-angle**

```
/impossible-angle この写真を不可能なカメラアングルから再作成。小さなカメラがシーン内に収まるかのように。被写体を認識可能に保ち、本物の写真のように見せる。
```

これはカメラを通常は絶対に到達できない場所に置く。靴紐の下からのスニーカーショット、または内側から外を見るコーヒーカップを試してみよう。被写体は馴染みのあるままだが、視点は完全に異なる。最初のものが十分に奇妙でない場合は、小さなカメラがどこにあるべきか正確に伝える。

**/meta-ads**

```
/meta-ads この製品写真を洗練された正方形のソーシャル広告に変換。製品を認識可能に保ち、短い見出しと明確な行動喚起を追加。価格、割引、レビュー、製品主張を捏造しない。
```

これは何か売るものがある場合に便利だ。キャンドル、スキンケアボトル、または自分の製品写真を与え、その周りに広告を構築させる。製品が実際に何をし、誰のためのものかを追加し、いくつかの異なる見出しを求める。広告キャンペーンに投入する前に、最終的なクリエイティブを選択して確認するのはあなただ。

私は200の画像と動画のショートカットすべてを完全な画像コードリソースに入れた。写真があって何をすればいいかわからない次の時のために保存しておこう。
