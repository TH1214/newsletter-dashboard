### 📌 ChatGPT用5つの秘密旅行コード

私は常にフルタイムで旅行しているため、空港、新しい街、メニューが読めないレストランに絶えず遭遇している。以下の5つのコードがそのすべてをカバーする。各コードは自分の詳細を入力する短いコマンドで、ChatGPTが残りを処理してくれる。次の旅行の前や最中に試してみれば、どれほど素晴らしいかわかるだろう。

**1. /layover**

```
/layover AA 1234, 5 hours in Dallas
```

ChatGPTが乗り継ぎ時間のミニ旅程を作成し、空港に戻るべき正確な時刻も含めてくれる。6時間もゲートで座っている必要はもうない。

**2. /hidden-gems**

```
/hidden-gems Lisbon
```

観光客向けの罠をスキップし、地元の人が実際に行く場所を教えてくれる。レストラン、景色、トップ10リストには決して載らない地域。

**3. /packing**

```
/packing Tokyo, December 10 to 17
```

訪問先の実際の天気予報に基づいて、完全な荷造りリストを作成してくれる。70度（約21℃）になる都市に冬用コートを詰める心配はない。

**4. /translate-menu**

```
/translate-menu [メニューの写真を添付]
```

どんな言語のメニューでも写真を撮れば、ChatGPTがすべての料理が実際に何であるか、何を注文する価値があるかを教えてくれる。

**5. /seat-hack**

```
/seat-hack Delta 412, JFK to LAX, December 20
```

正確な便で最良の空席と、実際にそれを取得するためのチェックインタイミングを教えてくれる。

これらは文字通り人生を変える。そして正直なところ、これは始まりに過ぎない。旅行中にChatGPTを使う方法は他にも無数にある：フライト時間に合わせて1日全体を計画させたり、チップのルールと実際に必要な5つのフレーズを教えてもらったり、予約前にパスポートの入国ルールを確認したり、空港からホテルまでの最安ルートを見つけてもらったりできる。ChatGPTをポケットの中の旅行アシスタントとして扱い始めれば、二度と古い方法で旅行を計画することはなくなる。

1つのヒント：フライト時刻、座席表、天気予報など変化するものについては、ChatGPTがウェブをライブ検索するため、重要なこと（フライトの搭乗開始時刻など）は航空会社のアプリで再確認すること。

### 📌 Microsoft Copilotで独自AIエージェントを構築

独自のAIエージェントを構築するのがこれまでになく簡単になり、Microsoft Copilot（マイクロソフト・コパイロット）がAgent Builder（エージェント・ビルダー）でゲームチェンジャーとなっている。最初のエージェントを構築するのは、思ったほど難しくない。ゼロから始める必要もなく、コーディングの知識も不要だ。以下は試してみる簡単な方法だ。

チームが何度も繰り返すことを1つ選ぶ。みんながあなたに聞く質問や、新入社員全員に説明するプロセスなど。それがあなたの最初のエージェントだ。

**ステップ1：** Microsoft Copilotアプリを開く（またはcopilot.cloud.microsoftにアクセス）し、職場アカウントでサインインする。左サイドバーの「Agents & Skills」をクリックし、「New agent」を選択。

**ステップ2：** 「Message Agent Builder」ボックスで、次のように何をすべきか説明する：「新入社員からの有給休暇ポリシー、経費、誰に何を聞くべきかについての質問に答える」。Copilotがあなたのために指示を書いてくれる。

**ステップ3：** +をクリックして、エージェントが知るべき情報（従業員ハンドブックやSharePointフォルダなど）を追加。

**ステップ4：** 「Try it」でテストし、「Create」をクリック。

**ステップ5：** 「Share」をクリックし、使用できる人を選び、チームと共有。

チームメイトがそれを使用するとき、すでにアクセス権のあるコンテンツからの回答のみを取得する。エージェントを共有しただけで、誰もあなたのファイルにアクセスできるようにはならない。

エージェントをさらに進めたい場合は？ Agent Builderは素早く軽量なエージェントに最適。より高度な機能については、エージェントをMicrosoft Copilot Studio（マイクロソフト・コパイロット・スタジオ）にコピーすれば、メール送信やスプレッドシート更新などのアクションを実行するためのツールを追加できる。また、Microsoft Teamsやチームがすでに毎日使っている他の場所に公開することもできる。

目に見える反復的なタスク、二度とやりたくないタスクを1つ選ぶ。今週それ用のエージェントを構築し、共有して、チームに時間を返そう。

### 📌 ChatGPTは会話が長くなると39%性能が悪化する

1つのチャットでChatGPTと長く話せば話すほど、回答は悪くなる。

MicrosoftとSalesforce（セールスフォース）の研究者が、ChatGPTやClaude（クロード）を含む主要AIモデル15種を、20万件以上の会話でテストした。AIに必要な情報をすべて最初から与えると、素晴らしい成果を上げた。しかし、同じ情報を長いやり取りの中で少しずつ与えると、平均でパフォーマンスが39%低下した。

知らない人のために説明すると、これは「コンテキストウィンドウ」と呼ばれるものに起因する。基本的にAIの短期記憶だ。メッセージを送るたびに、AIは新しいメッセージだけを読むのではない。毎回、チャット全体を一番上から再読し、それから答える。

ホワイトボードのようなものだと考えてほしい。送信したすべてのメッセージがそこに書かれ、回答する前にAIはボード全体を読む。チャットの開始時、ボードはきれいで読みやすい。1時間後には覆われている。あなたが捨てた古いアイデアがまだそこにあり、3番目のメッセージからの間違った推測が隅にまだ座っていて、ボードが満杯になると、最も古いものから消され始めてスペースを作る。

研究者が見たのはまさにそれだ。AIが早期に1つの間違った方向に進むと、迷子になって回復しない。なぜなら、その間違った方向転換がまだボードにあり、その後のすべての回答を導いているからだ。

AIを使い始める多くの人がこれをやっており、あなたもまだそうかもしれない。すべてが起こる1つのチャットがあり、すでにすべてを知っているように感じるので、そこに戻り続ける。しかし約束するが、これが回答が悪化し続ける理由だ。

修正する方法は2つある。

**1. 新しいチャットに要約する。** チャットが長くなり始めたら、これを貼り付ける：

```
この会話から重要なことすべてを、新しいチャットに貼り付けられる1つのプロンプトに要約してください。私たちが下したすべての決定と、あなたが必要とするすべての詳細を含めてください。
```

そして真新しいチャットを開いて貼り付ける。重要なことをすべて知っている新鮮なChatGPTと話しているようなものだ。

**2. スキルとして保存する。** Claudeを使っている場合、またはもう少し高度にしたい場合、これはより良い手だ。特にそのチャットで何度も繰り返すこと（週次メールの執筆やコンテンツ計画など）がある場合。こう言うだけ：

```
このチャットで私たちが見つけたすべてを、再利用できるスキルに変えてください。ステップ、私の好み、私が好きなフォーマットを含めて。
```

Claudeがスキルを構築するので、Claudeの「Customize」→「Skills」で保存する。新しいチャットを開始するときはいつでも、/を入力してスキルを選ぶだけで、学んだすべてを持ってきれいなホワイトボードで戻ってくる。（設定→機能で「Code execution and file creation」をオンにする必要がある。）

ChatGPTにも一部のプラン（主にBusiness、Enterprise、Edu）でスキルがある。「このチャットからスキルを構築して」と頼み、「Install」をクリックし、新しいチャットでスキル名を@する。

### 📌 AIが1,800ドルの車修理を0ドルに変えた

これは私が大好きなAIストーリーの種類だ。

ウェストバージニア州のある男性が、エンジンチェックランプが点灯した後、トヨタをディーラーに持ち込んだ。彼らは新しい排気部品が必要だと言い、見積もりは1,800ドルだった。最悪の部分：彼の車は保証期間をわずか約3,000マイル過ぎたばかりだった。惜しい。

単に支払う代わりに、彼はChatGPTに尋ねた。ChatGPTは価格が少し高いように見えると言い、その後、ほとんどの人が聞いたことのないことを教えた：トヨタに「goodwill（善意）」の支援を求めよ、と。基本的に、保証期間が切れた直後に部品が故障した場合、自動車メーカーは顧客を満足させるために修理を無料でカバーすることがある。尋ねるだけでいい。

そこで彼はトヨタに連絡し、彼のReddit投稿によると、最終的に何も支払わなかった。1,800ドルが0ドルに。

私はこのようなストーリーが大好きだ。なぜなら、AIを使えるさまざまな方法や、AIとの話し方について本当に考えさせられるからだ。彼は、自分一人では不安が彼を押して見積もりを支払わせただろうとさえ言った。多くの人がそうで、これはまさにAIが得意とすることだ。

そしてこれは車以上に機能する。電話、ラップトップ、冷蔵庫、保証期間終了直後に壊れるあらゆるもの。だから次回大きな修理見積もりを受け取ったら、支払う前にこれを貼り付けよう：

```
私の[車/電話/家電]、[メーカー、モデル、年式]で[走行距離または年数]、[修理内容]が必要で、[価格]の見積もりを受けました。これは公正な価格ですか？ これをカバーできる保証、リコール、延長保証、またはgoodwillプログラムはありますか？ その後、メーカーに送信する正確なメールを書いてください。
```

goodwillは会社次第で保証ではないことを知っておこう。だから毎回うまくいくわけではない。しかし尋ねるのに5分かかり、最悪の場合は「ノー」と言われるだけだ。

高すぎると感じる請求書がある場合、ChatGPTでそれに対抗するための無料ガイドがあり、すべてのプロンプトが含まれている。

次の旅行のために旅行コードを保存し、次回チャットが長くなり始めたらリセットしよう。そして今カウンターに修理見積もりがあるなら、支払う前にそのプロンプトを実行しよう。お金を節約できたら、返信していくら節約できたか教えてほしい。
