### 🧠 実践ノウハウ
#### ChatGPTのための5つの秘密旅行コード

フルタイムで旅をする筆者が常用する、ChatGPT用の5つの旅行コードを紹介する。それぞれ短いコードと詳細を入力するだけで、ChatGPTが残りを処理してくれる。次の旅行前や旅行中に試せば、その威力が分かるはずだ。

**1. /layover**

```
/layover AA 1234, 5 hours in Dallas
```

ChatGPTが乗り継ぎ時間のミニ旅程を作成し、空港に戻るべき正確な時刻も教えてくれる。もう6時間もゲートで座り続ける必要はない。

**2. /hidden-gems**

```
/hidden-gems Lisbon
```

観光客の罠をスキップし、地元民が実際に行く場所を教えてくれる。レストラン、景色、トップ10リストには決して載らない地域など。

**3. /packing**

```
/packing Tokyo, December 10 to 17
```

目的地の実際の天気予報に基づいて、完全なパッキングリストを作成してくれる。気温が70度（華氏、約21度）になる都市に冬用コートを詰め込むこともなくなる。

**4. /translate-menu**

```
/translate-menu [メニューの写真を添付]
```

どんな言語のメニューでも写真を撮れば、ChatGPTが各料理が実際に何かを教え、注文する価値があるものも提案してくれる。

**5. /seat-hack**

```
/seat-hack Delta 412, JFK to LAX, December 20
```

その便の最良の空席と、実際にその席を確保するためのチェックイン時刻を教えてくれる。

これらは文字通り人生を変えるレベルだ。正直なところ、これはほんの始まりに過ぎない。旅行でChatGPTを使う方法は他にも無数にある：フライト時間に合わせて1日全体を計画させたり、チップのルールと実際に必要な5つのフレーズを教えてもらったり、予約前にパスポートの入国規則を確認したり、空港からホテルまでの最安ルートを見つけたり。ChatGPTをポケットの中の旅行アシスタントとして扱い始めれば、二度と昔のやり方で旅行を計画することはなくなる。

ヒント：フライト時刻、座席マップ、天気予報など変化するものについては、ChatGPTがリアルタイムでウェブ検索するため、重要な情報（搭乗時刻など）は航空会社のアプリで再確認すること。

### 📢 スポンサー：Microsoft
#### Microsoft Copilotで独自のAIエージェントを構築する

自分専用のAIエージェントを構築することがかつてないほど簡単になり、Microsoft Copilot（マイクロソフト・コパイロット）のAgent Builder（エージェント・ビルダー）がゲームチェンジャーとなっている。最初のエージェント構築は、聞こえるほど難しくはない。ゼロから始める必要も、コーディング方法を知っている必要もない。試すための簡単な方法がある。

チームが何度も繰り返すこと、例えば誰もがあなたに尋ねる質問や、新入社員全員に説明するプロセスから始めよう。それが最初のエージェントだ。

**ステップ1:** Microsoft Copilotアプリを開く（またはcopilot.cloud.microsoftにアクセス）し、職場アカウントでサインインする。左サイドバーの「Agents & Skills」をクリックし、「New agent」を選択する。

**ステップ2:** 「Message Agent Builder」ボックスに、エージェントが何をすべきか記述する。例：「新入社員の休暇方針、経費、誰に何を尋ねるべきかについての質問に答える」。Copilotが指示を書いてくれる。

**ステップ3:** +をクリックして、エージェントが知るべき情報（従業員ハンドブックやSharePointフォルダなど）を追加する。

**ステップ4:** 「Try it」でテストし、「Create」をクリックする。

**ステップ5:** 「Share」をクリックし、使用できる人を選択し、チームと共有する。

そして、チームメイトがそれを使用する際、彼らはすでにアクセス権のあるコンテンツからのみ回答を得る。エージェントを共有したからといって、誰かがあなたのファイルにアクセスできるようになるわけではない。

エージェントをさらに発展させたい場合は、Agent Builderは素早く軽量なエージェントに最適だ。より高度な機能のためには、エージェントをMicrosoft Copilot Studio（マイクロソフト・コパイロット・スタジオ）にコピーし、メール送信やスプレッドシート更新などのアクションを実行するツールを追加できる。また、Microsoft Teamsやチームが毎日使っている他の場所に公開することもできる。

目に見える反復的なタスク、二度とやりたくないものを1つ選ぼう。今週それ用のエージェントを構築し、共有して、チームに時間を返そう。

### 🚨 衝撃の事実
#### ChatGPTは会話が長引くほど39%性能が低下する

ChatGPTと1つのチャットで長く会話するほど、回答の質が悪くなる。

MicrosoftとSalesforceの研究者が、ChatGPTやClaude（クロード）を含む主要AIモデル15種を、20万件以上の会話でテスト した。AIに必要な情報を全て最初に与えた場合は優れた性能を示したが、同じ情報が長い会話の中で少しずつ与えられた場合、性能は平均で39%低下した。

知らない人のために説明すると、これは「コンテキストウィンドウ」と呼ばれるものに関係している。基本的にAIの短期記憶だ。メッセージを送るたびに、AIは新しいメッセージだけを読むのではない。毎回、チャット全体を最初から読み直してから回答する。

ホワイトボードを思い浮かべてほしい。送信した全てのメッセージがそこに書かれ、回答の前にAIは毎回ボード全体を読む。チャットの最初は、ボードはきれいで読みやすい。1時間後には、びっしり埋まっている。捨てた古いアイデアもまだそこにあり、3番目のメッセージでの間違った推測も隅に残っていて、ボードがいっぱいになると、最も古い情報が消去されて新しい情報のためのスペースが作られる。

研究者が見たのはまさにそれだった。AIが早い段階で1つの間違った方向に進むと、迷ったまま回復しない。なぜなら、その間違った方向がまだボード上にあり、その後の全ての回答を導いているからだ。

AIを使い始めた多くの人がこれをやっており、あなたもまだそうかもしれない。全てが起こる1つのチャットがあり、既に全てを知っているような気がして使い続ける。しかし、これが回答が悪化し続ける理由だと断言する。

**2つの修正方法がある。**

**1. 新しいチャットに要約する。** チャットが長くなり始めたら、これを貼り付ける：

```
この会話から重要なことを全て、新しいチャットに貼り付けられる1つのプロンプトにまとめてください。私たちが下した全ての決定と、あなたが必要とする全ての詳細を含めてください。
```

次に、真新しいチャットを開いてそれを貼り付ける。重要なことを全て知っている新鮮なChatGPTと話すようなものだ。

**2. スキルとして保存する。** Claudeを使っている場合、またはもう少し高度なことをしたい場合、これがより良い方法だ。特に、週次メールの作成やコンテンツ計画など、そのチャットで何度も行うことがある場合。ただ言えばいい：

```
このチャットで理解した全てを、再利用できるスキルに変換してください。ステップ、私の好み、好きなフォーマットを含めてください。
```

Claudeがスキルを構築するので、Claude内の「Customize → Skills」で保存する。新しいチャットを始めるときはいつでも、/を入力してスキルを選ぶだけで、学習した全てを持って、きれいなホワイトボードで戻ってくる。（Settings → Capabilitiesで「Code execution and file creation」をオンにする必要がある。）

ChatGPTにも一部のプラン（主にBusiness、Enterprise、Edu）でスキルがある。「このチャットからスキルを構築して」と頼み、「Install」をクリックし、新しいチャットでスキル名を@で呼び出す。

### 💰 保存推奨
#### AIが1,800ドルの車修理代を0ドルに変えた

これは筆者が大好きなタイプのAI事例だ。

ウェストバージニア州のある男性が、エンジンチェックランプが点灯したためトヨタをディーラーに持ち込んだ。排気部品の交換が必要で、見積もりは1,800ドルだと言われた。最悪なのは、車が保証期間をわずか3,000マイル超過したばかりだったこと。惜しかった。

そのまま支払う代わりに、彼はChatGPTに尋ねた。ChatGPTは価格が少し高いようだと伝え、さらにほとんどの人が聞いたことのないことを教えた：トヨタに「goodwill（善意）」サポートを求めることだ。基本的に、保証期間終了直後に部品が故障した場合、自動車メーカーは顧客を満足させるために修理を負担することがある。尋ねさえすればいいのだ。

そこで彼はトヨタに連絡し、Redditの投稿によると、最終的に支払額はゼロになった。1,800ドルが0ドルに。

このような事例が大好きなのは、AIを使える様々な方法と、話しかけ方について本当に考えさせられるからだ。彼は、自分だけなら不安から見積もりをそのまま支払ったであろうとさえ述べている。多くの人がそうで、これはまさにAIが得意とすることだ。

そして、これは車だけでなく、もっと広く機能する。スマートフォン、ノートパソコン、冷蔵庫、保証期間終了直後に壊れるものなら何でも。次に大きな修理見積もりを受け取ったら、支払う前にこれを貼り付けよう：

```
私の[車/スマートフォン/家電]、[メーカー、モデル、年式]で[走行距離または使用年数]のものが[修理内容]を必要としており、[価格]と見積もられました。これは適正価格ですか？この修理をカバーできる保証、リコール、延長保証、または善意プログラムはありますか？次に、メーカーに送る正確なメールを書いてください。
```

ただし、善意サポートは会社次第であり、保証ではないため、毎回うまくいくわけではない。しかし、尋ねるのに5分しかかからず、最悪の場合は「ノー」と言われるだけだ。

高すぎると感じる請求書がある場合、筆者はChatGPTを使ってそれと戦う無料ガイド（全プロンプト付き）を用意している。
