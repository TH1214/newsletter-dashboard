### 📌 ChatGPT向け5つの旅行用秘密コード

筆者はフルタイムで旅行しているため、常に空港、新しい都市、メニューが読めないレストランにいる。以下の5つのコードがすべてをカバーする。各コードは自分の詳細を入力する短いコマンドで、ChatGPTが残りを処理してくれる。

**1. /layover（乗継）**

```
/layover AA 1234, 5 hours in Dallas
```

ChatGPTが乗継時間のミニ旅程を作成し、空港に戻る必要がある正確な時刻も教えてくれる。6時間ゲートに座り続ける心配がなくなる。

**2. /hidden-gems（穴場スポット）**

```
/hidden-gems Lisbon
```

観光地を飛ばして、地元の人が実際に行く場所を教えてくれる。レストラン、景色、トップ10リストに決して載らない地域など。

**3. /packing（荷造り）**

```
/packing Tokyo, December 10 to 17
```

行き先の実際の天気予報に基づいて、完全な荷造りリストを作成してくれる。70度の都市に冬用コートを詰め込む心配がない。

**4. /translate-menu（メニュー翻訳）**

```
/translate-menu [メニューの写真を添付]
```

どんな言語のメニューでも写真を撮れば、ChatGPTがすべての料理が何かを教え、何を注文すべきか教えてくれる。

**5. /seat-hack（座席ハック）**

```
/seat-hack Delta 412, JFK to LAX, December 20
```

その飛行機で空いている最良の座席と、実際にそれを取得するためにいつチェックインすべきかを教えてくれる。

これらは文字通り人生を変えるレベルだ。正直、これは始まりに過ぎない。旅行でChatGPTを使う方法は他にも多数ある。フライト時間に合わせて1日全体を計画させたり、チップのルールと実際に必要な5つのフレーズを教えてもらったり、予約前にパスポートの入国ルールを確認したり、空港からホテルまでの最安ルートを見つけてもらったりできる。ChatGPTをポケットの中の旅行アシスタントとして扱い始めると、二度と昔の方法で旅行を計画しなくなる。

**1つのヒント**: フライト時刻、座席マップ、天気予報など変化するものについては、ChatGPTがリアルタイムでウェブを検索するため、重要なこと（フライトの搭乗時刻など）は航空会社のアプリと照合すること。

### 📌 Microsoft Copilotで独自のAIエージェントを構築

Microsoft Copilot（マイクロソフト・コパイロット）のAgent Builderにより、独自のAIエージェントを構築することがかつてないほど簡単になった。最初のエージェントを構築することは、聞こえるほど威圧的ではない。ゼロから始める必要も、コーディング方法を知る必要もない。試す簡単な方法は以下の通り。

チームが何度も繰り返すこと、例えば誰もがあなたに尋ねる質問や、すべての新入社員に説明するプロセスから始める。それが最初のエージェントになる。

**ステップ1**: Microsoft Copilotアプリを開く（またはcopilot.cloud.microsoftにアクセス）し、仕事用アカウントでサインインする。左サイドバーの「Agents & Skills」をクリックし、「New agent」を選択。

**ステップ2**: 「Message Agent Builder」ボックスに、実行すべき内容を記述する。例：「新入社員の有給休暇ポリシー、経費、誰に何を尋ねるかについての質問に答える」。Copilotが指示を書いてくれる。

**ステップ3**: 「+」をクリックして、エージェントが知るべき内容（従業員ハンドブックやSharePointフォルダなど）を追加する。

**ステップ4**: 「Try it」でテストし、「Create」をクリックする。

**ステップ5**: 「Share」をクリックし、使用できる人を選択してチームと共有する。

チームメイトがエージェントを使用すると、すでにアクセス権を持つコンテンツからのみ回答を得られる。エージェントを共有したからといって、誰もあなたのファイルへのアクセス権を得ることはない。

**さらに進みたい場合**: Agent Builderは、迅速で軽量なエージェントに最適。より高度な機能を求める場合は、エージェントをMicrosoft Copilot Studioにコピーし、メール送信やスプレッドシート更新などのアクションを実行するツールを追加できる。Microsoft Teamsや、チームが毎日すでに作業している他の場所に公開することも可能。

目に見える繰り返しのタスク、二度とやりたくないタスクを1つ選ぶ。今週それ用のエージェントを構築し、共有して、チームに時間を返してあげよう。

### 📌 ChatGPTは会話が長引くと39%精度が低下する

ChatGPTと1つのチャットで長く話せば話すほど、回答の質が低下する。

MicrosoftとSalesforceの研究者が、ChatGPTやClaudeを含む15の主要AIモデルを、20万件以上の会話にわたってテストした。AIに必要な情報をすべて最初に与えた場合、優れた性能を示した。しかし、同じ情報が長いやり取りの中で少しずつ提供された場合、平均で性能が39%低下した。

これは「コンテキストウィンドウ」と呼ばれるものに起因する。基本的にAIの短期記憶だ。メッセージを送信するたびに、AIは新しいメッセージだけを読むのではない。毎回、チャット全体を最初から読み直し、その後回答する。

ホワイトボードのようなものだと考えてほしい。送信するすべてのメッセージがそこに書かれ、回答する前にAIは毎回ボード全体を読む。チャットの開始時、ボードはきれいで読みやすい。1時間後、ボードは埋まっている。捨てた古いアイデアがまだそこにあり、3番目のメッセージからの間違った推測がまだ隅に残っており、ボードが満杯になると、最も古いものがスペースを作るために消去され始める。

これがまさに研究者が観察したことだ。AIが早い段階で1つ間違った道を取ると、迷子になり回復しない。その間違った道がまだボード上にあり、その後のすべての回答を導いているからだ。

AIを使い始める多くの人がこれをやっており、あなたもそうかもしれない。すべてが起こる1つのチャットがあり、すでにすべてを知っているように感じるので使い続ける。しかし、これが回答が悪化し続ける理由だと約束する。

**これを修正する2つの方法**:

**1. 新しいチャットに要約する**

チャットが長くなり始めたら、以下を貼り付ける：

```
この会話から重要なすべてを、新しいチャットに貼り付けられる1つのプロンプトにまとめて。下した決定と必要なすべての詳細を含めて。
```

その後、新しいチャットを開いて貼り付ける。重要なことをすべて知っている新鮮なChatGPTと話しているようなものだ。

**2. スキルとして保存する**

Claudeを使っている場合、または少し高度にしたい場合、これがより良い方法だ。特にそのチャットで繰り返し行うこと（週次メールの作成やコンテンツ計画など）に対して。こう言えばいい：

```
このチャットで理解したすべてを、再利用できるスキルに変換して。手順、私の好み、好きなフォーマットを含めて。
```

Claudeがスキルを構築し、Claude内の「Customize → Skills」の下に保存する。新しいチャットを開始するときはいつでも、「/」と入力してスキルを選択すれば、学習したすべてを持って、きれいなホワイトボードで戻ってくる。（設定→Capabilitiesで「Code execution and file creation」をオンにする必要がある。）

ChatGPTも一部のプラン（主にBusiness、Enterprise、Edu）でスキルを持っている。「このチャットからスキルを構築して」と尋ね、「Install」をクリックし、新しいチャットでスキル名を@メンションする。

### 📌 AIで1,800ドルの車修理費が0ドルに

ウェストバージニア州のある男性が、エンジンチェックランプが点灯した後、トヨタをディーラーに持ち込んだ。新しい排気部品が必要だと言われ、見積もりは1,800ドルだった。最悪なのは、車が保証期間をわずか約3,000マイル過ぎていたことだ。本当に惜しい。

支払う代わりに、彼はChatGPTに尋ねた。ChatGPTは価格が少し高いようだと指摘し、その後、ほとんどの人が聞いたことのないことを教えた：トヨタに「グッドウィル」支援を求めること。基本的に、保証期間が切れた直後に部品が故障した場合、自動車メーカーは顧客を満足させるために修理を無償でカバーすることがある。尋ねるだけでいい。

そこで彼はトヨタに連絡し、Redditの投稿によると、最終的に何も支払わなかった。1,800ドルが0ドルになった。

このような話が大好きだ。AIを使う様々な方法や、AIとの話し方について本当に考えさせられるから。彼は、自分だけだったら不安から見積もりをそのまま支払っていただろうとさえ言っている。多くの人がそうで、これはまさにAIが得意とすることだ。

そして、これは車だけでなく、もっと多くのものに有効だ。携帯電話、ノートパソコン、冷蔵庫、保証期間終了直後に壊れるものすべて。次回大きな修理見積もりを受け取ったら、支払う前にこれを貼り付けよう：

```
私の[車/携帯電話/家電]、[メーカー、モデル、年式]で[走行距離または使用年数]のものが[修理内容]が必要で、[価格]と見積もられました。これは妥当な価格ですか？これをカバーできる保証、リコール、延長保証、またはグッドウィルプログラムはありますか？その後、メーカーに送る正確なメールを書いてください。
```

グッドウィルは会社次第で保証ではないため、毎回機能するわけではない。しかし、尋ねるのに5分かかるだけで、最悪の場合「ノー」と言われるだけだ。

高すぎると感じる請求書がある場合、ChatGPTを使って対抗するための無料の完全ガイド（すべてのプロンプト付き）がある。
