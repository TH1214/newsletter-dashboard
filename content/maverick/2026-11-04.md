### 🧳 ChatGPT用の5つの秘密旅行コード

フルタイムで旅行している筆者が常用する5つのChatGPT旅行コードを紹介。各コードは短いコマンドで、詳細を入力するだけでChatGPTが処理を行う。

**1. /layover（乗り継ぎ）**

```
/layover AA 1234, 5 hours in Dallas
```

乗り継ぎ時間のミニ旅程を作成し、空港に戻るべき正確な時刻も提示。6時間もゲートで待つ必要がなくなる。

**2. /hidden-gems（穴場スポット）**

```
/hidden-gems Lisbon
```

観光地ではなく、地元の人が実際に行くレストラン、景色、トップ10リストに載らない地域を教えてくれる。

**3. /packing（荷造り）**

```
/packing Tokyo, December 10 to 17
```

訪問先の実際の天気予報に基づいた荷造りリストを作成。70度（華氏、約21度）の都市に冬用コートを持っていく失敗を防ぐ。

**4. /translate-menu（メニュー翻訳）**

```
/translate-menu [メニューの写真を添付]
```

どの言語のメニューでも写真を撮るだけで、全料理の内容と注文すべき料理を教えてくれる。

**5. /seat-hack（座席ハック）**

```
/seat-hack Delta 412, JFK to LAX, December 20
```

特定の便で空いている最良の座席と、実際にその座席を確保するためのチェックイン時刻を教えてくれる。

これらは文字通り人生を変えるツールだ。ChatGPTを旅行アシスタントとして扱い始めれば、二度と昔の方法で旅行計画を立てることはなくなる。

**注意点**：フライト時刻、座席マップ、天気予報など変動する情報については、ChatGPTはウェブをライブ検索するが、重要事項（搭乗時刻など）は航空会社のアプリで再確認すること。

### 🤖 Microsoft Copilotで独自AIエージェントを構築

Microsoft Copilotの「Agent Builder」を使えば、コーディング不要で独自AIエージェントを構築できる。

**構築手順**：

**ステップ1**：Microsoft Copilotアプリ（または copilot.cloud.microsoft）を開き、仕事用アカウントでサインイン。左サイドバーの「Agents & Skills」をクリックし、「New agent」を選択。

**ステップ2**：「Message Agent Builder」ボックスに、エージェントが行うべきことを記述。例：「新入社員の有給休暇ポリシー、経費、誰に何を尋ねるべきかについての質問に答える」。Copilotが指示を自動作成。

**ステップ3**：「+」をクリックして、従業員ハンドブックやSharePointフォルダーなど、エージェントが知るべき情報を追加。

**ステップ4**：「Try it」でテストし、「Create」をクリック。

**ステップ5**：「Share」をクリックし、使用者を選択してチームと共有。

チームメイトは自分がアクセス権を持つコンテンツからのみ回答を得られる。エージェントを共有しても、ファイルへのアクセス権は付与されない。

さらに高度な機能を求める場合は、エージェントをMicrosoft Copilot Studioにコピーし、メール送信やスプレッドシート更新などのアクションを追加できる。Microsoft Teamsなどでも公開可能。

### 📉 ChatGPTは長時間会話で39%性能低下

ChatGPTとの会話が長くなるほど、回答の質が低下する。

MicrosoftとSalesforceの研究者が、ChatGPTやClaudeを含む主要AIモデル15種を20万以上の会話でテスト。必要な情報を最初にすべて提供した場合はうまく機能したが、長い対話で少しずつ情報を提供した場合、平均で**39%性能が低下**した。

**原因はコンテキストウィンドウ（文脈窓）**。AIの短期記憶のようなもので、メッセージを送るたびに、AIは新しいメッセージだけでなく、**チャット全体を最初から毎回読み直して**から回答する。

ホワイトボードに例えると：送信したメッセージはすべてボードに書かれ、回答前にAIはボード全体を読む。チャット開始時はボードはきれいだが、1時間後には埋め尽くされる。放棄した古いアイデア、3番目のメッセージでの誤った推測も残っており、ボードが満杯になると最古の内容が消去され始める。

研究者は、AIが早期に誤った方向に進むと回復せず、その誤りがボード上に残り続けてその後のすべての回答に影響することを確認した。

**2つの解決策**：

**1. 新しいチャットに要約する**

チャットが長くなってきたら、以下を貼り付ける：

```
この会話の重要事項すべてを、新しいチャットに貼り付けられる1つのプロンプトにまとめて。下した決定と必要な詳細をすべて含めて。
```

その後、新しいチャットを開いて貼り付ける。重要事項をすべて知っている新鮮なChatGPTと話すようなもの。

**2. スキルとして保存する**

Claudeを使用している場合、または少し高度な方法を求める場合、特に週次メール作成やコンテンツ計画など繰り返し行うことに適している。以下のように指示：

```
このチャットで判明したすべてを、手順、私の好み、好きなフォーマットを含めて、再利用可能なスキルにして。
```

Claudeがスキルを構築するので、「Customize → Skills」で保存。新しいチャットを開始する際は、「/」を入力してスキルを選択するだけで、学習内容すべてを持った、きれいなホワイトボードで再開できる（Settings → Capabilitiesで「Code execution and file creation」をオンにする必要がある）。

ChatGPTも一部プラン（主にBusiness、Enterprise、Edu）でスキル機能を提供。「このチャットからスキルを作成して」と依頼し、「Install」をクリック後、新しいチャットでスキル名を「@」で呼び出す。

### 🚗 AIで1,800ドルの車修理費が0ドルに

ウェストバージニア州の男性がトヨタ車のチェックエンジンランプ点灯でディーラーに持ち込んだところ、新しい排気部品が必要で見積もりは**1,800ドル**。最悪だったのは、保証期間をわずか約3,000マイル過ぎていたこと。

そのまま支払う代わりに、彼はChatGPTに尋ねた。ChatGPTは価格が少し高いと指摘し、さらにほとんどの人が聞いたことのない「goodwill（善意補償）」支援をトヨタに求めるよう提案。基本的に、保証期間終了直後に部品が故障した場合、自動車メーカーは顧客満足のため修理を負担することがある。依頼するだけでよい。

彼がトヨタに連絡した結果、Redditの投稿によると、支払額は**0ドル**になった。1,800ドルが0ドルに。

このような事例は、AIの多様な使い方と話しかけ方を考えさせてくれる。彼は、自分一人では不安からそのまま見積もりを支払っていただろうと述べている。多くの人がそうであり、これはまさにAIが得意とする分野だ。

これは車以外にも適用できる。スマホ、ノートPC、冷蔵庫など、保証期間終了直後に壊れたもの。次回大きな修理見積もりを受け取ったら、支払う前に以下を貼り付ける：

```
私の[車/スマホ/家電]、[メーカー、モデル、年式]で[走行距離または使用年数]のものが[修理内容]を必要とし、[価格]の見積もりを受けた。これは妥当な価格？保証、リコール、延長保証、goodwillプログラムでカバーできる可能性は？その後、メーカーに送る正確なメールを書いて。
```

goodwillは企業の裁量であり保証ではないため、毎回成功するわけではない。しかし依頼は5分で済み、最悪「いいえ」と言われるだけだ。

高すぎると感じる請求書がある場合、ChatGPTで交渉するための無料ガイド（全プロンプト付き）も用意されている。
