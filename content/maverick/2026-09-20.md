### 📌 ChatGPTで請求書を削減する方法

あなたが支払っているほぼ全ての請求書は、必要以上に高額である。自動車保険、インターネット、携帯電話プラン、忘れていたジムの会費など。企業側は大半の人が電話して交渉しないことを知っているため、料金を下げない。ここでChatGPTの出番となり、大幅な節約が可能になる。ChatGPTは明細書を精査し、全ての請求を洗い出し、競合他社の料金を調べ、現在の契約先に価格マッチを求めるメールを送信し、全ての請求が決着するまで返信を処理する。3つのプロンプトを貼り付けて受信箱を確認するだけだ。

**ステップ1:** ChatGPTを開き、上部の「Work」に切り替える。有料プランならGPT-6 Astraが選択されていることを確認し、無料プランなら最新の5.6モデルを選ぶ。次に以下を貼り付ける。Gmailがまだ接続されていない場合は接続を求められるか、代わりに過去3ヶ月の明細書をドラッグ&ドロップできる。

```
@Gmail 私の明細書とメールを精査し、支払っている全ての定期請求とサブスクリプションをリスト化してください：プロバイダー、金額、頻度、次回更新日。それらを3つのグループに分類：交渉可能なもの（保険、インターネット、携帯電話、エネルギー、競合がいるもの）、60日間使用していないため解約すべきもの、そのままにすべきもの。各グループの年間合計を含む表形式で出力してください。
```

この表は衝撃的だ。全てを一箇所で年間の数字として見るのは初めてで、「60日間未使用」グループは予想以上に長い。ここから実際に節約する部分に入る。

**ステップ2:** 同じチャット内で以下を貼り付ける。

```
交渉グループの全ての請求について、私の詳細を使用して、同じプランまたは補償内容で大手競合3社が請求する金額を調べてください。次に@Gmailで現在の各プロバイダーにメール送信：競合の価格を伝え、今日すぐに乗り換える準備ができていると述べ、私を維持するために何ができるか尋ねてください。各メールを送信前に見せてください。
```

これは予想以上に機能する。顧客維持は新規顧客獲得より安価であり、大半の企業は「乗り換え」という言葉が出た瞬間に提示できる金額を用意している。保留になることも、チャットすることもなく、ChatGPTが既に書いたメールを承認するだけだ。

**ステップ3:** これが素晴らしい部分。ChatGPTが返信を処理してくれる。最後にこれを貼り付ける。

```
スケジュールタスクを設定：毎朝、@Gmailでこれらのプロバイダーからの返信を確認。競合の価格と同等かそれ以下の場合は、受諾の返信をして私に報告。提示額が少ない場合は、競合の価格を再度示して一致を求める返信を1回送信。断られた場合は私に報告して乗り換えます。全ての請求が決着するまでこれを実行。次に、解約グループの全てについて、@Gmailで解約メールを送信するか解約リンクを見つけてください。
```

こうして、他のことをしている間に交渉全体が進行する。プロバイダーがオファーを返してきたら、ChatGPTが読み、返信し、各請求がどこに落ち着いたか1行のサマリーが届く。実際の注意が必要な時間は約20分で、それは毎年同じ20分だ。

### 📌 Claudeでドキュメントとスライドを作成

水曜日、Anthropic（アンソロピック）はCowork（タスク実行側のClaude）を通常のClaudeアプリに統合したため、どちらを開くか選ぶ必要がなくなった。そしてこの機会に、チャット内で3つの機能を立ち上げた：**Claude Docs**、**Claude Slides**、**Claude Design**である。

実際の意味はこうだ。レポートを依頼すると、共有可能なリンクで行ごとに編集できる実際のドキュメントを作成する。デッキを依頼すると、クリックして変更できる実際のスライドを構築し、PowerPointやPDFとしてエクスポートできる。グラフィックを依頼すると、会話内でデザインする。彼らが示した例は1つのメッセージ：「いつものように書いて、漏れがあればフラグを立て、ハイライトを5枚のスライドにまとめてリーダーシップミーティング用に」と伝えると、レポートとデッキを一緒に返してくれる。

今後数週間でPro（プロ）とMax（マックス）プランに、ウェブ、デスクトップ、モバイルで展開され、その後TeamとFreeが続く。Proプランでまだ表示されない場合、それが理由だ。これはClaudeが「テキストではなく、実物を作ってくれ」という問題に対する初の本格的な回答であり、待ち望んでいたものだ。

今週OpenAI（オープンAI）から仕事でChatGPTを使う人に重要な2つの小さなニュース：

| 内容 | 重要性 |
|------|--------|
| Microsoft Word内のChatGPT | 木曜日に新しいアドイン。ドキュメントを離れずにサイドバーから下書き、要約、書き直し、フォーマットが可能 |
| カスタムGPTsの廃止 | 作成した場合、12月11日に旧バージョンが停止する前に「My GPTs」で「Migrate to plugin」をクリック。プラグインは同じ機能を提供し、アプリにも接続可能 |

### 📌 ChatGPTで求人応募を自動化

Indeed（インディード）がChatGPTに直接統合された。求人リストを1件ずつスクロールし、同じフォームに40回履歴書を貼り付ける代わりに、Indeedアカウントを接続すれば、ChatGPTが求人を取り込み、面接を受けられる可能性でランク付けし、カスタマイズした応募を1件ずつ自動実行する。セットアップは約3分。手順は以下の通り。

**ステップ1:** まずIndeedで履歴書を更新する。ChatGPTはファイルをアップロードできないため、Indeedプロフィールにあるものが送信される。何よりも先にこれを修正する。

**ステップ2:** ChatGPTを開き、左サイドバーの「Plugins」をクリックし、「Indeed」を検索し、「Install」を押し、求められたらIndeedアカウントにサインインする。これで接続完了。

**ステップ3:** 新しいチャットを開始し、以下を貼り付ける。

```
@Indeed 私の履歴書にある内容を使用して、私が資格を持つ過去7日間に投稿された全ての求人を見つけ、面接を獲得する可能性でランク付けしてください。
```

返ってくるのは、給与、企業評価、各求人に「Apply on Indeed」ボタンが付いたランク付けリストだ。これだけで週末分の作業が1分で完了する。しかし人々が熱狂している次のステップには、デスクトップアプリとPlusプランが必要だ。

**ステップ4:** ChatGPTデスクトップアプリで、同じチャット内で以下を貼り付ける。

```
@browser ランク付けされた求人リストを上から順に確認し、上位50件の求人に応募してください。各求人について、Indeedでリストを開き、職務内容を読み、それに合わせて私の応募をカスタマイズしてください。
```

ChatGPTは独自のブラウザでIndeedを開き、応募を開始し、各リストに合わせてカバーレターを書き直す。実行中はラップトップをスリープさせず、どれだけの自由度を与えるか尋ねられたら、完全アクセスではなく「Approve for me」を選択すれば、送信前に異常があれば確認できる。実際には、1セッションで50〜150件の本物のカスタマイズされた応募が完了し、これは大半の人が1ヶ月で送る数以上だ。

これを読んでいる全員が求職中とは限らないが、全員が求職中の知人を知っている。これは転送すべき情報だ。
