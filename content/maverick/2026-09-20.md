### 📌 本日実行すべきこと

**ChatGPTで請求書を値下げする**

あなたが支払っているほぼすべての請求は、本来必要な金額より高い。自動車保険、インターネット、携帯電話プラン、忘れていたジムの会費。企業側は、ほとんどの人が電話して交渉してこないことを知っているため、料金を下げない。ここでChatGPTの出番だ。大幅な節約が見込める。ChatGPTは明細書を確認し、すべての請求を洗い出し、競合他社の料金を調べ、現在の契約先にマッチングを求めるメールを送り、すべての交渉が完了するまで返信を処理する。あなたは3つのプロンプトを貼り付けて、受信トレイを確認するだけだ。全手順を紹介する。

**ステップ1:** ChatGPTを開き、上部の「Work」に切り替える。ChatGPT有料プランを利用している場合は、GPT-6 Astraが選択されていることを確認し、無料プランの場合は最新の5.6モデルを選択する。次に以下を貼り付ける。Gmailがまだ接続されていない場合は接続を求められる。または、過去3か月分の明細書をドラッグ＆ドロップしてもよい。

```
@Gmail 明細書とメールを確認し、支払っている定期的な請求とサブスクリプションをすべてリスト化してください：プロバイダー、金額、頻度、次回更新日。それを3つのグループに分けてください：交渉して値下げできるもの（保険、インターネット、電話、エネルギー、競合がいるもの）、60日間使用していないため解約すべきもの、そのままにしておくもの。各グループの年間合計額を含む表を作成してください。
```

この表が目覚めの一撃となる。すべてを一箇所で年間金額として見るのは初めてだからだ。「60日間使用していない」グループは、予想以上に長くなることが多い。ここからが実際に節約につながる部分だ。

**ステップ2:** 同じチャット内で以下を貼り付ける。

```
交渉グループのすべての請求について、私の詳細情報を使用して、同じプランまたは補償内容で3大競合他社が請求する金額を調べてください。次に@Gmailで現在の各プロバイダーにメールを送信してください：競合他社の価格を伝え、今日すぐに乗り換える準備ができていると言い、私を引き留めるために何ができるか尋ねてください。各メールを送信前に見せてください。
```

これは予想以上に機能する。あなたを引き留める方が、新規顧客を獲得するより安上がりだからだ。ほとんどの企業は、「乗り換え」という言葉が出た瞬間に提示できる金額を用意している。保留で待つ必要も、チャットする必要もない。ChatGPTが既に書いたメールを承認するだけだ。

**ステップ3:** これが私の好きな部分だ。ChatGPTが返信を処理してくれる。最後にこれを貼り付ける。

```
スケジュールタスクを設定してください：毎朝、@Gmailでこれらのプロバイダーからの返信を確認してください。競合他社の価格と同等またはそれ以下の提示があれば、承諾の返信をして私に知らせてください。それより低い提示の場合は、競合他社の価格で1回返信し、マッチングを求めてください。断られた場合は私に知らせてください。乗り換えます。すべての請求が完了するまでこれを実行してください。次に、解約グループのすべてについて、@Gmailで解約メールを送信するか、解約リンクを見つけてください。
```

つまり、あなたが他のことをしている間に交渉全体が進行する。プロバイダーから提示があれば、ChatGPTが読み取り、返信し、各請求がどこに落ち着いたか1行のサマリーが届く。実際の注意を要する時間は約20分で、毎年同じ20分だ。

### 📌 これは大きい

**Claudeで文書とスライドが作成できるように**

水曜日、Anthropic社はタスク実行型のCoworkを通常のClaudeアプリに統合したため、どちらを開くか選ぶ必要がなくなった。そしてこのタイミングで、チャット内で3つの機能を立ち上げた：Claude Docs（文書）、Claude Slides（スライド）、Claude Design（デザイン）だ。

実際の使用感はこうだ。レポートを依頼すると、共有可能なリンクで、1行ずつ編集できる実際の文書を作成する。プレゼン資料を依頼すると、クリックして変更し、PowerPointやPDFとしてエクスポートできる実際のスライドを構築する。グラフィックを依頼すると、会話内でデザインする。彼らが示した例は1つのメッセージだけ：「いつものやり方で書いて、漏れがあればフラグを立て、ハイライトを5枚のスライドにまとめてリーダーシップミーティング用に」で、レポートとプレゼン資料の両方が返ってくる。

今後数週間でPro・Maxプランのウェブ・デスクトップ・モバイルに展開され、その後TeamとFreeプランが続く。Proプランでまだ表示されない場合は、それが理由だ。これはClaudeが初めて「テキストではなく、実際のものを作る」という問題に対する本格的な解決策を提供した瞬間であり、私が待ち望んでいたものだ。

今週OpenAIから発表された、仕事でChatGPTを使う人に関係する小さな2つのニュース：

| 内容 | 重要な理由 |
|------|-----------|
| Microsoft Word内のChatGPT | 木曜日の新アドイン。サイドバーから文書を離れずに下書き・要約・書き換え・書式設定が可能 |
| カスタムGPTが廃止へ | 構築した場合は「My GPTs」から12月11日までにプラグインへ移行を。それ以降は旧版が動作停止。プラグインは同じ機能に加えアプリ連携も可能 |

### 📌 知っておく価値あり

**ChatGPTが求人応募を代行**

IndeedがChatGPTに直接連携するようになった。求人リストを1件ずつスクロールして履歴書を40回も同じフォームに貼り付ける代わりに、Indeedアカウントを接続すれば、ChatGPTが求人を取り込み、面接獲得の可能性でランク付けし、個別最適化した応募を1件ずつ代行する。セットアップは約3分だ。手順を紹介する。

**ステップ1:** まずIndeed上で履歴書を更新する。ChatGPTはファイルをアップロードできないため、Indeedプロフィールにあるものが送信される。他の作業より先にこれを修正する。

**ステップ2:** ChatGPTを開き、左サイドバーの「Plugins」をクリックし、「Indeed」を検索して「Install」を押し、求められたらIndeedアカウントにサインインする。これで接続完了だ。

**ステップ3:** 新しいチャットを開始し、以下を貼り付ける。

```
@Indeed 履歴書の内容を使用して、過去7日間に投稿された、私が資格を持つすべての求人を見つけ、面接獲得の可能性でランク付けしてください。
```

戻ってくるのは、給与・企業評価・各求人に「Apply on Indeed」ボタンが付いたランク付けリストだ。これだけで週末の作業が1分で完了する。しかし人々が熱狂しているのは次のステップで、デスクトップアプリとPlusプランが必要だ。

**ステップ4:** ChatGPTデスクトップアプリで、同じチャット内に以下を貼り付ける。

```
@browser ランク付けされた求人リストを上から順に確認し、上位50件の求人に応募してください。各求人について、Indeedで求人情報を開き、職務内容を読み、それに合わせて応募内容を調整してください。
```

ChatGPTは独自のブラウザでIndeedを開き、応募を開始し、各求人に合わせてカバーレターを書き換えながら進める。実行中はノートパソコンを起動状態に保ち、どの程度の自由度を与えるか尋ねられたら、完全アクセスではなく「Approve for me」を選択すると、送信前に異常があれば確認できる。実際には、1セッションで50〜150件の実際の個別最適化された応募が完了する。これはほとんどの人が1か月で送る数を上回る。

この記事を読んでいる全員が求職中とは限らないが、誰もが求職中の知人を持っている。これは転送すべき情報だ。
