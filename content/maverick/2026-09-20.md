### 📌 💰 今日やるべきこと：ChatGPTで請求書を減額する

あなたが支払っているほぼすべての請求書は、本来必要な額より高い。自動車保険、インターネット、携帯電話プラン、忘れていたジムの会費など。企業側は、ほとんどの人が電話して交渉しないことを知っているため、料金を下げない。ここでChatGPTの出番となる。ChatGPTはあなたの明細書を調べ、すべての請求を見つけ、競合他社がいくら請求するかを調べ、現在のプロバイダーに競合価格に合わせるようメールし、すべての請求が終わるまであなたの代わりに返信を処理する。3つのプロンプトを貼り付けて、受信箱を確認するだけだ。全体の手順は以下の通り。

**ステップ1:** ChatGPTを開き、上部で「Work」に切り替える。ChatGPTの有料プランを使っている場合は、GPT-6 Astraモデルが選択されていることを確認し、無料プランの場合は最新の5.6モデルを選ぶ。次にこれを貼り付ける。Gmailがまだ接続されていない場合は接続を求められるか、代わりに過去3か月の明細書をドラッグできる。

```
@Gmail 私の明細書とメールを調べて、支払っているすべての定期請求とサブスクリプションをリストアップしてください：プロバイダー、金額、頻度、次の更新日。次にそれらを3つのグループに分けてください：交渉して減額できるもの（保険、インターネット、電話、エネルギー、競合がいるもの）、60日間使っていないので単にキャンセルすべきもの、そのままにしておくもの。各グループの年間合計を含む表にしてください。
```

この表が目覚ましコールとなる。なぜなら、すべてを一箇所で年間の数字として見るのは初めてで、「60日間使っていない」グループは常に思っているより長いからだ。次は実際にお金を節約する部分だ。

**ステップ2:** 同じチャットで以下を貼り付ける。

```
交渉グループのすべての請求について、私の詳細を使って、同じプラン または補償に対して最大手の競合3社がいくら請求するかを調べてください。次に@Gmail 現在の各プロバイダーにメールしてください：競合の価格を伝え、今日切り替える準備ができていると言い、私を維持するために何ができるか尋ねてください。送信前に各メールを見せてください。
```

これは予想以上に機能する。あなたを維持する方が、新規顧客を見つけるよりも企業にとって安上がりで、ほとんどの企業は「切り替える」という言葉を聞いた瞬間に提示できる金額を持っている。保留にされることもなく、チャットすることもなく、ChatGPTがすでに書いたメールを承認するだけだ。

**ステップ3:** これが私の好きな部分だ。ChatGPTがあなたの代わりに返信を処理する。これを最後に貼り付ける。

```
スケジュールタスクを設定してください：毎朝、@Gmail これらのプロバイダーからの返信をチェックしてください。競合の価格に合うか下回る場合は、受け入れる返信をして私に伝えてください。それより少ない金額を提示した場合は、競合の価格で一度返信し、それに合わせるよう依頼してください。断られたら私に伝えてください。切り替えます。すべての請求が終わるまでこれを実行してください。次にキャンセルグループのすべてについて、@Gmail キャンセルメールを送信するか、キャンセルリンクを見つけてください。
```

つまり、交渉全体があなたが他のことをしている間に行われる。プロバイダーがオファーを返信し、ChatGPTがそれを読み、返信し、各請求がどこに落ち着いたかの1行の要約を受け取る。全体で実際の注意が必要なのは約20分で、毎年同じ20分だ。

### 📌 🚀 これは大きい：ClaudeがDocs・Slidesを作成可能に

水曜日にAnthropicは、Claudeのタスク実行側であるCoworkを通常のClaudeアプリに統合したため、どちらを開くか選ぶ必要がなくなった。そしてこの機会に、チャット内に3つの機能を立ち上げた：**Claude Docs**、**Claude Slides**、**Claude Design**だ。

実際にこれが意味することは以下の通り。レポートを依頼すると、共有可能なリンクで1行ずつ編集できる実際の文書を作成する。デッキを依頼すると、クリックして変更でき、PowerPointやPDFとしてエクスポートできる本物のスライドを構築する。グラフィックを依頼すると、会話内でデザインする。彼らが示した例は1つのメッセージ：「いつものように書いて、見落としがあればフラグを立て、リーダーシップミーティング用にハイライトを5枚のスライドにまとめて」で、レポートとデッキを一緒に返す。

これは今後数週間でProとMaxでウェブ、デスクトップ、モバイルに展開され、その後TeamとFreeが続く。Proプランでまだ表示されていない場合は、それが理由だ。これは「テキストではなく、実物を作って」という問題に対するClaudeの初めての本当の答えで、私が待っていたものだ。

今週OpenAIから仕事でChatGPTを使う場合に重要な2つの小さなニュース：

| 内容 | 重要な理由 |
|------|-----------|
| ChatGPTがMicrosoft Word内に統合 | 木曜日の新アドイン。文書を離れることなくサイドバーから下書き、要約、書き直し、フォーマット可能 |
| カスタムGPTの廃止 | 作成した場合は、My GPTsに移動し12月11日までにプラグインに移行を。旧版は動作停止。プラグインは同じ機能を持ちアプリにも接続可能 |

### 📌 💼 知っておく価値あり：ChatGPTが求人応募を代行

Indeedが直接ChatGPTに統合された。求人を1件ずつスクロールして40回同じフォームに履歴書を貼り付ける代わりに、Indeedアカウントを接続し、ChatGPTが求人を取得し、面接を受けられる可能性で順位付けし、1件ずつカスタマイズした応募書類で応募する。セットアップは約3分。手順は以下の通り。

**ステップ1:** まずIndeedで履歴書を更新する。ChatGPTはファイルをアップロードできないため、Indeedプロファイルに載っているものが送信される。他の作業の前にこれを修正する。

**ステップ2:** ChatGPTを開き、左サイドバーでPluginsをクリックし、**Indeed**を検索し、Installをクリックし、求められたらIndeedアカウントにサインインする。これで接続は完了だ。

**ステップ3:** 新しいチャットを開始し、これを貼り付ける。

```
@Indeed 私の履歴書に基づいて、過去7日間に投稿された、私が資格を持つすべての求人を見つけ、面接を獲得する可能性で順位付けしてください。
```

返ってくるのは、給与、企業評価、すべてに「Apply on Indeed」ボタンが付いた順位付きリストだ。これだけで週末の作業が1分で終わる。しかし人々が驚いているのは次のステップで、デスクトップアプリとPlusプランが必要だ。

**ステップ4:** ChatGPTデスクトップアプリで、同じチャットにこれを貼り付ける。

```
@browser 順位付けされた求人リストを上から順に確認し、上位50件の求人に応募してください。各求人について、Indeedで求人情報を開き、職務内容を読み、それに合わせて応募書類をカスタマイズしてください。
```

ChatGPTは独自のブラウザでIndeedを開き、応募を開始し、進むにつれて各求人のカバーレターを書き直す。実行中はラップトップを起動したままにし、どの程度の自由を与えるか尋ねられたら、完全アクセスではなく「Approve for me」を選び、送信前に異常なものを確認できるようにする。実際には、1セッションで50〜150件の本物のカスタマイズされた応募を完了でき、これはほとんどの人が1か月で送る数より多い。

これを読んでいる全員が求職中というわけではないが、全員が求職中の誰かを知っている。これは転送すべきものだ。
