### 🧠 今日やるべきこと

**ChatGPTが1日であなたの人生全体を修正できるようになった**

誰もが書き留めていないリストを持っている。春から解約しようと思っていたサブスクリプション、予約し続けていない歯医者、頭の中で40回は下書きしたメール。どれも難しくはない。ただ、肩に乗っている期間が長すぎて、その重さに気づかなくなっているだけだ。

そこで私はChatGPTにそれらすべてを1日で修正するよう依頼し、2年間避けていたことを1つの午後で片付けてもらった。3つのプロンプトで、2つ目のプロンプトでアドバイスから実際の作業へと移行する。

**ステップ1:** ChatGPTを開き、上部のChatからWorkに切り替え、音声入力をオンにして、これを貼り付ける。そして話すだけだ。

```
私の人生で壊れている、未完成、または静かにストレスを与えているすべてについてインタビューしてください。分野ごとに進めてください：お金、健康、家、人間関係、仕事、管理業務、デジタルライフ、その他。分野ごとに3つの短い質問をして、小さすぎるものはありません。声に出すのが恥ずかしいようなことも含めてください。DONEと言ったら、すべてを「The Weight」という1つのリストにまとめてください：項目ごとに1行、分野ごとにグループ化し、それぞれどれくらい避けてきたかを横に記載してください。
次に「The Weight」を1日計画に変換してください。すべての項目を修正にかかる速さで並べ替え、最速のものを最上部に配置します。ただし、厳格な期限や健康問題があるものは、速度に関係なく最初に配置してください。各項目について、所要時間、正確に何をすべきか、ラベルを付けてください：ME（私だけができる）、YOU（ここであなたができる）、またはSPLIT（あなたが準備し、私が仕上げる）。Canvasにチェックリストとして配置し、[午前9時]から始まる各ブロックの開始時間を記載してください。
```

答えを入力するのではなく話すこと。そうすれば3倍多く言えるし、このすべてはどれだけ正直であるかにかかっている。返ってくるのは、あなたに乗っているすべてのもの、それぞれがどれくらいそこにあったかが隣に記載された1つの場所だ。私のリストには、隣に「2」と書かれたものがいくつかあった。年単位だ。次に、それをすべて時間付きのチェックリストに変え、素早く勝てるものを最上部に配置するので、コーヒーが終わる前に5つのことにチェックを入れられる。そして約半分はYOUと表示される。

**ステップ2:** ここがコツだ。これを貼り付ける。

```
次に、YOUまたはSPLITとマークされたすべてのYOU部分を順番に実行してください。すべてのメールとテキストを送信準備完了状態で下書きしてください。各サブスクリプションについて、正確な解約ページを見つけて手順を書いてください。各予約について、予約ページを見つけて必要なものを準備してください。必要に応じてブラウザを使用してください。詳細：私は[都市]に住んでいます。サブスクリプションは[アプリ]です。何かにログイン、支払い、送信、またはキャンセルする前に私に尋ねてください。進むにつれてCanvasで各項目をチェックし、私に残されているものを正確に教えてください。
```

そして、それが始まる。避けていたテキストを下書きし、忘れていたすべてのサブスクリプションの解約ページを見つけ、先延ばしにしていた予約の予約ページを引き出し、目の前で1つずつチェックを入れていく。何かを送信、支払い、またはキャンセルする前にあなたに確認するが、難しい部分、あなたを止めていた部分は完了している。

**ステップ3:** もう1つ。これが人々を動かすものだから。

```
このリストの中で、今日実際にやれば私の人生を最も変えるであろう1つのことを教えてください。3つの文で理由を説明し、その最初の10分間を、0:00から時計を動かして、ステップバイステップで教えてください。
```

それは決して予想したものではなく、通常は好ましくないほど強く響く。10分間やってみよう。ガイドにはさらに4つのプロンプトがあり、使っていないすべてのサブスクリプションが使用をやめてから今までにどれだけコストがかかったかを合計するものも含まれている。

### 🚨 これは深刻だ

**Anthropicの研究者が、AIが人類全員を殺す可能性があると考えて退職した**

これは今日、完全にインターネットを破壊したものだ。月曜日、Jacob Coxonという27歳の研究者がAnthropicを退職し、その理由を投稿した。彼の理由は驚くべきものだ。彼は3年間、最初はOpenAI、次にAnthropicで実際にこれらのモデルを自分で構築してきた。そして彼は投稿で、どちらの会社も責任ある行動を取っておらず、自己改善する超知能へと真っ直ぐに競争しており、私たちの命を賭けている、そしてAIを構築している人々は、それが10年以内に人類全員を殺す可能性があると真剣に信じていると述べた。翌日、Anthropicでアライメント科学を率いるEvan Hubingerが、これらのモデルが安全であることを確認することが実際の仕事である人物が、返信して彼に同意した。彼の言葉：「Jacobはここで正しい。私たちは本当にAIが人類全員を殺す可能性があると真剣に信じている。」彼は今後10年以内に自分の確率を10%以上と評価し、Anthropicはまだ超知能に対するこれを解決する計画を持っておらず、明らかにその軌道に乗っていないと述べた。

これは仕事について怒っている人ではない。これは、安全企業として自らを売り込んでいる会社の安全責任者が、記録に残る形で計画がないと言っているのだ。彼は、今日のモデルからのリスクは低く、彼が心配しているのはその後に来るもの、誰もが予想したよりも速く自己改善するモデルだと付け加えた。

しかし、重要な部分は怖い引用ではない。なぜ誰も止めないのかだ。囚人のジレンマと呼ばれる古い思考実験があり、それはまさにここで起こっていることだ。2人が逮捕され、別々の部屋に入れられる。両方が黙っていれば、両方が軽い刑を受ける。一方が話し、もう一方が黙っていれば、話した方は自由になり、もう一方は最大刑を受ける。両方が話せば、両方が重い刑を受ける。どちらの部屋からでも、もう一方の人が何をしようと、話した方が有利だ。だから両方が話し、両方がお互いを信頼していた場合よりも悪い場所に行き着く。

囚人をAIラボに置き換えてみよう。この競争の全員が、減速する方が安全だということに同意している。しかし、OpenAIが減速してAnthropicが減速しなければ、OpenAIは負ける。1レベル上げると、アメリカが減速して中国が減速しなければ、アメリカは負ける。だから、すべてのプレーヤーにとって、それぞれ単独での賢明な動きは続けることであり、全員が止めるべきだと同意しているが、誰もが止める人になることはできない。これがうまくいかなくなるのに悪役は必要ない。多くの賢い人々が自分自身にとって合理的な選択を何度も何度も下すだけで、一緒に誰も選ばなかった場所に走ってしまう。そして、このようなジレンマの中にいる人々は内側からそれを修正することはできない。だからCoxonの唯一の答えは協調的な一時停止であり、それは政府にかかっている。そして彼らがどれほど速く動くかはあなたも見てきた。Anthropicは文字通り、安全性をめぐってOpenAIを去った人々によって設立され、まさにこの罠から逃れるために会社を構築した。そして今週、そこで安全を率いる人物は、彼らにも計画がないと述べた。

そして、競争が実際にどれほど速く進んでいるかがこれだ。月曜日、OpenAIはエージェントが100万ドルの賞金付きの有名な数学問題を解いたと投稿し、投稿に埋もれていたのはこの一文だった：証明は「GPT-6 Astraよりも大幅に高性能な」次世代モデルを使用して作成された。Astraは1週間前に登場した。だから地球上で最も強力なモデルはすでにそうではなく、理由は単純だと私は賭ける：Astraはその後に来るものを構築するのを助けるのに十分優れており、そのモデルは次を構築するのを助ける。それがサイクルであり、終わらない。

私はAI支持者だ。皆さんもご存知の通り、私は毎日人々にこのものの使い方を教えており、やめるつもりはない。しかし、私は彼に同意するし、ここに座ってこれが大丈夫だと言うつもりはない。実際にそれをどうするか？あなたがやっていたことと同じことだ。今日あなたの携帯電話にあるモデルは危険ではなく、これらのツールを理解している人々は、何が来ようと、理解していない人々よりもはるかに良い立場にいるだろう。それを学び続け、使い続け、そして彼らが互いにしか話していないと思っているときに構築している人々が言うことに注意を払い続けよう。ただし、これらすべての後、バンカーを買いに行く時かもしれない。

### 🤯 これは狂気だ

**今週のGPT-6 Astraによる最も狂気じみた3つの構築物**

日曜日、私はGPT-6 Astraが地球上で最も強力なAIモデルだと言った。6日後、人々は完全に夢中になっている。なぜなら、それはローンチが示唆したよりもはるかに優れているからだ。ここに今週私が目を離せなかった3つの構築物がある。

**1. 人体全体、2,234個のパーツで**

via @ftcarpe on X

Asheという開発者がAstraに1つのプロンプトを与え、2,234個の個別にモデル化されたパーツに分解できる人体の完全な3Dウェブサイトを構築した。すべての骨、すべての臓器、15の身体システム、そしてそれを回転させ、任意のパーツをクリックしてその機能を読むことができる。今すぐライブで無料だ。そして医学校はこのようなソフトウェアに6桁を支払っている。

**2. 1つの文から遊べるビデオゲーム**

via @luckeyfaraday on X

人々は1つの文を入力して、完全に遊べるゲームを受け取っている。ある人は、すべての新しいモデルで実行するテストを持っており、Minecraftを1つのプロンプト、ワンショット、1つのファイルで要求し、Fable、Grok、Gemini、すべてで実行している。Astraは実際にMinecraftを返した最初のものだ。別の誰かがブラウザで遊べるマリオカートスタイルのレーサーを構築し、誰かが数分でFall Guysを構築した。

**3. オフィスの9枚の悪い写真が3Dモデルに変換された**

via @rpnickson on X

誰かが自分のスタジオの9枚の悪い写真をアップロードした。異なる角から携帯電話で撮影しただけで、Astraに空間を構築するよう依頼した。それはすべてが他のすべてに対してどこにあるかを理解し、写真をつなぎ合わせ、歩き回れる部屋の完全にインタラクティブな3Dモデルを返した。誰も寸法や机がどこにあるかを教えなかった。それは写真から理解した。これは本当に狂気じみており、私を吹き飛ばした。

これら3つすべてが私の心を吹き飛ばした。そして信じてほしい。カバーしなかったものがさらに非常に多くある。ChatGPT内でGPT-6 Astraを今すぐ試してみよう。Plusでは、通常のチャットではなくWorkの下にあるので、上部でそれに切り替えよう。
