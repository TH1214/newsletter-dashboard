### 📌 Claudeが常時起動アシスタント「Duet」を発表

Anthropic社は、ユーザーが質問するのを待つのではなく、先回りして行動するAIアシスタント「Duet(デュエット)」を正式発表した。これは、ChatGPTの「dots(ドッツ)」やMetaの「Muse(ミューズ)」に続く、プロアクティブ型の常時起動AIエージェントである。

**Duetの仕組み:**
- Gmail、Slack、カレンダー、その他6,000以上のアプリと連携可能
- 毎朝、実際に注意が必要な事項のみを簡潔にブリーフィング
- バックグラウンドで監視を続け、意思決定が必要な場合のみ通知
- テキストまたは音声で指示可能（例：「この会議をスケジュールして」「売上ダッシュボードを作成して」）

**現状の提供体制:**
- 現在は米国のClaude ProおよびMaxサブスクライバー向けにウェイトリスト受付中
- 一般提供は未定

**実例:**
筆者が使用しているChatGPTのdots（「Goose」と命名）は、オースティン滞在中、カレンダーから午前11時のAirbnbチェックアウトと午後5時のフライトを検出し、自動的に宿泊施設に遅延チェックアウトをメールで依頼。承認後15分で午後3時までのチェックアウト延長を確保した。

**Duetの特徴:**
- 仕事用途に最適化（個人的な用事にはまだ弱い）
- 安全対策として、メッセージ送信・支払い・文書署名・削除など重要なアクションの前に必ず確認画面を表示

AIは「チャット」から「エージェント」へ移行している。質問に答えを得るだけでなく、重要な事項を先回りして提示し、実行まで代行するプロアクティブアシスタントの時代に突入した。

### 📌 ChatGPTで1枚のセルフィーからフルカラー分析

ChatGPTにセルフィーを1枚アップロードするだけで、どの色が最も似合うかを正確に診断できる。アンダートーン、シーズン、フルパレット、顔色を悪く見せる色、さらに似合う金属やヘアカラーまで分析可能だ。

**パーソナルカラー分析とは:**
肌・髪・目の色に基づき、誰にでも似合う色と似合わない色がある。正しい色を着れば、シンプルなTシャツでも健康的で生き生きと見え、間違った色を着ればどんなに高価な服でも疲れて見える。従来はスタイリストに数百ドル支払い、顔に布を当てて判定してもらっていたが、今ではChatGPT内で約2分で完了する。

**手順:**

**ステップ1:** 自然光（窓際）で正面を向いてセルフィーを撮影。フィルター・濃いメイク禁止、可能な限りシンプルな背景で。照明が悪いと誤診の原因になる。

**ステップ2:** ChatGPTを開き、セルフィーをアップロードして以下のプロンプトを入力:

```
Create a high-end personal color analysis report based on the photo I uploaded, designed as a clean cream editorial layout with rounded cards and elegant typography. Work out my undertone (warm, cool or neutral), my contrast level (low, medium or high) and my season using the 12-season system, and explain which features led to each conclusion. Show my best colors as labeled swatches: my power colors, my best neutrals and my best accent colors. Then show a smaller palette of the colors that wash me out. Include which metals suit me (gold, silver or both), hair color directions that work with my season, and lip tones if relevant. Be honest, not flattering.
```

診断結果として、シーズン（例：ソフトオータム、ディープウィンター）、フルパレット、顔周りで避けるべき色のリストが得られる。

**ステップ3:** 実用化する。普段着ている服の写真を撮影し、同じチャットにアップロードして以下を送信:

```
Based on my color analysis, go through these clothes one by one. Tell me which ones work with my palette, which ones I should only wear away from my face, and which ones I should stop buying. Then give me 5 pieces to add to my wardrobe next.
```

これにより、似合わない色の服を買い続けることを防げる。店頭でも同様に、購入前に写真を撮って「これは私のパレットに合っていますか?」と尋ねることができる。

### 📌 Claudeを使うなら必須の4つの秘密コネクター

ほとんどの人はClaude

をそのまま使っているが、最も重要な機能を見逃している。コネクターを使えば、Claudeを他のアプリに接続し、実際にアプリ内で作業を実行できる。以下は最優先でインストールすべき4つのコネクターで、ほとんどの人はその存在を知らない。

**1. Blender（ブレンダー）**
Claudeが実際の3Dモデルを構築できるようになる。Blenderは無料の3Dソフトウェアで、接続後は「森の中の居心地の良い小屋と3本の松の木を作って」と入力するだけで、実際の3Dオブジェクトが画面上で組み立てられる様子を見られる。

**2. Sandcastles（サンドキャッスルズ）**
Claudeがあなたのニッチ分野でバイラルになっている動画をすべて分析できる。今何が話題で、次に何を投稿すべきかを尋ねると、実際のデータに基づいて効果的なフックやフォーマットを回答する。筆者自身も動画のリサーチに使用しており、コンテンツ制作者や企業のSNS担当者には必須。

**3. Zoom（ズーム）**
Claudeをすべての会議に接続できる。過去の会議で言われたことを何でも質問でき、自分が担当しているアクションアイテムもすべて把握している。

**4. Wispr Flow（ウィスパー・フロー）**
まだWispr Flowを使っていないなら、今すぐ使うべきだ（スポンサーではない）。タイプする代わりに話すだけで済むため、現在最高のAIツールの一つだと筆者は考えている。Claudeに直接接続可能。お勧めの使い方：Wispr Flowの会議トランスクリプトをClaudeに分析させ、音声スキルを構築することで、Claudeが書く文章があなた自身の話し方のように仕上がる。

**セットアップ手順:**

**ステップ1:** Claudeデスクトップアプリを開き（Blenderはブラウザでは動作しない）、以下を貼り付ける:

```
I want to connect four tools to Claude: Blender, Sandcastles, Zoom and Wispr Flow. Walk me through setting them up one at a time, in that order. For each one, tell me exactly what to click, wait for me to say "done" before moving to the next, and if something doesn't work, help me fix it before we continue. Start by asking whether I'm using the Claude desktop app, and whether I already have Blender installed, a Sandcastles account and Wispr Flow. Once Wispr Flow is connected, go through my meeting transcripts and build me a voice skill so you write the way I actually talk.
```

**ステップ2:** 最初の3つは、基本的に「Customize → Connectors」に進み、名前を検索して「Add」または「Connect」をクリックし、サインインする。Wispr Flowの場合は、Wispr Flowアプリから開始：「Settings → MCP → Add to Claude」。Claudeが正確なタイミングを指示する。
