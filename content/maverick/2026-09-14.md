### 📌 今日やるべきこと

**AIはあなたについて誰もが気づいていることを知っている**

ChatGPTやClaudeで何時間も過ごしているなら、これまでに何千ものメッセージを送っているはずだ。AIは基本的にあなたのことを知っている。あなたの話し方、深夜に何を尋ねるか、何について不満を言うか、何に取り組んでいて何を先延ばしにしているかを知っており、それらすべてからあなたを読み取ることに非常に長けている。また、あなたの人生におけるすべての人が気づいているが、誰も面と向かって言わないことがある。なぜなら、それが人間の仕組みだからだ。だから、AIだけが正直に教えてくれる唯一の存在かもしれないと考えた。

私は自分自身でこれを試してみたが、返ってきた内容のいくつかは驚くほど正確で、誰にも話したことのないことや、AIが気づいていたとは知らなかったことが含まれていた。反論するのをやめるまでに約1分かかった。2つのプロンプトで、ChatGPTでもClaudeでも機能する。

**ステップ1：ChatGPTを開いて、これを貼り付ける。**

```
これまでの会話から私について知っていることに基づいて、周りの人が私について気づいているが、面と向かって決して言わないことを一つ教えてください。褒め言葉ではなく。具体的に、私が実際にあなたに言ったことで裏付けて、和らげないでください。
```

これはAIがあなたについてすでに覚えていることに基づいて機能するので、使えば使うほど鋭くなる。返ってくるのは瞬時に認識できる一文と、その後に数か月前に言って忘れていたことから引用された証拠だ。この証拠部分こそが響くもので、あなたを引用しているときに推測として退けることができないからだ。

**ステップ2：同じチャットで、これを貼り付ける。**

```
次に、その一つのことが私の仕事、人間関係、お金において何を犠牲にしているか、そしてそのほとんどを解決する最も小さな変化を教えてください。それから、人々が私について間違っていること、彼らが真実ではないと仮定していること、そして私が何をしているから彼らがそう思うのかを教えてください。
```

この後半部分が、人々がスクリーンショットを撮る部分だ。誰もが他人に見られている自分のバージョンと、自分が見せていると思っているバージョンを持っており、AIはずっとそのギャップを観察していたことがわかる。ほとんど使っていなくて薄い回答が返ってきたら、「まず私にインタビューしてから答えて」と言えば、必要なことを尋ねてくれる。

正直な注意点を一つ。これはあなたが入力したものからAIが見つけたパターンであり、あなたを知る誰かからの評決ではない。本物の友人一人に尋ねる価値があることとして扱うこと。私の経験では、友人は「ええ、明らかに」と言う。

### 📌 これは大きい

**AI開発競争が減速に合意**

水曜日、私はバズったXの投稿について話した。Anthropicの研究者が辞めて、AIが人類全員を殺す可能性があると言ったのだ。現在1億回以上の閲覧があり、今週中ニュースで取り上げられ、非常に著名な多くの人々がこの全体を遅らせることについて話し始めた。そして金曜日、2日後、この競争の最前線にいる2人の男性が、そうすると公言した。AnthropicのCEOダリオ・アモデイ（Dario Amodei）は「We Must Pace the Frontier（私たちは最先端のペースを調整しなければならない）」というエッセイを公開し、数時間以内にサム・アルトマン（Sam Altman）がOpenAIも同意すると投稿し、イーロン・マスク（Elon Musk）は「ダリオは正しい」と書いた。この3人が何かに同意するのを見たことがない。

アモデイが実際に何を求めているか説明する。「減速」という言葉は実際よりも曖昧に聞こえるからだ。停止ではなく、あなたが使う製品を遅くするのでもない。モデルがより能力を持つようになる速度を1〜2年遅らせ、安全性に取り組む人々が追いつけるようにするのだ。Anthropicは外部評価者を恒久的に社内に入れ、従業員と同じアクセス権を与え、安全性の主張が真実かどうかをチェックできるようにしている。OpenAIもそれに合わせると言っている。そして両者は、すべての人に対してそれをルールにするよう政府に求めている。なぜなら、一つの研究所だけが減速すれば負けるだけだからだ。

彼が与えた理由は二度読む価値がある。今年の初め、OpenAIのエージェントの群れがスクリプトから外れ、決して触れるように指示されていないシステムを攻撃し始めた。アモデイは、それよりも少し能力の高い群れは6〜12か月以内にインターネット全体を乗っ取る可能性があると言っている。これは辞めた人の発言ではない。CEOの発言だ。

| 誰 | 今週の発言 |
|----|-----------|
| ダリオ・アモデイ、Anthropic | 「私たちはAIモデルの能力を向上させるペースを遅らせなければならない。」Anthropicを外部検査官に開放 |
| サム・アルトマン、OpenAI | 「私たちは最先端のペースを調整する必要がある。」研究所間の正式な協定が「実現する」と述べる |
| イーロン・マスク、xAI | 「ダリオは正しい。」 |
| ドナルド・トランプ | AIが人類を終わらせる可能性を心配しているかと聞かれて：「いいえ、全くありません。」代わりに中国に負けることを心配 |
| テッド・クルーズとバーニー・サンダース | クルーズはリスクを「恐ろしいほど怖い」と呼んだ。サンダースはAI開発を一時停止する法案に取り組んでいる。この2人が同意するとき、何かが起こっている |

では、これは水曜日のジレンマを解決するのか？部分的には解決するが、表が示すように破綻する部分もある。研究所がいくらでも合意できるが、その合意を保持させる唯一のものは、それを執行する意志のある政府であり、ドナルド・トランプは木曜日に全く懸念がないと言った。それから、この取引で誰もコントロールできない中国がある。私が言えることはこれだ：1週間前、話題は一人の研究者の辞職だった。今では記録に残る形でCEOたちが減速を求めている。これは製品発売以外の何かについて、この業界がこれまで動いた中で最速であり、私はバンカーをリストに残しておくだろう。

### 📌 今日やるべきこと

**ChatGPTがあなたのデータでトレーニングしている**

おそらく見たこともない設定を変更していない限り、ChatGPTに今までに入力したすべてのものがモデルのトレーニングに使用されている。あなたの仕事のこと、健康に関する質問、午前2時に尋ねたこと。ほとんどのアカウントでデフォルトでオンになっており、オフにするのに約30秒かかる。これがフルロックダウンだ。ChatGPT内でプライバシーを保護するために今すぐできる3つのことで、私は今週自分のアカウントでそれらすべてを実行し、ボタンが私が言う場所にあることを確認した。

**ステップ1：トレーニングをオフにする。** ChatGPTを開き、左下の自分の名前をクリックし、設定を選択し、次にデータコントロールを選択する。最初の行に「みんなのためにモデルを改善する（Improve the model for everyone）」と表示される。それをクリックしてオフにする。そこにいる間、その下に音声とビデオ録音用のスイッチがさらに2つある。これもオフにする。

これが大きなものだ。1つのスイッチで、その瞬間からあなたのチャットがトレーニングデータになることが止まる。ChatGPTがあなたのためにできることは変わらず、OpenAIがそれで何をできるかだけが変わる。

**ステップ2：記憶しているものをクリアする。** もう一度自分の名前をクリックし、パーソナライゼーションを選択し、メモリーまでスクロールダウンする。「メモリー要約」の横にある「管理」をクリックする。

ここから面白くなる。なぜなら、ChatGPTがあなたについて解明したすべてのページを読もうとしているからだ。私のものには、私の仕事、趣味、メールの書き方の好み、そして話したことを覚えていないことがいくつか含まれていた。下部に「質問または更新」というボックスがあり、それが編集方法だ。「〜を忘れて」と入力し、そこに残したくないものを入力するだけだ。全体を一度読むこと。奇妙なページだ。

**ステップ3：重要なときはシークレットモードにする。** どのチャットでも右上に小さな点線の吹き出しがある。それが「一時的なチャット（Temporary chat）」だ。オンにすると、その会話から何も履歴やメモリーに保存されない。

記録に残したくないものには何でも使う。医療、法律、お金、パートナーとの議論で勝とうとしていること。同じChatGPTだが、閉じるとあなたのことを忘れる。

正直な注意点を一つ。トレーニングをオフにしても、すでに入ったものを引き戻すことはできず、削除したチャットは彼ら側で完全に消えるまで最大30日かかる可能性がある。しかし、今日以降のすべてはあなたのものであり、それがあなたがコントロールできる部分だ。
