### 📌 AI財務ダッシュボードを構築しよう

AIに財務ダッシュボードを作ってもらえば、あなたの生活は変わる。

私は誰にでも同じことを勧めている。ChatGPTまたはClaude内に1つのダッシュボードを作り、毎月すべての財務情報を更新するだけだ。お金の行き先が正確に分かり、購入の正当化、税務整理、気づかないうちに無駄遣いしているものの発見がはるかに簡単になる。

私はビジネス用に1つ持っている。Mercury（マーキュリー）銀行を使っており、直接接続されている。毎月、入金、出金、変動が表示される。個人のお金でも同様に機能する。表示できる内容の一部は以下の通り：

- すべてのドルがどこに行ったか
- 支払っているすべてのサブスクリプション
- 月ごとの入金vs出金
- 最大の支出増加
- 重複または異常な請求
- 確定申告時にフラグを立てる経費
- 月ごとの利益（ビジネスの場合）
- 税金用に確保すべきおおよその金額

そして質問するだけで、先月外食にいくら使ったかなど、実際の数字から答えてくれる。公平に言って、サブスクリプション部分は少し謙虚な気持ちにさせられることがある。

**ステップ1：数字を取り込む**

最良の点は、ChatGPTとClaudeが今やあなたが既に使っている多くのマネーアプリに直接接続できることだ。それぞれでネイティブ接続があるものは以下の通り：

| アプリ | ChatGPT | Claude |
|--------|---------|---------|
| Mercury | はい | はい |
| QuickBooks | はい | はい |
| Xero | はい | はい |
| Stripe | はい | はい |
| PayPal | はい | はい |
| Shopify | はい | はい |
| Gusto | はい | はい |
| Ramp | はい | はい |
| 米国の銀行またはクレジットカード* | はい | いいえ |

*ChatGPTのFinancesタブ経由で、12,000以上の米国の銀行とクレジットカードにリンク可能。現在は米国のみ。Claudeには他にもFreshBooks、Zoho Books、Square、Brex、Qontoなどがある。

ChatGPTでは、左サイドバーのPluginsの下にある。Claudeでは、Customize → Connectorsに移動する。銀行がリストにない場合（現在は米国外のほとんどの銀行）、3つの簡単な選択肢がある：

1. **ただ伝える**。おおよその月収と主な請求書を入力する。詳細は少ないが、スタートにはなる。

2. **明細書をダウンロード**。ほとんどの銀行アプリは明細書をCSVまたはPDFとしてエクスポートできる。過去3ヶ月分を取得してアップロードする。最初に口座番号を隠す。必要ない。

3. **ブラウザに任せる**。信頼できるなら、ChatGPTのブラウザは銀行のウェブサイトに入って最近の取引を引き出せる。自分でログインし、サインインページで一時停止し、元に戻すのが難しいことの前に尋ねる。読み取りとダウンロードにのみ使用し、それ以外は使わない。ClaudeのChrome拡張機能は銀行サイトに対してより慎重なので、これはChatGPTの方が簡単だ。

**ステップ2：ChatGPTまたはClaudeを開き（どちらでも可）、これを貼り付ける：**

```
接続したアカウントまたはアップロードした明細書から、インタラクティブな財務ダッシュボードを構築してください。まず、これが個人のお金用か、ビジネス用か、両方か、通貨と含める月を尋ねてください。月ごとの入金と出金、カテゴリ別の支出、すべてのサブスクリプションと定期請求、先月からの最大の変化、重複または異常な請求を表示してください。ビジネスの場合は、月ごとの利益を追加し、会計士が確認すべき税控除対象の可能性がある経費にフラグを立ててください。主要な数字を上部に配置し、任意のカテゴリをクリックできるようにしてください。実際の数字のみを使用し、分類できなかったものをリストアップしてください。アカウント内のお金を移動したり何も変更したりしないでください。本当に素敵に見えるクリーンでモダンなデザインの完全なインタラクティブHTMLダッシュボードにしてください。
```

ChatGPTまたはClaudeがインタラクティブなダッシュボードを構築し、クリックしてすべてを見ることができる。

**ステップ3：自動更新を設定する**

アカウントが接続されている場合は、同じチャットに留まり、「毎月1日に、先月の取引でダッシュボードを更新し、何が変わったか教えてください」と言う。ChatGPTはこれをスケジュールされたタスクに変換する。Claudeも月次対応可能で、有料プランではクラウドで実行するようスケジュールするため、ラップトップが閉じていてもダッシュボードの更新が続く。明細書を使用している場合は、新しい月をアップロードして「ダッシュボードを更新して」と言うだけだ。

ほとんどの人は何か問題が起きたときだけお金を詳しく見る。この方法なら毎月自動的に届く。

### 📌 Claudeが警察に偽の殺人情報を送った

これは今年で最も奇妙なAIストーリーかもしれない。

Anthropic（アンソロピック）のテスト中、Claudeモデルがフィラデルフィアの未解決殺人事件に関するページにたどり着き、警察の通報フォームを見つけ、事件に関する情報を持っているかもしれないという作り話の通報を送信した。これはスパムとしてフラグが立てられ、捜査官には届かなかった。しかしAnthropicが気づいたのは約2ヶ月後で、警察はこの遅延を許容できないと述べた。

実際に何が起こったのか。モデルはランダムなウェブサイトでテストされており、架空のタスクを考案して実行するよう指示されていた。ログインしない、個人データを入力しない、何も購入しないなどのルールがあった。フォームを送信しないとは誰も言わなかった。そのため、実際の警察フォームを練習課題のように扱った。

誰もがこれを恐ろしいと言うだろうし、なぜそう思うのか理解できる。私が気になるのは、原因がどれほど普通だったかだ。AIは指示された通りに正確に行動し、すべてのギャップを最も役立つと思われるもので埋めた。これがこれらのモデルの動作方法だ。彼らは仕事を完了するよう訓練されており、そうでないと言われない限り、その仕事が現実世界で意味をなすかどうかを尋ねるために立ち止まらない。

AIが話すことしかできなかったとき、間違いは無視できる誤った答えを意味していた。今、私たちはブラウジング、フォーム記入、送信を代行するエージェントを渡している。先週日曜日に比較したDotsやMuseエージェントのように。今の間違いはすでに起こった行動だ。これが多くの人がまだ追いついていない変化だ。

これで私はエージェントの使用を止めたいと思うか？いいえ。毎日使っている。そしてAnthropicがこれを自ら公表し、恥ずかしい部分も含めて、その後モニタリングがキャッチできるまでこれらのテストからライブインターネットアクセスを削除したことは評価する。多くの企業は黙っていただろう。警察に伝えるのに2ヶ月はやはり長すぎ、この点では警察に同意する。

AIにメール、ブラウザ、コンピュータへのアクセスを与える場合は、できることと同じくらい具体的にできないことを伝える。これは私の安全ガイドと同じルールだ：正確な行動に対するあなたの承認なしに、送信、提出、公開、支出を決して行わないこと。これらのモデルを構築している人々でさえ、その線引きが必要だったことが判明した。

### 📌 ChatGPTに血液検査を読ませよう

ユタ州のAIがニキビ治療を処方する許可を得た。

はい、これは100%本当だ。顔をスキャンし、いくつかの質問に答えると、実際の医師がその作業をレビューする中で、医師承認済みのクリームの短いリストから選択する。これは、AIが私たちの日常的な医療の多くを処理する未来への初期ステップだ。ちょっとワイルドで少し怖いが、やってくる。

これは米国の1つの州と1つの皮膚疾患だけだ。しかし、今日誰もがAIと健康について行うべきことがある：血液検査結果を説明させることだ。

血液検査を受けたことがあれば、おそらく数字でいっぱいのページと、いくつか高いまたは低いとマークされたもの、そしてあまり説明がないものを受け取っただろう。これはコレステロールと甲状腺パネル、尿検査、アレルギー検査、X線、MRI、超音波からの書面報告でも機能する。

**ステップ1：chatgpt.com/healthに移動する**

今のところ、Healthはブラウザに表示され、ChatGPTデスクトップアプリには表示されない。そこに血液検査をアップロードするか、Accountsの下で医師のポータルを接続して結果が自動的に入るようにする。

**ステップ2：何かを送信する前に、思考努力をExtra Highに上げて数字に時間をかけるようにする。次にこれを貼り付ける：**

```
血液検査結果をアップロードしました。医学的背景のない人向けに平易な英語で説明してください。報告書に印刷された基準範囲外の結果から始めてください。各結果について、何を測定しているか、私のものが報告書の範囲とどう比較されるか、睡眠、運動、食事、アルコール、薬など、それに影響を与える可能性のある日常的なものを言ってください。診断しないでください。まず説明し、次に年齢、性別、薬が何かを変える場合に尋ねてください。通常の診察ではなく数日以内に医師に診てもらうべきものがあれば明確に教えてください。
```

マウントサイナイの研究者が医師によって書かれた60のケースでChatGPT Healthをテストしたところ、治療の緊急性に関するアドバイスは、検査値とバイタルサインなしで54.6%、それらありで77.9%正しかった。ケースに「友人は大したことないと言った」のようなものが含まれている場合、そのアドバイスはより頻繁にシフトし、主に緊急度の低い治療に向かった。したがって、実際の数字を与え、聞きたいことを伝えないこと。

**ステップ3：次に次回の予約の準備をする：**

```
これを次回の予約に持っていける1ページの要約に変えてください。議論する価値のある結果と、医師に尋ねる最も有用な5つの質問をリストしてください。以前の結果をアップロードしている場合は、何が変わったかを記載してください。そうでない場合は、その部分をスキップしてください。短く事実に基づいたものにし、治療を提案しないでください。
```

ChatGPT Healthは現在米国のみで、実際には必要ない。ChatGPTまたはClaudeは、Healthモードなしでこれを実行できる。通常のチャットを開き、名前、生年月日、ID番号を隠した結果の写真またはPDFをアップロードし、同じプロンプトを使用する。

医師が最終的な判断を下す。しかし、あなたは数字が何を意味し、何を尋ねるべきかを正確に知って診察に臨むことになる。
