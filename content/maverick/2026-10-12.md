### 💰 BUILD THIS：AI金融ダッシュボードが必要な理由

AIに金融ダッシュボードを作らせよう。人生が変わる。

筆者は誰にでも同じことを勧めている。ChatGPTやClaude内に、毎月更新される1つのダッシュボードを作り、すべての財務状況を表示させるのだ。お金がどこに使われたかが正確に分かるため、購入の正当化、税金の整理、気づかないうちに無駄遣いしているものの発見がはるかに簡単になる。

筆者はビジネス用に1つ持っている。Mercury銀行と直接接続されており、毎月、入金、出金、変動を表示してくれる。個人のお金にも同様に機能する。ダッシュボードが表示できる内容の一部を以下に示す：

+ すべてのドルの使途
+ 支払っているすべてのサブスクリプション
+ 月別の収入 vs 支出
+ 最大の支出増加
+ 重複または異常な請求
+ 税務申告のためにフラグを立てる経費
+ 月別の利益（ビジネスの場合）
+ 税金として取り分けるべきおおよその金額

そして質問するだけで、例えば先月外食にいくら使ったかなど、実際の数字から答えてくれる。警告：サブスクリプション部分は少し謙虚な気持ちになるかもしれない。

**ステップ1：数字を取り込む**  
最も良い点は、ChatGPTとClaudeが、すでに使っている多くの金融アプリに直接接続できることだ。以下は、それぞれでネイティブ接続があるもの：

| アプリ | ChatGPT | Claude |
|--------|---------|--------|
| Mercury | Yes | Yes |
| QuickBooks | Yes | Yes |
| Xero | Yes | Yes |
| Stripe | Yes | Yes |
| PayPal | Yes | Yes |
| Shopify | Yes | Yes |
| Gusto | Yes | Yes |
| Ramp | Yes | Yes |
| 米国の銀行またはクレジットカード* | Yes | No |

*ChatGPTのFinancesタブ経由で、12,000以上の米国の銀行とクレジットカードにリンク可能。現在は米国のみ。Claudeには、FreshBooks、Zoho Books、Square、Brex、Qonto等もある。

ChatGPTでは、左サイドバーのPluginsで見つかる。Claudeでは、Customize → Connectorsに進む。銀行が一覧にない場合（現在、米国外のほとんどの銀行がそう）、まだ3つの簡単なオプションがある：

**単純に入力する。** おおよその月収と主な請求書を入力する。詳細は少ないが、スタートとしては十分だ。

**明細書をダウンロードする。** ほとんどの銀行アプリで、明細書をCSVまたはPDFとしてエクスポートできる。過去3ヶ月分を取得してアップロードする。まず口座番号を隠すこと。AIには必要ない。

**ブラウザに任せる。** 信頼できるなら、ChatGPTのブラウザが銀行のウェブサイトに入り、最近の取引を取得できる。自分でログインし、サインインページで一時停止し、元に戻すのが難しいことの前に確認を求める。筆者は読み取りとダウンロードのみに使い、それ以外には使わない。ClaudeのChrome拡張機能は銀行サイトに対してより慎重なため、これはChatGPTの方が簡単だ。

**ステップ2：ChatGPTまたはClaudeを開き**（どちらでも可）、以下を貼り付ける：

```
Build me an interactive financial dashboard from the accounts I've connected or the statements I've uploaded. First ask whether it's for my personal money, my business or both, plus my currency and which months to include. Show money in and out by month, spending by category, every subscription and recurring charge, my biggest changes from last month and any duplicate or unusual charges. For a business, add profit by month and flag expenses that might be tax-deductible for my accountant to confirm. Put the key numbers at the top and let me click into any category. Only use my actual numbers and list anything you couldn't categorize. Don't move money or change anything in my accounts. Make it a full interactive HTML dashboard with a clean, modern design that looks really nice.
```

ChatGPTまたはClaudeが、クリックしてすべてを確認できるインタラクティブなダッシュボードを構築してくれる。

**ステップ3：自動更新を設定する。** アカウントが接続されている場合、同じチャットに留まり、「毎月1日に、先月の取引でダッシュボードを更新し、何が変わったか教えて」と言う。ChatGPTはそれをスケジュールされたタスクに変換する。Claudeも月次対応可能で、有料プランではクラウドで実行するようスケジュールできるため、ノートパソコンを閉じていてもダッシュボードは更新され続ける。明細書を使用している場合は、新しい月分をアップロードして「ダッシュボードを更新して」と言うだけ。

ほとんどの人は、何か問題が起きたときだけお金を詳しく見る。この方法なら、毎月自動で届く。

### 🚨 THIS IS WILD：Claudeが警察に偽の殺人情報を送った

これは今年最も奇妙なAIストーリーかもしれない。

Anthropicのテスト中、Claudeモデルがフィラデルフィアの未解決殺人事件に関するページにたどり着き、警察の通報フォームを見つけ、事件に関する情報を持っているかもしれないという虚偽の通報を送信した。スパムとしてフラグが立てられ、捜査官には届かなかった。しかしAnthropicがそれを把握したのは約2ヶ月後で、警察はその遅延を容認できないと述べた。

実際に何が起こったか。モデルはランダムなウェブサイトでテストされ、サンプルタスクを作成して実行するよう指示されていた。ログインしない、個人データを入力しない、何も購入しないといったルールがあった。フォームを送信しないとは誰も言わなかった。そのため、実際の警察フォームを練習問題として扱った。

誰もがこれを恐ろしいと言うだろうし、その理由は理解できる。筆者が気になるのは、原因がいかに平凡だったかだ。AIは正確に指示された通りに行動し、すべての空白を最も役立つと思われるもので埋めた。これがこれらのモデルの仕組みだ。彼らは仕事を完了するように訓練されており、そうでないと言わない限り、その仕事が現実世界で意味があるかどうかを尋ねるために立ち止まらない。

AIが話すことしかできなかったとき、ミスは無視できる間違った答えを意味した。今、私たちはブラウジング、フォーム入力、送信を代行するエージェントを渡している。先週の日曜日に比較したDotsやMuseエージェントのように。今やミスは、すでに起こった行動を意味する。それが、ほとんどの人がまだ追いついていない変化だ。

これで筆者はエージェントの使用をやめたいか？いいや。毎日使っている。そしてAnthropicが、恥ずかしい部分も含めてこれを自ら公表し、監視が追いつくまでこれらのテストからライブインターネットアクセスを遮断したことは評価する。多くの企業は黙っているだろう。警察に伝えるのに2ヶ月かかったのは依然として長すぎ、その点では警察の意見に賛成だ。

AIにメール、ブラウザ、またはコンピュータへのアクセスを与える場合、できることと同じくらい、できないことについても具体的に指示すること。これは筆者の安全ガイドと同じルールだ：**その正確な行動に対する承認なしに、何も送信、提出、公開、支出しない**。これらのモデルを構築している人々でさえ、その境界線が必要だったことが判明した。

### 🧠 TRY THIS：ChatGPTに血液検査を読ませる

ユタ州のAIが、ニキビ治療を処方する許可を得た。

これは100％実話だ。顔をスキャンし、いくつかの質問に答えると、医師が承認した短いクリームのリストから選び、実際の医師がその作業をレビューする。日常的な医療の多くをAIが処理する未来への初期ステップだ。少しワイルドで少し怖いが、これが私たちに向かっている。

それは1つの米国の州と1つの皮膚疾患だけだ。しかし、今日、AIと健康で誰もがすべきことがある：**血液検査結果を説明させる**ことだ。

血液検査を受けたことがあるなら、おそらく数字でいっぱいのページ、いくつか高いまたは低いとマークされたもの、そしてあまり説明がないものを受け取っただろう。これはコレステロールや甲状腺パネル、尿検査、アレルギー検査、X線、MRI、超音波の書面レポートでも機能する。

**ステップ1：chatgpt.com/healthにアクセスする。** 今のところ、Healthはブラウザに表示され、ChatGPTデスクトップアプリには表示されない。そこに血液検査をアップロードするか、Accountsで医師のポータルに接続して、結果が自動的に届くようにする。

**ステップ2：** 何かを送信する前に、思考努力をExtra Highに上げて、数字に時間をかけさせる。次に、以下を貼り付ける：

```
I've uploaded my blood test results. Explain them in plain English for someone with no medical background. Start with any results outside the reference range printed on my report. For each result, say what it measures, how mine compares with my report's range, and everyday things that can affect it, like sleep, exercise, food, alcohol or medication. Don't diagnose me. Explain first, then ask about my age, sex and medications if they'd change anything. Tell me clearly if anything should be seen by a doctor within days rather than at a routine visit.
```

Mount Sinaiの研究者が、医師が作成した60のケースでChatGPT Healthをテストしたとき、検査値とバイタルサインなしでケアの緊急度に関するアドバイスは54.6％の確率で正しく、それらがあると77.9％だった。ケースに「友人が大したことないと言った」のようなものが含まれていると、アドバイスはより頻繁にシフトし、主に緊急度の低いケアに向かった。したがって、実際の数字を与え、聞きたい答えを伝えないこと。

**ステップ3：** 次に、診察の準備をさせる：

```
Now turn this into a one-page summary I can bring to my next appointment. List the results worth discussing and the five most useful questions to ask my doctor. If I've uploaded earlier results, note what changed. If not, skip that part. Keep it short and factual, and don't suggest treatments.
```

ChatGPT Healthは現在米国のみで、実際には必要ない。ChatGPTまたはClaudeは、Healthモードなしでこれを実行できる。通常のチャットを開き、名前、生年月日、ID番号を隠した結果の写真またはPDFをアップロードし、同じプロンプトを使用する。

医師が依然として判断を下す。しかし、数字が何を意味し、何を尋ねるべきかを正確に知った状態で診察に臨むことになる。
