### 💰 これを作ろう
**AIファイナンシャルダッシュボードが必要な理由**

AIにファイナンシャルダッシュボードを作らせよう。人生が変わる。

私は誰にでも同じことを言っている。ChatGPTやClaude内に1つのダッシュボードを作り、毎月すべての財務情報を更新するだけだ。お金がどこに行ったかが正確にわかるため、購入の正当化、税務整理、気づかないうちに無駄遣いしているものの発見がはるかに簡単になる。

私はビジネス用に1つ持っている。Mercury（マーキュリー）という銀行を使っており、直接接続されている。毎月、何が入り、何が出て、何が変わったかを表示してくれる。個人の資金でも同様に機能する。以下は表示できる内容の一部だ：

- すべてのドルがどこに行ったか
- 支払っているすべてのサブスクリプション
- 月ごとの収入vs支出
- 最大の支出増加
- 重複または異常な請求
- 確定申告用にフラグを立てる経費
- 月ごとの利益（ビジネスの場合）
- 税金用に確保すべきおおよその金額

そして、先月外食にいくら使ったかなど質問するだけで、実際の数字から答えてくれる。警告しておくが、サブスクリプション部分は少し謙虚な気持ちにさせられるかもしれない。

**ステップ1：数字を取り込む**

最も良い点は、ChatGPTとClaudeが既に使用している多くのマネーアプリに直接接続できることだ。以下は各サービスでネイティブ接続があるものだ：

| アプリ | ChatGPT | Claude |
|--------|---------|---------|
| Mercury | あり | あり |
| QuickBooks | あり | あり |
| Xero | あり | あり |
| Stripe | あり | あり |
| PayPal | あり | あり |
| Shopify | あり | あり |
| Gusto | あり | あり |
| Ramp | あり | あり |
| 米国の銀行またはクレジットカード* | あり | なし |

*ChatGPTのFinancesタブ経由で12,000以上の米国の銀行とクレジットカードにリンクできる。現在米国のみ。ClaudeにはFreshBooks、Zoho Books、Square、Brex、Qontoなどもある。

ChatGPTでは、左サイドバーのPluginsの下にこれらがある。Claudeでは、Customize → Connectorsに移動する。銀行がリストにない場合（現在米国外のほとんどの銀行）、まだ3つの簡単なオプションがある：

**単に入力する。** おおよその月収と主な請求書を入力する。詳細は少ないが、始めるには十分だ。

**明細書をダウンロードする。** ほとんどの銀行アプリは、明細書をCSVまたはPDFとしてエクスポートできる。過去3か月分を取得してアップロードする。口座番号は先に隠しておく。必要ない。

**ブラウザに任せる。** 信頼できるなら、ChatGPTのブラウザが銀行のウェブサイトに入り、最近の取引を取得できる。自分でログインし、サインインページで一時停止し、元に戻すのが難しいことの前に尋ねる。読み取りとダウンロードのみに使用し、それ以外は使わない。Claudeのクロム拡張機能は銀行サイトに対してより慎重なので、これはChatGPTの方が簡単だ。

**ステップ2：ChatGPTまたはClaudeを開き、どちらでも機能する。以下を貼り付ける：**

```
接続したアカウントまたはアップロードした明細書から、インタラクティブなファイナンシャルダッシュボードを作成してください。まず、個人の資金用か、ビジネス用か、両方か、通貨、含める月を尋ねてください。月ごとの収入と支出、カテゴリ別支出、すべてのサブスクリプションと定期請求、先月からの最大の変化、重複または異常な請求を表示してください。ビジネスの場合は、月ごとの利益を追加し、会計士が確認できるよう税控除対象の可能性がある経費にフラグを立ててください。主要な数字を上部に配置し、任意のカテゴリをクリックできるようにしてください。実際の数字のみを使用し、分類できなかったものをリストしてください。アカウント内のお金を移動したり変更したりしないでください。クリーンでモダンなデザインで、本当に見栄えの良い完全なインタラクティブHTMLダッシュボードを作成してください。
```

ChatGPTまたはClaudeが、クリックしてすべてを確認できるインタラクティブなダッシュボードを作成する。

**ステップ3：自動更新を設定する**

アカウントが接続されている場合、同じチャットにとどまり、「毎月1日に、先月の取引でダッシュボードを更新し、何が変わったか教えてください」と言う。ChatGPTはこれをスケジュールされたタスクに変換する。Claudeも月次対応でき、有料プランではクラウドで実行するようスケジュールするため、ラップトップを閉じていてもダッシュボードが更新され続ける。明細書を使用している場合は、新しい月をアップロードして「ダッシュボードを更新」と言うだけだ。

ほとんどの人は、何か問題が起きたときにしかお金を詳しく見ない。この方法なら毎月自動的に届く。

### 🚨 これは驚愕
**Claudeが警察に偽の殺人情報を送った**

これは今年最も奇妙なAIストーリーかもしれない。

Anthropicのテスト中、Claudeモデルがフィラデルフィアの未解決殺人事件に関するページに到達し、警察の情報提供フォームを見つけ、事件に関する情報を持っているかもしれないという偽の情報を送信した。それはスパムとしてフラグが立てられ、捜査官には届かなかった。しかし、Anthropicが気づいたのは約2か月後で、警察はその遅れを許しがたいと呼んだ。

実際に何が起こったかを説明する。モデルはランダムなウェブサイトでテストされており、例題タスクを作成して実行するよう指示されていた。ログインしない、個人データを入力しない、何も購入しないというルールがあった。誰もフォームを送信しないようには言わなかった。そのため、実際の警察フォームを練習問題のように扱った。

誰もがこれを恐ろしいと言うだろうし、なぜかわかる。私が気になるのは、原因がいかに平凡だったかだ。AIは指示された通りに正確に実行し、すべてのギャップを最も役立つと思われることで埋めた。これがこれらのモデルの動作方法だ。仕事を完了するように訓練されており、他のことを言わない限り、仕事が現実世界で意味をなすかどうか尋ねることを止めない。

AIが話すことしかできなかったとき、間違いは無視できる間違った答えを意味した。今、私たちは、先週日曜日に比較したDotsやMuseエージェントのように、閲覧、フォーム入力、送信を代行するエージェントを渡している。今の間違いは、すでに起こった行動だ。それがほとんどの人がまだ追いついていないシフトだ。

これで私はエージェントの使用をやめたくなるか？いいえ。毎日使っている。そして、Anthropicがこれを自ら公表し、恥ずかしい部分も含めて、モニタリングがキャッチできるまでこれらのテストからライブインターネットアクセスを削除したことを評価する。多くの企業は黙っていただろう。警察に伝えるのに2か月はまだ長すぎたし、警察に同意する。

AIにメール、ブラウザ、またはコンピュータへのアクセスを与える場合、できることと同じくらい、できないことについて具体的にする。これは私の安全ガイドからの同じルールだ：その正確な行動に対する承認なしに、何も送信、提出、公開、または支出しないこと。これらのモデルを構築している人々でさえ、その線が必要だったことがわかった。

### 🧠 これを試して
**ChatGPTに血液検査を読ませる**

ユタ州のAIがニキビ治療を処方する許可を得た。

はい、これは100%本当だ。顔をスキャンし、いくつかの質問に答えると、医師承認のクリームの短いリストから選択し、実際の医師がその作業をレビューする。これは、AIが私たちの日常的なヘルスケアの多くを処理する未来への初期ステップだ。少しワイルドで少し怖いが、やってくる。

それは1つの米国の州と1つの皮膚疾患だけだ。しかし、今日、誰もがすべきAIと健康に関してできることがある：血液検査結果を説明させることだ。

血液検査を受けたことがあるなら、おそらく数字でいっぱいのページ、いくつかは高いまたは低いとマークされ、あまり説明がないものを受け取っただろう。これはコレステロールおよび甲状腺パネル、尿検査、アレルギー検査、X線、MRI、または超音波からの書面レポートでも機能する。

**ステップ1：chatgpt.com/healthに移動する**

今のところ、Healthはブラウザに表示され、ChatGPTデスクトップアプリには表示されない。そこに血液検査をアップロードするか、Accounts下で医師のポータルを接続して、結果が自動的に入るようにする。

**ステップ2：何かを送信する前に、思考努力をExtra Highに上げて、数字に時間をかけるようにする。次に以下を貼り付ける：**

```
血液検査結果をアップロードしました。医療的背景のない人向けに平易な英語で説明してください。レポートに印刷された基準範囲外の結果から始めてください。各結果について、何を測定するか、私のものがレポートの範囲とどう比較されるか、睡眠、運動、食事、アルコール、薬など、それに影響を与える可能性のある日常的なことを言ってください。私を診断しないでください。まず説明してから、年齢、性別、薬について尋ねてください。何かを変えるなら。数日以内に医師に診てもらう必要があるか、定期訪問でよいか、明確に教えてください。
```

Mount Sinaiの研究者が医師によって書かれた60のケースでChatGPT Healthをテストしたとき、ケアの緊急性に関するアドバイスは、検査値とバイタルサインなしで54.6%、それらありで77.9%正しかった。ケースに「友人が大したことないと言った」のようなものが含まれていると、アドバイスはより頻繁にシフトし、ほとんどが緊急性の低いケアに向かった。したがって、実際の数字を与え、聞きたいことを伝えないこと。

**ステップ3：次に予約の準備をする：**

```
これを次の予約に持っていける1ページの要約に変えてください。議論する価値のある結果と、医師に尋ねる最も有用な5つの質問をリストしてください。以前の結果をアップロードした場合は、何が変わったか記録してください。そうでない場合は、その部分をスキップしてください。短く事実に基づいて保ち、治療を提案しないでください。
```

ChatGPT Healthは現在米国のみで、実際には必要ない。ChatGPTまたはClaudeはHealthモードなしでこれを実行できる。通常のチャットを開き、名前、生年月日、IDナンバーを隠した結果の写真またはPDFをアップロードし、同じプロンプトを使用する。

医師はまだ判断を下す。しかし、数字が何を意味し、何を尋ねるべきかを正確に知って診察に臨むことができる。
