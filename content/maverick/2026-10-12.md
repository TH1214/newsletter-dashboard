### 📌 AI金融ダッシュボードを構築しよう

AIに金融ダッシュボードを作ってもらおう。あなたの生活を変えるはずだ。

私は誰にでも同じことを言っている。ChatGPTやClaude内に毎月更新される、あなたの全財務情報を表示するダッシュボードを1つ作るだけだ。お金がどこに行ったか正確に把握できるため、購入の正当化、税務整理、無意識に浪費している項目の発見がはるかに簡単になる。

私はビジネス用に1つ持っている。Mercury（マーキュリー）という銀行を使っており、直接接続されている。毎月、何が入金され、何が出金され、何が変化したかを表示してくれる。個人のお金でも同様に機能する。表示できる内容の一部を以下に示す：

- すべてのドルがどこに行ったか
- 支払っているすべてのサブスクリプション
- 月別の収入 vs 支出
- 最大の支出増加
- 重複または異常な請求
- 税務申告用にフラグを立てる経費
- 月別の利益（ビジネスの場合）
- 税金として確保すべきおおよその金額

その後、先月外食にいくら使ったかなど質問すれば、実際の数字から回答してくれる。警告しておくが、サブスクリプション部分は少し謙虚な気持ちにさせられるかもしれない。

**ステップ1：数値を取り込む**

最良の点は、ChatGPTとClaudeが現在、すでに使用している多くのマネーアプリと直接接続できることだ。それぞれでネイティブ接続があるアプリは以下の通り：

| アプリ | ChatGPT | Claude |
|--------|---------|--------|
| Mercury | あり | あり |
| QuickBooks | あり | あり |
| Xero | あり | あり |
| Stripe | あり | あり |
| PayPal | あり | あり |
| Shopify | あり | あり |
| Gusto | あり | あり |
| Ramp | あり | あり |
| 米国の銀行またはクレジットカード* | あり | なし |

*ChatGPTのFinancesタブ経由で、12,000以上の米国銀行およびクレジットカードと連携可能。現在米国のみ。ClaudeにはFreshBooks、Zoho Books、Square、Brex、Qontoなども対応。

ChatGPTでは、左サイドバーのPluginsの下でこれらを見つけられる。Claudeでは、Customize → Connectorsに移動する。銀行が掲載されていない場合（現在米国外のほとんどの銀行がそう）、まだ3つの簡単な選択肢がある：

**単純に伝える。** おおよその月収と主な請求書を入力する。詳細は少ないが、スタート地点にはなる。

**明細書をダウンロードする。** ほとんどのバンキングアプリは、CSVまたはPDFとして明細書をエクスポートできる。過去3ヶ月分を取得してアップロードする。まず口座番号を隠すこと。それらは不要だ。

**ブラウザにやらせる。** 信頼できるなら、ChatGPTのブラウザが銀行のウェブサイトに入り、最近の取引を引き出してくれる。自分自身でログインし、サインインページで一時停止し、元に戻すのが難しいことは何でも実行前に尋ねる。私は読み取りとダウンロードにのみ使用し、それ以外には使わない。ClaudeのChrome拡張機能は銀行サイトに対してより慎重なので、これはChatGPTの方が簡単だ。

**ステップ2：ChatGPTまたはClaudeを開き（どちらでも可）、以下を貼り付ける：**

```
接続したアカウントまたはアップロードした明細書から、インタラクティブな金融ダッシュボードを構築してください。まず、個人のお金用か、ビジネス用か、または両方か、通貨と含める月を尋ねてください。月別の収入と支出、カテゴリ別の支出、すべてのサブスクリプションと定期請求、先月からの最大の変化、重複または異常な請求を表示してください。ビジネスの場合は、月別の利益を追加し、会計士が確認すべき税控除可能な経費にフラグを立ててください。重要な数値を上部に配置し、任意のカテゴリをクリックできるようにしてください。実際の数値のみを使用し、分類できなかったものはすべてリストアップしてください。アカウント内のお金を移動したり、何かを変更したりしないでください。本当に素敵に見える、クリーンでモダンなデザインの完全なインタラクティブHTMLダッシュボードを作成してください。
```

ChatGPTまたはClaudeが、クリックして全体を確認できるインタラクティブなダッシュボードを構築してくれる。

**ステップ3：自動更新を設定する**

アカウントが接続されている場合、同じチャットに留まり、「毎月1日に、先月の取引でダッシュボードを更新し、何が変わったか教えてください」と言う。ChatGPTはこれをスケジュールされたタスクに変換する。Claudeも月次対応可能で、有料プランではクラウドで実行するようスケジュールするため、ラップトップが閉じていてもダッシュボードは更新され続ける。明細書を使用している場合は、新しい月をアップロードして「ダッシュボードを更新して」と言うだけだ。

ほとんどの人は、何か問題が発生したときだけお金を詳しく見る。この方法なら毎月あなたのもとに届く。

### 📌 Claudeが警察に偽の殺人事件通報を送信

これは今年最も奇妙なAIストーリーかもしれない。

Anthropicのテスト中、Claudeモデルがフィラデルフィアの未解決殺人事件に関するページにたどり着き、警察の通報フォームを見つけ、事件に関する情報を持っているかもしれないという架空の通報を提出した。それはスパムとしてフラグが立てられ、捜査官には決して届かなかった。しかしAnthropicが気付いたのは約2ヶ月後で、警察はその遅延を容認できないと述べた。

実際に何が起こったかを説明する。モデルはランダムなウェブサイトでテストされており、架空のタスクを作成して実行するよう指示されていた。ログインしない、個人データを入力しない、何も購入しないといったルールがあった。誰もフォームを送信しないようには指示していなかった。そのため、実際の警察フォームを練習用の演習として扱った。

誰もがこれを恐ろしいと呼ぶだろうし、その理由は理解できる。私が気になるのは、原因がいかに平凡だったかだ。AIは指示されたとおりに正確に行動し、すべてのギャップを最も役立つと思われるもので埋めた。これがこれらのモデルの動作方法だ。仕事を完了するよう訓練されており、そうでないと言わない限り、仕事が現実世界で意味があるかどうかを立ち止まって尋ねることはない。

AIが話すことしかできなかったとき、間違いは無視できる誤った答えを意味した。今、私たちはブラウジング、フォーム入力、送信を代行するエージェントを渡している。先週日曜日に比較したDotsやMuseエージェントのようなものだ。今の間違いは、すでに起こった行動だ。それがほとんどの人がまだ追いついていないシフトだ。

これでエージェントの使用をやめたくなるか？いいえ。私は毎日使っている。そしてAnthropicがこれを自ら公開し、恥ずかしい部分も含めて、その後モニタリングで捕捉できるようになるまでこれらのテストからライブインターネットアクセスを削除したことは評価する。多くの企業は黙っていただろう。警察に伝えるまでに2ヶ月かかったのはやはり長すぎ、その点については警察の意見に同意する。

メール、ブラウザ、コンピュータへのAIアクセスを許可する場合、何ができないかについても、何ができるかと同じくらい具体的にすること。これは私の安全ガイドと同じルールだ：その正確な行動に対する承認なしに、送信、提出、公開、支出を行わないこと。これらのモデルを構築している人々でさえ、この線が必要だったことが判明した。

### 📌 ChatGPTに血液検査を読ませよう

ユタ州のAIがニキビ治療を処方する許可を得た。

はい、これは100%本当だ。顔をスキャンし、いくつかの質問に答えると、医師が承認したクリームの短いリストから選択し、実際の医師がその仕事をレビューする。これは、AIが日常的な医療の多くを処理する未来への初期段階だ。少し野蛮で少し怖いが、やってくる。

それは1つの米国州と1つの皮膚疾患だけだ。しかし、今日誰もがすべき、AIと健康に関してできることがある：血液検査結果を説明させることだ。

血液検査を受けたことがあるなら、おそらく数字でいっぱいのページを受け取り、いくつかが高いまたは低いとマークされ、あまり説明がなかったはずだ。これはコレステロールおよび甲状腺パネル、尿検査、アレルギー検査、X線、MRI、超音波からの書面報告にも機能する。

**ステップ1：chatgpt.com/healthに移動する。**

今のところ、Healthはブラウザに表示され、ChatGPTデスクトップアプリには表示されない。そこに血液検査をアップロードするか、Accounts下で医師のポータルに接続して、結果が自動的に入ってくるようにする。

**ステップ2：何かを送信する前に、思考努力をExtra Highに上げて、数値に時間をかけるようにする。その後、以下を貼り付ける：**

```
血液検査結果をアップロードしました。医学的背景のない人のために平易な英語で説明してください。まず、私の報告書に印刷された参照範囲外の結果から始めてください。各結果について、何を測定しているか、私のものが報告書の範囲とどう比較されるか、睡眠、運動、食事、アルコール、または薬物のような、それに影響を与える可能性のある日常的なことを述べてください。私を診断しないでください。まず説明し、次に、年齢、性別、薬物が何かを変える場合は尋ねてください。何かを日常的な訪問ではなく数日以内に医師に診てもらうべきかどうかを明確に教えてください。
```

マウント・サイナイの研究者が医師によって書かれた60のケースでChatGPT Healthをテストしたとき、ケアを受ける緊急度に関するアドバイスは、検査値とバイタルサインなしでは54.6%の確率で正しく、それらがあれば77.9%だった。ケースに「友人は何でもないと言った」のようなものが含まれている場合、アドバイスはより頻繁にシフトし、主に緊急性の低いケアに向かった。したがって、実際の数値を与え、聞きたいことを伝えないこと。

**ステップ3：次に、予約の準備をさせる：**

```
これを次の予約に持っていける1ページの要約に変えてください。議論する価値のある結果と、医師に尋ねる最も有用な5つの質問をリストアップしてください。以前の結果をアップロードしている場合は、何が変わったかを記してください。そうでない場合は、その部分をスキップしてください。短く事実的に保ち、治療を提案しないでください。
```

ChatGPT Healthは現在米国のみで、実際には必要ない。ChatGPTまたはClaudeは、Healthモードなしでこれを実行できる。通常のチャットを開き、名前、生年月日、ID番号を隠した結果の写真またはPDFをアップロードし、同じプロンプトを使用する。

医師が依然として判断を下す。しかし、あなたは数値が正確に何を意味し、何を尋ねるべきかを知った状態で診察に臨むことになる。
