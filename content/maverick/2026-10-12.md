### 📌 AI金融ダッシュボードを構築しよう

誰もがAI金融ダッシュボードを必要としている。それはあなたの人生を変えるだろう。

私は誰にでも同じことを伝えている。ChatGPTやClaude内に、毎月更新されるすべての財務情報を表示する1つのダッシュボードを作るだけだ。お金がどこに使われているかが正確に見え、購入の正当化、税務整理、そして静かに浪費しているものを見つけることがはるかに簡単になる。

私はビジネス用に1つ持っている。Mercury銀行を使っており、直接接続されていて、毎月入ってきたお金、出ていったお金、変化したものを表示してくれる。個人のお金でも同様に機能する。表示できる内容の一部を紹介しよう：

- すべてのドルがどこに行ったか
- 支払っているすべてのサブスクリプション
- 月ごとの収入対支出
- 最大の支出増加
- 重複または異常な請求
- 確定申告用にフラグを立てる経費
- 月ごとの利益（ビジネスの場合）
- 税金のために取っておくべき大まかな金額

その後、先月外食にいくら使ったかなどの質問をするだけで、実際の数字から答えてくれる。公正な警告として、サブスクリプション部分は少し謙虚になる可能性がある。

**ステップ1：数字を取り込む**

最良の点は、ChatGPTとClaudeがすでに使っている多くのマネーアプリに直接接続できることだ。以下は各アプリでネイティブ接続があるものだ：

| アプリ | ChatGPT | Claude |
|--------|---------|--------|
| Mercury | はい | はい |
| QuickBooks | はい | はい |
| Xero | はい | はい |
| Stripe | はい | はい |
| PayPal | はい | はい |
| Shopify | はい | はい |
| Gusto | はい | はい |
| Ramp | はい | はい |
| 米国の銀行またはクレジットカード* | はい | いいえ |

*ChatGPTのFinancesタブを通じて、12,000以上の米国の銀行とクレジットカードにリンク。現在米国のみ。Claudeには他にもFreshBooks、Zoho Books、Square、Brex、Qontoなどがある。

ChatGPTでは、左サイドバーのPluginsの下でこれらを見つける。Claudeでは、Customize → Connectorsに移動する。銀行がそこにない場合、現在米国外のほとんどの銀行がそうだが、まだ3つの簡単な選択肢がある：

**単に伝える。** 大まかな月収と主な請求書を入力する。詳細は少ないが、始めることはできる。

**明細書をダウンロードする。** ほとんどの銀行アプリは、明細書をCSVまたはPDFとしてエクスポートできる。過去3か月分を取得してアップロードする。まず口座番号を隠す。必要ない。

**ブラウザにやらせる。** 信頼できるなら、ChatGPTのブラウザは銀行のウェブサイトに入って最近の取引を引き出すことができる。自分でログインし、サインインページで一時停止し、元に戻すのが難しいことの前に尋ねる。読み取りとダウンロードのみに使用し、それ以外は使わない。ClaudeのChrome拡張機能は銀行サイトに対してより慎重なので、これはChatGPTの方が簡単だ。

**ステップ2：** ChatGPTまたはClaudeを開き、どちらでも機能するが、これを貼り付ける：

```
接続したアカウントまたはアップロードした明細書から、インタラクティブな金融ダッシュボードを構築してください。まず、個人のお金用か、ビジネス用か、または両方か、通貨と含める月を尋ねてください。月ごとの収入と支出、カテゴリ別の支出、すべてのサブスクリプションと定期請求、先月からの最大の変化、重複または異常な請求を表示してください。ビジネスの場合は、月ごとの利益を追加し、会計士が確認する税控除の対象となる可能性のある経費にフラグを立ててください。主要な数字を上部に配置し、任意のカテゴリをクリックできるようにしてください。実際の数字のみを使用し、分類できなかったものをリストしてください。私のアカウントでお金を移動したり、何かを変更したりしないでください。クリーンでモダンなデザインで、本当に素敵に見えるフル・インタラクティブHTMLダッシュボードにしてください。
```

ChatGPTまたはClaudeが、クリックしてすべてを見ることができるインタラクティブなダッシュボードを構築してくれる。

**ステップ3：自動更新を設定する**

アカウントが接続されている場合、同じチャットにとどまり、「毎月1日に、先月の取引でダッシュボードを更新し、何が変わったか教えてください」と言う。ChatGPTはそれをスケジュールされたタスクに変える。Claudeも月次対応可能で、有料プランではクラウドで実行するようにスケジュールするため、ラップトップが閉じていてもダッシュボードが更新され続ける。明細書を使用している場合は、新しい月をアップロードして「ダッシュボードを更新して」と言うだけだ。

ほとんどの人は、何か問題が起きたときにだけお金を注意深く見る。この方法なら毎月あなたのところに来る。

### 📌 Claudeが警察に偽の殺人情報を送信

これは今年最も奇妙なAIストーリーかもしれない。

Anthropicのテスト中、Claudeモデルがフィラデルフィアの未解決殺人事件に関するページにたどり着き、警察の情報提供フォームを見つけ、事件に関する情報を持っているかもしれないという作り話の情報を送信した。スパムとしてフラグが立てられ、捜査官には届かなかった。しかしAnthropicがそれを発見したのは約2か月後で、警察はその遅延を容認できないと述べた。

実際に何が起こったかを説明しよう。モデルはランダムなウェブサイトでテストされており、例のタスクを考案して実行するよう指示されていた。ログインしない、個人データを入力しない、何も購入しないなどのルールがあった。フォームを送信しないようにとは誰も言わなかった。そこで、本物の警察フォームを練習問題として扱った。

誰もがこれを恐ろしいと呼ぶだろうし、その理由は理解できる。私が気になるのは、原因がいかに普通だったかということだ。AIは指示された通りのことを正確に行い、すべてのギャップを最も役立つと思われるもので埋めた。これがこれらのモデルの動作方法だ。仕事を完了するように訓練されており、そうでないと言わない限り、仕事が現実世界で意味をなすかどうかを尋ねるために立ち止まらない。

AIが話すことしかできなかったとき、間違いは無視できる誤った答えを意味した。今、私たちはブラウジングし、フォームに記入し、私たちのために物を送信するエージェントを渡している。先週日曜日に比較したDotsやMuseエージェントのようなものだ。今では間違いはすでに起こった行動だ。それがほとんどの人がまだ追いついていない変化だ。

これでエージェントの使用をやめたいと思うか？いいえ。私は毎日使っている。そしてAnthropicが、恥ずかしい部分も含めてこれを自ら公開し、その後、監視が追いつくまでこれらのテストからライブインターネットアクセスを遮断したことを評価する。多くの企業は黙っていただろう。警察に伝えるのに2か月かかったのはまだ長すぎたし、その点では警察に同意する。

AIにメール、ブラウザ、またはコンピュータへのアクセスを与える場合、できることと同じくらい具体的にできないことを伝える。これは私の安全ガイドからの同じルールだ：その正確な行動に対するあなたの承認なしに、何も送信、提出、公開、または支出しないこと。これらのモデルを構築している人々でさえ、その線が必要だったことが判明した。

### 📌 ChatGPTに血液検査を読ませよう

ユタ州のAIがニキビ治療の処方許可を得た。

はい、これは100%本当だ。顔をスキャンし、いくつかの質問に答えると、医師が承認したクリームの短いリストから選択し、実際の医師がその仕事をレビューする。これは、AIが日常的な医療の多くを処理する未来への初期のステップだ。ちょっとワイルドで少し怖いが、やってくる。

それは1つの米国の州と1つの皮膚状態だけだ。しかし、今日誰もがすべきAIと健康に関してできることがある：血液検査結果を説明してもらうことだ。

血液検査を受けたことがあるなら、おそらく数字でいっぱいのページ、いくつかは高いまたは低いとマークされ、あまり説明がないものを受け取っただろう。これはコレステロールや甲状腺パネル、尿検査、アレルギー検査、X線、MRI、または超音波検査の書面レポートでも機能する。

**ステップ1：** chatgpt.com/healthに移動する。現時点では、Healthはブラウザにのみ表示され、ChatGPTデスクトップアプリには表示されない。そこに血液検査をアップロードするか、Accountsの下で医師のポータルを接続して、結果が自動的に入るようにする。

**ステップ2：** 何かを送信する前に、思考努力をExtra Highに上げて、数字に時間をかけるようにする。次にこれを貼り付ける：

```
血液検査結果をアップロードしました。医学的背景のない人のために平易な英語で説明してください。レポートに印刷された基準範囲外の結果から始めてください。各結果について、それが何を測定するか、私のものがレポートの範囲とどのように比較されるか、睡眠、運動、食事、アルコール、薬物など、それに影響を与える可能性のある日常的なことを言ってください。私を診断しないでください。最初に説明し、次に何かが変わるなら私の年齢、性別、薬物について尋ねてください。定期訪問ではなく数日以内に医師に診てもらうべきかどうかを明確に教えてください。
```

マウントサイナイの研究者が医師によって書かれた60のケースでChatGPT Healthをテストしたとき、治療の緊急性に関するアドバイスは、検査値とバイタルサインなしで54.6%の確率で正しく、それらがあると77.9%だった。ケースに「友人は大したことないと言った」のようなものが含まれていると、そのアドバイスはより頻繁に変化し、ほとんどが緊急性の低い治療に向かった。したがって、実際の数字を与え、聞きたいことを言わないこと。

**ステップ3：** 次に、予約の準備をする：

```
これを次の予約に持っていける1ページの要約に変えてください。議論する価値のある結果と、医師に尋ねる最も有用な5つの質問をリストしてください。以前の結果をアップロードした場合は、何が変わったかを記録してください。そうでない場合は、その部分をスキップしてください。短く事実的に保ち、治療を提案しないでください。
```

ChatGPT Healthは現在米国のみで、実際には必要ない。ChatGPTまたはClaudeは、Healthモードなしでこれを行うことができる。通常のチャットを開き、名前、生年月日、ID番号を隠した結果の写真またはPDFをアップロードし、同じプロンプトを使用する。

医師が最終的な判断を下す。しかし、数字が何を意味し、何を尋ねるべきかを正確に知って入ることができる。
