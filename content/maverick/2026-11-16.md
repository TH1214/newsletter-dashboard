### 📌 ChatGPTでビジネスを申請できるようになった

ChatGPT内で直接ビジネスを申請し、より多くの顧客を獲得できるようになりました。しかも今なら完全無料です。

毎週12億人がChatGPTを利用しており、その多くが購入先や依頼先を尋ねています。これまでChatGPTはオンライン上で見つけた情報を寄せ集めていましたが、OpenAIが「Businesses in ChatGPT」を立ち上げ、ビジネスオーナー自身が詳細情報、商品、価格、在庫状況などすべてを入力できるようになりました。

**設定方法（パソコンで実行）：**

**ステップ1：** chatgpt.com/business-hub にアクセスし、サインインして「Search business」に会社名を入力し、リストをクリックします。オンライン販売をしていて表示されない場合は、上部の会社名付き「Create」オプションをクリックします（現時点では、実店舗やレストランは米国内の既存リストのみ申請可能）。

**ステップ2：** ビジネス用電話番号、ビジネスメール、ウェブサイトのドメイン、またはShopifyストアで本人確認を行います。簡単な身分確認もあり、承認されるとプロフィールに青いチェックマークが表示されます。

**ステップ3：** 詳細情報、営業時間、写真、商品（価格と在庫付き）をすべて入力します。Shopifyストアをお持ちの場合は、接続するだけで商品が自動的に取り込まれます。

開始前に、以下を新しいチャットに貼り付けると、ChatGPTがプロフィール全体を作成してくれます：

```
私はChatGPTのビジネスハブでビジネスを申請しており、プロフィールを完全かつ正確にしたいと考えています。販売内容、顧客層、営業時間、配送・返品ポリシー、価格付きのベスト商品、顧客からよく聞かれる質問について、一度に1つずつ質問してください。その後、それぞれの見出しの下に貼り付けるべき内容をすべて書いてください。私が伝えた内容のみを使用してください。
```

設定が完了すると、ChatGPTがあなたのビジネスに言及した回数、ウェブサイトへのクリック数、ユーザーがどのような質問をしていた時にあなたを見つけたかを確認できます。実際のチャット内容は表示されず、集計のみが表示されます。

さらに驚くべきことに、**ビジネスエージェント**をオンにできます。誰かがChatGPTであなたを見つけた時、あなたの商品とポリシーを使って質問に答えるAI版のビジネスとチャットでき、いつでも購入のためにウェブサイトへ誘導されます。現時点では、エージェントは米国内のオンラインストアとオンラインサービスのみが対象です。

私たちは2003年のGoogle時代に再び立ち戻っていると本当に思います。Google初期に登場したビジネスは何年も勝ち続けました。同じことがChatGPT内で起ころうとしていると考えています。

もし誰かにこれらすべてを代行してもらいたい場合は、いつもCytdを紹介しています。以前も言及したことがあるかもしれません。私はツールとチームを本当に信じているため投資しました。Cytdは、ChatGPT、Claude、Gemini、Perplexityで人々が質問した時にビジネスをランク付けする代行サービスで、現在はChatGPT内でのプロフィール申請と管理も代行してくれるため、より多くの顧客を獲得できます。

このニュースレター読者限定で初月無料の特別契約を結びました（ビジネスオーナーなら自分で作業する必要がないため、文字通りノーブレイナーです）。

### 📌 本を数分で読めるノートに変える4つの秘密ChatGPTコード

どんな本も数分で読めるノートに変える4つの秘密ChatGPTコードを紹介します。読み終えていないビジネス書、英語の授業用の小説、木曜日締め切りの読書会の本。これら4つですべてカバーできます。

まず、ChatGPTに本を渡します。メッセージボックスの+をクリックしてPDFを添付するか、章を貼り付けます。有名な本ならタイトルを入力するだけでも機能しますが、ChatGPTは記憶から引き出すため、実際の本を使う方がはるかに良い結果が得られます。次に最初のコードを入力し、同じチャット内にいる限り、その後のすべてのコードが同じ本に対して機能します。

**1. /visualnotes**

```
/visualnotes
```

ChatGPTが本全体を数分でスキャンできる短い視覚的ノートに変換します。大きなアイデアごとに1ブロック、見出し、アイコン、シンプルな図付きです。

**2. /mentalmodels**

```
/mentalmodels
```

本の最大のアイデアを抽出し、それらがどのように繋がっているかの視覚的マップに変換します。

**3. /chaptermap**

```
/chaptermap
```

章ごとに本を分解し、各章の要点と他のすべてとの関連性を示します。

**4. /themes**

```
/themes
```

本全体を通じて展開されるすべての主要テーマを見つけ、登場人物や出来事と結びつけるため、実際に深い意味を理解できます。これは英語の授業の文字通りのチートコードです。

**その他のお気に入り：**

+ `/actionsteps` 本を今週実行すべきことに変換
+ `/quizme` 一度に1つずつクイズを出題
+ `/asktheauthor` 著者のように回答
+ `/kidsversion` 子供の年齢向けに再話

ヒント：本が非常に長く、回答が曖昧になり始めたら、一度に1章ずつ渡してください。私の40個の本コードすべてを毎回同じように機能させるには、ガイドにすべてのコードを一度に教える1つのセットアッププロンプトがあります。

### 📌 MetaのMuseを使う3つのクールな方法

Muse（Meta製のAIエージェントで、専用アプリ、muse.ai、WhatsApp内で利用可能）についてよく質問されます。素晴らしいツールだと思います。個人的にはChatGPTのDotsを常時稼働のパーソナルアシスタントとして使用していますが、Instagramと密接に連携したアシスタントが欲しい場合、Museは素晴らしい選択肢です。Instagram、Facebookページ、Metaのビジネスツールに直接接続されるため、これらのアプリで活動しているコンテンツクリエイターや中小企業にとって非常に優れています。しかも無料で始められます。

Facebookマーケットプレイスにも組み込まれているため、何かを売ろうとしている場合は、これを使いたいでしょう。リストを書き、購入者にメッセージを送信してくれます。引き継がせる前に、共有を許可されている内容を確認してください。

実際に人々が使用している3つのクールな方法を紹介します。

**1. Instagram保存投稿をすべて整理**

何百もの投稿を保存したまま二度と見ない場合、これはあなた向けです。X（旧Twitter）のあるユーザーは、Museに保存した投稿すべてをフォルダに整理するよう依頼し、1,300以上の投稿が分類されました。Instagram自身もこれについて投稿しています。

```
Instagramで保存したすべての投稿をトピック別にコレクションに分類してください。各コレクションに明確な名前を付け、何が含まれているか教えてください。
```

**2. 自動車保険料を削減**

これが最もクレイジーです。ニューヨークの創業者で3児の父であるJoe Devoyは、自動車保険証書をMuseにアップロードし、全く同じ補償内容でより良い料金を求めました。約5分で、年間3,500ドル節約できる保険を見つけ、購入し、古い保険をキャンセルしました。彼のX投稿は60万回以上閲覧されました。

```
これが私の自動車保険証書です。全く同じ補償内容でより良い料金を見つけてください。オプションを見せて、何かを購入する前に私に聞いてください。
```

**3. 保存したリールを実際のプランに変換**

レシピを保存するのは簡単ですが、実際に作るのが難しい部分です。Meta自身の例は、保存したレシピリールを買い物リストに変換することです。旅行用に保存したレストランやスポットでも同じことができるため、保存が実際に行うことに変わります。

```
Instagramで保存した[レシピ/レストラン/場所]を見て、[今週の買い物リスト/私の街での完璧な1日のプラン]に変換してください。
```

常にコントロールできます。Museは新しいものを送信または購入する前に尋ねるため、最終決定権はあなたにあります。

さらに深く知りたい場合は、設定方法と最適な使用方法を説明する完全なMuseガイドがあります。
