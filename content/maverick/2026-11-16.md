### 📌 ChatGPTにビジネスを登録できるようになりました

ChatGPT内で直接ビジネスを登録できるようになり、より多くの顧客を獲得できます。しかも現在は完全無料です。

毎週12億人がChatGPTを使用しており、その多くが購入先や雇用先を尋ねています。これまでChatGPTは、オンラインで見つけた情報を寄せ集めていました。OpenAIは「Businesses in ChatGPT」を立ち上げ、今では自分で全てを伝えることができます：詳細、商品、価格、在庫状況など。

以下、設定方法です。パソコンで実施してください。

**ステップ1:** chatgpt.com/business-hub にアクセスし、サインインして「Search business」にビジネス名を入力し、リスティングをクリックします。オンライン販売をしていて表示されない場合は、上部の「Create」オプションをクリックします。（実店舗やレストランは現時点で米国内の既存リスティングのみ登録可能）

**ステップ2:** ビジネス電話番号、ビジネスメール、ウェブサイトのドメイン、またはShopifyストアで本人確認を行います。簡単な身分確認もあり、承認されるとプロフィールに青いチェックマークが表示されます。

**ステップ3:** 詳細、営業時間、写真、さらに価格と在庫付きの商品を全て入力します。Shopifyストアをお持ちの場合は、接続するだけで商品が自動的に取り込まれます。

開始する前に、以下を新しいチャットに貼り付けると、ChatGPTがプロフィール全体を作成してくれます：

```
私はChatGPTのBusiness Hubでビジネスを登録しようとしており、プロフィールを完全かつ正確にしたいと考えています。販売内容、顧客層、営業時間、配送・返品ポリシー、価格付きのベスト商品、顧客からよく聞かれる質問について、一度に1つずつ質問してください。その後、それぞれの見出しの下に貼り付けるべき内容を全て書いてください。私が伝えたことだけを使用してください。
```

設定が完了すると、ChatGPTがあなたのビジネスに言及した回数、ウェブサイトへのクリック数、見つけられた際に何を尋ねていたかを確認できます。実際のチャット内容は表示されず、集計のみが表示されます。

そして最も驚くべき点は、独自のビジネスエージェントをオンにできることです。誰かがChatGPT内であなたを見つけると、あなたの商品とポリシーを使って質問に答えるAI版ビジネスとチャットでき、時間を問わず、その後購入のためにウェブサイトに誘導します。現時点では、エージェントは米国内のオンラインストアとオンラインサービスのみが対象です。

私たちは2003年のGoogle時代を再び迎えていると本当に思います。Google初期に登場したビジネスは何年も勝ち続け、同じことがChatGPT内でも起きようとしていると考えています。

これを全て代行してもらいたい場合は、いつもCytdを紹介しています。以前聞いたことがあるかもしれません。私はツールとチームを本当に信じているため投資しました。彼らは、ChatGPT、Claude、Gemini、Perplexityで人々が尋ねた際にビジネスをランク付けする代行サービスであり、現在はChatGPT内でプロフィールを直接登録し管理してくれるため、より多くの顧客を獲得し始められます。

私は彼らと交渉し、このニュースレターの読者のみが初月無料になるようにしました（ビジネスオーナーなら文字通りノーブレイナーです、自分で作業する必要がないので）。

### 📌 あらゆる本に使える4つのChatGPT秘密コード

ここでは、あらゆる本を数分で読めるノートに変換する4つの秘密ChatGPTコードを紹介します。読み終わらなかったビジネス書、英語の授業用の小説、木曜日締切のブッククラブ選書など、これら4つで全てカバーできます。

まず、ChatGPTに本を渡します。メッセージボックスの+をクリックしてPDFを添付するか、章を貼り付けます。有名な本ならタイトルを入力するだけでも機能しますが、その場合ChatGPTは記憶に頼るため、実際の本を使うとはるかに良い結果が得られます。次に最初のコードを入力し、その後の各コードは同じチャット内にいる限り同じ本に機能します。

**1. /visualnotes**

```
/visualnotes
```

ChatGPTは本全体を数分でスキャンできる短いビジュアルノートに変換し、大きなアイデアごとに1ブロック、見出し、アイコン、シンプルな図を付けます。

**2. /mentalmodels**

```
/mentalmodels
```

本の最大のアイデアを抽出し、それらがどのように繋がっているかのビジュアルマップに変換します。

**3. /chaptermap**

```
/chaptermap
```

本を章ごとに分解し、各章の要点と他の全てとの関連性を示します。

**4. /themes**

```
/themes
```

本全体を通じて展開されるすべての主要テーマを見つけ、登場人物や出来事と結びつけるため、実際により深い意味を理解できます。これは英語の授業の文字通りのチートコードです。

他のお気に入りもいくつか紹介します：

+ `/actionsteps` 本を今週実行すべきことに変換
+ `/quizme` 一度に1問ずつクイズ
+ `/asktheauthor` 著者のように回答
+ `/kidsversion` 子供の年齢向けに再話

ヒント：本が非常に長く、回答が曖昧になり始めた場合は、一度に1章ずつ渡してください。私の40個の書籍コード全てを毎回同じように機能させるため、ガイドには全てのコードを一度に教えるセットアッププロンプトがあります。

### 📌 MetaのMuseを使う3つのクールな方法

Museについてよく質問されます。Metaの独自アプリ、muse.ai、そしてWhatsApp内に存在するAIエージェントです。素晴らしいツールだと思います。私は個人的にChatGPTのDotsを常時稼働のパーソナルアシスタントとして使用していますが、Instagramと密接に連携したアシスタントが欲しい場合、Museは素晴らしい選択肢です。Instagram、Facebookページ、Metaのビジネスツールに直接接続されるため、これらのアプリで既に活動しているコンテンツクリエイターや中小企業にとって非常に優れています。そして開始は無料です。

Facebook Marketplaceにも組み込まれているため、何かを販売しようとしている場合は、これを使いたいところです。リスティングを書き、買い手にメッセージを送ることができます。引き継ぐ前に、共有が許可されている内容を確認してください。

人々が実際に使っている3つのクールな方法を紹介します。

**1. Instagram保存を整理する**

再び見ることのない何百もの投稿を保存している場合、これはあなた向けです。X上のある人がMuseに保存した全投稿を整理するよう指示したところ、1,300以上の投稿が分類されました。Instagram自身もこれについて投稿しています。

```
Instagramで保存した全投稿をトピックごとにコレクションに分類してください。各コレクションに明確な名前を付け、何が含まれているか教えてください。
```

**2. 自動車保険料を削減する**

これが最も驚くべきものです。ニューヨークの創業者で3児の父であるJoe Devoyは、自動車保険証書をMuseにアップロードし、全く同じ補償でより良い料金を求めました。約5分で、年間3,500ドル節約できる保険を見つけ、購入し、古い保険をキャンセルしました。X上の彼の投稿は60万回以上の閲覧を記録しました。

```
これが私の自動車保険証書です。全く同じ補償でより良い料金を見つけてください。オプションを見せて、何かを購入する前に私に尋ねてください。
```

**3. 保存したリールを実際のプランに変換する**

レシピを保存するのは簡単です。実際に作るのが難しい部分です。Meta自身の例は、保存したレシピリールを食料品リストに変換することです。旅行のために保存したすべてのレストランやスポットでも同じことができるため、保存したものが実際に実行するものに変わります。

```
Instagramで保存した[レシピ/レストラン/場所]を見て、[今週の食料品リスト/私の街での完璧な1日のプラン]に変換してください。
```

そして、常にコントロールを保持できます。Museは新しいものを送信または購入する前に尋ねるため、最終決定権は依然としてあなたにあります。

より深く知りたい場合は、設定方法と最適な使用方法を説明する完全なMuseガイドがあります。
