### 📌 今日やるべきこと

**ChatGPTであなたのビジネスを登録しよう**

ChatGPT内で直接ビジネスを登録できるようになり、はるかに多くの顧客を獲得できます。そして今なら完全無料です。

毎週12億人がChatGPTを使用しており、その多くが「どこで買えばいいか」「誰を雇えばいいか」をChatGPTに尋ねています。これまでChatGPTはオンラインで見つけた情報を寄せ集めていましたが、OpenAIが「Businesses in ChatGPT」を立ち上げ、今では自分ですべてを伝えられるようになりました。詳細、商品、価格、在庫状況など、すべてです。

以下が設定方法です。パソコンで行ってください。

**ステップ1:** chatgpt.com/business-hub にアクセスし、サインインして「Search business」にビジネス名を入力し、自分のリストをクリックします。オンライン販売をしていて表示されない場合は、上部にある自分のビジネス名で「Create」オプションをクリックします。（地元の店舗やレストランは、現時点では既存の米国リストのみ登録可能です。）

**ステップ2:** ビジネス電話、ビジネスメール、ウェブサイトのドメイン、またはShopifyストアで本人確認します。簡単なID確認もあり、承認されるとプロフィールに青いチェックマークが表示されます。

**ステップ3:** すべてを入力します。詳細、営業時間、写真、そして価格と在庫を含む商品情報です。Shopifyストアがあれば、接続するだけで商品が自動的に取り込まれます。

始める前に、以下を新しいチャットに貼り付けて、ChatGPTにプロフィール全体を書いてもらいましょう。

```
私はChatGPTのBusiness Hubでビジネスを登録しようとしており、プロフィールを完全かつ正確にしたいと考えています。私が何を販売しているか、顧客は誰か、営業時間、配送と返品ポリシー、価格付きのベスト商品、顧客から最もよく聞かれる質問について、一度に1つずつ質問してください。その後、それぞれの見出しの下に貼り付ける必要があるすべてを書いてください。私が伝えたことだけを使用してください。
```

設定が完了すると、ChatGPTがあなたを言及した回数、何人があなたのウェブサイトをクリックしたか、彼らがあなたを見つけたときに何を尋ねていたかを確認できます。実際のチャットは表示されず、合計数のみです。

そして最も驚くべき部分がこれです。独自のBusiness Agentをオンにできます。誰かがChatGPTであなたを見つけると、あなたのビジネスのAIバージョンとチャットでき、あなたの商品やポリシーを使って質問に答え、いつでも対応し、その後購入のためにウェブサイトに誘導します。現時点では、エージェントは米国内のオンラインストアとオンラインサービスのみが対象です。

私たちは2003年のGoogle時代を再び迎えていると本当に思います。Googleに早期に登場したビジネスは何年も勝ち続けました。同じことがChatGPT内で起こりつつあると思います。

そして、これをすべて代行してもらいたい場合、私はいつもCytdを紹介しています。以前も言及したことがあるかもしれません。私は彼らに投資しました。なぜなら、ツールとその背後にいるチームを本当に信じているからです。彼らは、ChatGPT、Claude、Gemini、Perplexityで人々が尋ねたときにあなたのビジネスがランク付けされるようにする代行サービスで、現在はChatGPT内で直接プロフィールを登録し、管理を代行してくれるので、はるかに多くの顧客を獲得し始めることができます。

そして、このニュースレターの読者だけが初月無料になる取引をまとめました（ビジネスオーナーなら文字通りノーブレイナーです。自分で作業する必要がないので）。

### 📌 これを試してみよう

**あらゆる本を数分で理解できる4つの秘密ChatGPTコード**

以下は、あらゆる本を数分で読めるノートに変える4つの秘密ChatGPTコードです。読み終わらなかったビジネス書、英語の授業用の小説、木曜日が期限のブッククラブの本。これら4つがすべてカバーします。

まず、ChatGPTに本を渡します。メッセージボックスの+をクリックしてPDFを添付するか、章を貼り付けます。有名な本ならタイトルを入力するだけでも機能しますが、ChatGPTは記憶に頼るので、実際の本を使う方がはるかに良い結果が得られます。次に最初のコードを入力し、同じチャット内にいる限り、その後のすべてのコードは同じ本に対して機能します。

**1. /visualnotes**

```
/visualnotes
```

ChatGPTは本全体を、数分でスキャンできる短いビジュアルノートに変換します。大きなアイデアごとに1ブロック、見出し、アイコン、シンプルな図付きです。

**2. /mentalmodels**

```
/mentalmodels
```

本の最大のアイデアを引き出し、それらがすべてどのように繋がっているかのビジュアルマップに変換します。

**3. /chaptermap**

```
/chaptermap
```

本を章ごとに分解し、それぞれの重要なポイントと他のすべてとの関連性を示します。

**4. /themes**

```
/themes
```

本全体を通じて展開されるすべての主要なテーマを見つけ、登場人物や出来事と結びつけるので、より深い意味を実際に理解できます。これは英語の授業の文字通りのチートコードです。

そして、私のお気に入りをいくつか追加します。

+ /actionsteps は本を今週やるべきことに変換
+ /quizme は一度に1つずつ質問でクイズ
+ /asktheauthor は著者のように答える
+ /kidsversion は子供の年齢に合わせて再話

1つのヒント: 本が本当に長く、答えが曖昧になり始めたら、一度に1章ずつ渡してください。そして、私の40個の本コードすべてが毎回まったく同じように機能するように、私のガイドには、ChatGPTにすべてのコードを一度に教える1つのセットアッププロンプトがあります。

### 📌 これを保存しよう

**人々がMetaのMuseを使っている3つのクールな方法**

Museについてよく聞かれます。Metaのこのエージェントは、独自のアプリ、muse.ai、そしてWhatsApp内で動作します。優れたツールだと思います。個人的には、常時オンのパーソナルアシスタントとしてChatGPTのDotsを使っていますが、Instagramとしっかりつながったアシスタントが欲しい場合、Museは素晴らしい選択肢です。Instagram、Facebookページ、Metaのビジネスツールに直接接続されるので、すでにそれらのアプリで生活しているコンテンツクリエイターや中小企業に本当に適しています。そして、スタートは無料です。

Facebook Marketplaceにも組み込まれているので、物を売ろうとしている場合は、これを使いたいものです。リストを書いたり、買い手にメッセージを送ったりできます。引き継ぐ前に、何を共有できるかを確認してください。

以下は、人々が実際に使っている最もクールな3つの方法です。

**1. Instagramの保存をすべて整理する**
何百もの投稿を保存したまま二度と見ない場合、これはあなたのためのものです。Xのある人がMuseに、これまで保存したすべての投稿をフォルダに整理するよう伝えたところ、1,300以上の投稿が分類されました。Instagram自身もこれについて投稿しました。

```
Instagramで保存したすべての投稿を見て、トピックごとにコレクションに分類してください。各コレクションに明確な名前を付けて、何が入っているか教えてください。
```

**2. 自動車保険料を削減する**
これが最も驚くべきものです。ニューヨークの創業者で3児の父であるJoe Devoyは、自動車保険証券をMuseにアップロードし、まったく同じ補償範囲でより良い料金を求めました。約5分で、年間3,500ドル節約できる保険を見つけ、購入し、古い保険をキャンセルしました。彼のXへの投稿は60万回以上の閲覧数を獲得しました。

```
これが私の自動車保険証券です。まったく同じ補償範囲でより良い料金を見つけてください。オプションを見せて、何かを購入する前に私に聞いてください。
```

**3. 保存したリールを実際の計画に変える**
レシピを保存するのは簡単です。実際に作るのが難しい部分です。Meta自身の例は、保存したレシピリールを買い物リストに変えることです。旅行のために保存したすべてのレストランやスポットで同じことができるので、保存したものが最終的に実際に行うことに変わります。

```
Instagramで保存した[レシピ/レストラン/場所]を見て、[今週の買い物リスト/私の街での完璧な1日の計画]に変えてください。
```

そして、あなたは常にコントロールを維持します。Museは新しいものを送信または購入する前にあなたに尋ねるので、最終的な決定権はあなたにあります。
