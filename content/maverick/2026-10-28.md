### 📌 写真を修正する5つの秘密ChatGPTコード

ChatGPTに写真をアップロードし、`/identity-lock`と入力すると、顔の特徴を一切変えずに写真全体を修正できる。

これらのコードが支持される理由は、AI写真編集における最大の問題を解決するからだ。写真を良くしてと頼むと、いとこのような別人が返ってくる。同じ雰囲気だが、鼻が違う。以下の5つのコードは写真を修正しながら、あなた自身の見た目を保つ。AdobeやCanvaにとって、これは厳しい展開だ。

**1. /identity-lock** — 編集時にこれを追加すると、ChatGPTはあなたを完全に同じに保ちながら、周囲のすべてを変更する。同じ顔、同じ髪、同じ服装、同じ照明。変わるのは背景だけ。見知らぬ人の顔にならずに、より良い設定にしたいときに使用する。

**2. /studio-quality** — 照明とシャープネスを改善し、スマートフォンで撮った写真をプロカメラマンが撮影したように見せる。

**3. /upscale** — 鮮明さと解像度を向上させる。古いぼやけた写真や、印刷したい写真に最適。

**4. /clean-up** — 散らかった背景、ランダムな人物、椅子の上の洗濯物などを削除し、画像全体をクリーンに見せる。

**5. /pose-only** — 顔に触れずにポーズだけを変更する。すべて完璧なのに、立ち方だけが少し変な写真に最適。

使い方は以下の通り。ChatGPTを開き、写真を添付してコードを入力するだけ。「/clean-up, keep the dog（犬は残して）」のように、具体的な要望があれば数語追加できる。そして最良の点は、これらを重ねて使えること。最初に`/clean-up`を実行し、その結果に`/studio-quality`を適用すれば、実際に投稿したくなる写真が完成する。

ヒント：各写真ごとに新しいチャットを開始すること。そうすることで、ChatGPTが前回の編集を次の編集に混ぜ込まない。

### 📌 ClaudeがModsをリリース：自分専用のClaudeを構築

ClaudeがModsをリリースし、会話するだけで自分専用のClaudeを構築できるようになった。

毎日Claudeに尋ねることを考えてみよう。「今どこまで進んでいるか要約して」「まだ未完了のものは何？」「これをチェックして間違いを探して」。Modsを使えば、これらのプロンプトをチャットの真上に配置される実際のボタンに変換でき、二度と入力する必要がなくなる。コードを書く必要はない。欲しいものを説明すれば、Claudeが構築し、オンにできる。

ModsはClaude Codeで動作するため、有料のClaudeプランとClaudeデスクトップアプリが必要（ウェブ上の通常のClaudeチャットでは機能しない）。

**ステップ1：** Claudeデスクトップアプリを開き、Codeを選択し、作業中のプロジェクトまたはフォルダを開く。

**ステップ2：** 以下を貼り付ける：

```
Build me a mod with three buttons above the chat. One to summarize this project, one to list unfinished tasks, and one to check the latest draft for mistakes. Have each button send that instruction into the conversation.
（チャットの上に3つのボタンを持つmodを作って。1つはこのプロジェクトを要約、1つは未完了タスクのリスト、1つは最新のドラフトのミスチェック。各ボタンはその指示を会話に送信するようにして）
```

**ステップ3：** Claudeがファイルの承認を求めたら承認する。作成したmodをオンにするか尋ねられたら「Turn them on」をクリックし、返信が終わると3つのボタンがチャットの上に表示される。

ここからがコツだ。さらに構築を続けられる。同じチャットで以下を貼り付ける：

```
Add a panel next to the chat that shows every file you changed and lets me compare it before and after.
（チャットの横に、変更したすべてのファイルを表示し、変更前後を比較できるパネルを追加して）
```

これにより、Claudeがウェブサイト、メモ、ドキュメントを更新したとき、次に進む前に正確に何をしたかを実際に確認できる。異なるボタンやレイアウトが欲しい？Claudeに何を変更したいか伝えるだけ。

注意点：modは構築したチャットでのみ読み込まれる。Claude Codeを開くたびに使いたい場合は、Claudeにプラグインとして保存するよう依頼すれば、手順を案内してくれる。

どんなボタンを使うか分からない？Claudeに一緒に考えてもらう：

```
Interview me about how I use Claude Code so you can suggest mods that would save me the most time. Ask me one question at a time about what I work on, the prompts I type over and over and what slows me down. When you're done, suggest 5 mods, explain each one in one sentence, and build the one you think I'll use most.
（Claude Codeの使い方についてインタビューして、最も時間を節約できるmodを提案して。何に取り組んでいるか、何度も入力するプロンプト、何が遅くしているかについて、一度に1つずつ質問して。終わったら5つのmodを提案し、それぞれを1文で説明して、最も使うと思うものを構築して）
```

### 📌 Anthropicが上場へ、ほぼ黒字化

Claudeの背後にある企業Anthropicが正式に上場を申請した。NasdaqでティッカーシンボルANTで取引される予定。株価と日付はまだ決定していないが、報道によると時価総額は1.4〜2兆ドルのどこかで、早ければ11月中旬の上場とされている。

これは今年のAIにおける最大級の出来事の1つになると考えている。これまで、Claudeを作る企業の株を所有できるのは大口投資家とテクノロジー大手だけだった。間もなく、証券アプリを持つ誰もが所有できるようになる。

申請書の成長は驚異的だ。Anthropicは2023年に4,100万ドル、2024年に3億8,600万ドル、2025年に46億ドルを稼いだ。そして今年の最初の6か月間だけで163億ドルを稼いだ。Claudeに年間最低10万ドルを支出する企業は、1年で約950社から1万1,900社以上に増加し、現在Fortune 500の半分以上を含む。1,900社以上がAnthropicに年間100万ドル以上を支払い、約250社が1,000万ドル以上を支払っている。約5,300人の従業員で、1人あたり年間660万ドル以上の収益を生み出しており、わずか1年前の140万ドルから増加している。

先週水曜日に話した800億ドルの損失を覚えているだろうか？正式な申請書が出た今、それが正確に何だったかが分かる。そのうち724億ドルは、私が言及した会計上の費用で、Anthropicの価値が大幅に上昇したため、古い投資家向け社債が紙上でずっと価値が高くなったことによるものだ。これは建物から出ていったお金ではない。

実際のビジネスが何をしたかを見てみよう。Anthropicの実際の営業損失は、この6か月間で163億ドルの収益に対して6億9,300万ドルだった。これは稼いだ1ドルごとに約4セント失った計算で、1年前の12億ドルの収益に対する21億ドルの損失から減少している。そして従業員に支払う株式を除けば、実際には16億ドルを稼いだ。これだけのコンピューティングパワーに支出している企業にとって、これはほぼ黒字であり、見出しが示すようなものではない。

他にも興味深い点がいくつかあった：

**創業者は大部分を寄付する。** Anthropicの共同創業者は、個人が保有するAnthropicの株式の80%をそれぞれ慈善団体に寄付することを約束している。また、株価が50%上昇するたびに、善意の目的のために最大2%の追加株式を受け取るファンドもある。

**創業者が支配権を維持。** 誰でも株を買えるようになった後でも、共同創業者は50.1%の議決権を保持するため、ウォール街が単に乗っ取ってClaudeを変えることはできない。

私の見解を述べる。先週、Google、Amazon、Microsoftは、Anthropicの資金の多くが彼らに流れるため、どうあってもこのレースに勝つと言った。これは今も真実だ。しかし、この申請書はAnthropicが単に金を投げ捨てている企業ではないことを示している。数千の企業が莫大な金額を支払っている本物のソフトウェアを構築しており、それは成長し続けている。より多くの資金はより多いコンピューティングパワーを意味し、より多いコンピューティングパワーはあなたのためのより良いClaudeを意味する。株を買えとは言わない（私はファイナンシャルアドバイザーではない）が、これは非常に注意深く見守る。

AIが単なる誇大広告かどうかを待っていたなら、これがあなたの答えだ。**AIは本物であり、ここに留まる**。だから今できる最善のことは、それを使う方法を学ぶことだ。
