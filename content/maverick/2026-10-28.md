### 📌 写真の顔を変えずに修正する5つのChatGPT秘密コード

ChatGPTに写真をアップロードして「/identity-lock」と入力すれば、顔の特徴を一切変えずに写真全体を修正できる。

最新動画でこれらのコードが大好評な理由は、AI写真編集で最も厄介な問題を解決するからだ。写真を良くしてほしいと頼むと、従兄弟のような別人が返ってくる。雰囲気は似ているが、鼻が違う。この5つのコードは写真を修正しながら、あなたをあなたのままにしてくれる。正直なところ、AdobeやCanvaがこれに対抗するのは困難だろう。

1. **/identity-lock**：どんな編集にもこれを追加すれば、ChatGPTはあなたの周囲すべてを変更しながら、あなた自身は完全に同じに保つ。同じ顔、同じ髪、同じ服装、あなたへの照明も同じ。変わるのは背景だけ。見知らぬ人の顔になることなく、より良い設定が欲しいときに使おう。

2. **/studio-quality**：照明とシャープネスを改善し、スマホで撮った写真がプロのカメラマンが撮影したように見える。

3. **/upscale**：鮮明度と解像度を向上させる。お気に入りの古いぼやけた写真や、印刷したい写真に最適。

4. **/clean-up**：散らかった背景、無関係な人物、椅子の上の洗濯物などを削除し、画像全体をよりクリーンに見せる。

5. **/pose-only**：顔に触れることなくポーズだけを変更する。すべて完璧だが立ち方が少し変なときに最適。

使い方は次の通り。ChatGPTを開き、写真を添付してコードを入力する。それだけだ。具体的なものが欲しい場合は「/clean-up, keep the dog（犬は残して）」のように数語追加できる。最も優れている点は、これらを**重ねて使える**こと：最初に/clean-upを実行し、その結果に/studio-qualityを実行すれば、実際に投稿したくなる写真が手に入る。

コツを一つ：写真ごとに新しいチャットを開始すること。そうすればChatGPTが前回の編集を次の編集に混ぜることがない。

### 📌 Claude Modsが登場：独自のClaude版を構築しよう

ClaudeがModsをリリースし、会話するだけで独自のClaude版を構築できるようになった。

毎日Claudeに尋ねることを考えてみよう。「現状をまとめて」「まだ未完了なのは？」「これをミスチェックして」。Modsを使えば、これらのプロンプトをチャットのすぐ上に配置される実際のボタンに変換できるので、二度と入力する必要がない。コードは一切書かない。欲しいものを説明すれば、Claudeが構築し、オンにするだけだ。

ModsはClaude Codeで動作するので、有料のClaudeプランとClaudeデスクトップアプリが必要（ウェブ上の通常のClaudeチャットでは動作しない）。

**ステップ1**：Claudeデスクトップアプリを開き、Codeを選択し、作業中のプロジェクトまたはフォルダを開く。

**ステップ2**：これを貼り付ける：

```
チャットの上に3つのボタンを持つmodを構築してください。1つはこのプロジェクトを要約するボタン、1つは未完了タスクをリストするボタン、1つは最新の下書きをミスチェックするボタンです。各ボタンがその指示を会話に送信するようにしてください。
```

**ステップ3**：Claudeがファイルの承認を求めたら承認する。書いたmodsをオンにするか尋ねられたら「Turn them on」をクリックし、返信が終わると、3つのボタンがチャットの上に表示される。

ここからがコツだ。さらに構築を続けられる。同じチャットにこれを貼り付ける：

```
チャットの横にパネルを追加して、変更した全ファイルを表示し、前後を比較できるようにしてください。
```

Claudeがウェブサイト、メモ、文書を更新したとき、先に進む前に何をしたか正確に確認できる。別のボタンやレイアウトが欲しい？Claudeに変更内容を伝えるだけだ。

注意点が1つ：modは構築したチャットでのみ読み込まれる。Claude Codeを開くたびに使いたい場合は、Claudeにプラグインとして保存するよう依頼すれば、手順を案内してくれる。

どのボタンを使うか分からない？Claudeに一緒に考えてもらおう：

```
Claude Codeの使い方について私にインタビューして、最も時間を節約できるmodsを提案してください。何に取り組んでいるか、何度も入力するプロンプト、何が作業を遅らせているかについて、一度に1つの質問をしてください。終わったら、5つのmodsを提案し、それぞれを1文で説明し、私が最も使いそうなものを構築してください。
```

私はWispr Flowを使ってタイピングではなく声で答えている。約3倍速く、はるかに詳細な情報を提供できるからだ。

### 📌 AnthropicがIPO間近、ほぼ黒字化を達成

Claude開発元のAnthropic（アンソロピック）が正式に株式公開を申請した。Nasdaqに**ANT**のティッカーシンボルで上場する。株価と日付はまだ未定だが、報道では評価額は1.4〜2兆ドルの間とされ、早ければ11月中旬に上場する見込みだ。

これは今年のAIで最大級の出来事の1つになると考えている。これまで、Claudeを作る会社の株を所有できるのは大口投資家やテクノロジー大手だけだった。まもなく、証券アプリを持つ誰もが所有できるようになる。

申請書の成長は驚異的だ。Anthropicは**2023年に4,100万ドル**、**2024年に3億8,600万ドル**、**2025年に46億ドル**を稼いだ。そして今年の最初の6か月間だけで**163億ドル**を稼いだ。Claudeに年間少なくとも10万ドルを支出する企業は、約950社から**1万1,900社以上**に1年で増加し、現在**Fortune 500の半数以上**を含む。年間100万ドル以上を支払う企業は1,900社以上、1,000万ドル以上を支払う企業は約250社だ。約5,300人の従業員で、**1人あたりの年間収益は660万ドル以上**で、わずか1年前の140万ドルから増加した。

先週水曜日にお伝えした800億ドルの損失を覚えているだろうか？正式な申請書が出て、それが何だったか正確に分かる。そのうち**724億ドルは会計上の費用**で、これはAnthropicが非常に価値が高まったため、古い投資家債券が帳簿上ではるかに価値が高くなったことによるものだ。建物から出ていったお金ではない。

実際のビジネスがしたことは次の通り。Anthropicの163億ドルの収益に対する**実際の営業損失は6億9,300万ドル**だった。これは稼いだ1ドルあたり約4セントの損失で、1年前の12億ドルの収益に対する21億ドルの損失から減少している。そして従業員に支払う株式を除けば、実際には**16億ドルの利益を上げた**。これだけのコンピューティングパワーに支出している企業にとって、これは**ほぼ黒字**であり、見出しが示唆したものとは全く異なる。

他にも興味深い点がいくつかある：

**創業者は大半を寄付する**。Anthropicの共同創業者は各自、個人が保有するAnthropic株式の80%を慈善事業に寄付することを誓約した。また、株価が50%上昇するたびに最大2%の株式を善良な目的のために受け取る基金もある。

**創業者は支配権を維持する**。誰でも株式を購入できるようになった後も、共同創業者は**50.1%の議決権**を保持するため、ウォール街が単純に乗っ取ってClaudeを変えることはできない。

私の見解は次の通り。先週、Google、Amazon、Microsoftがこの競争で確実に勝つと述べた。Anthropicの収益の多くが彼らに流れるからだ。それは今でも真実だ。しかし、この申請書は、Anthropicが単にお金を捨てている会社ではないことを示している。何千もの企業が莫大な金額を支払っている本物のソフトウェアを構築しており、それは成長し続けている。より多くのお金はより多くのコンピューティングパワーを意味し、より多くのコンピューティングパワーはあなたにとってより良いClaudeを意味する。株を買えとは言わない（私はファイナンシャルアドバイザーではない）が、これは非常に注意深く見守るつもりだ。

AIが単なる誇大宣伝かどうか待っていたなら、これがあなたの答えだ。**AIは現実であり、定着している**。だから今できる最善のことは、それを使う方法を学ぶことだ。
