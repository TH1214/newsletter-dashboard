### 🧠 今日やるべきこと

**Claudeはあなたの最古のオンライン履歴を見つけられる**

インターネット上には約15年前のあなたが存在している。一度作って二度と戻らなかったアカウント、2回だけ投稿したフォーラム、あなたの名前が載っている学校やクラブのページ、4つのエントリーを書いて放置したブログ。どれも何の成果も生まなかった。それらはすべてまだそこにあり、意図的に探しに行った人はほとんどいない。

筆者はこれをClaudeで試すことにした。プロンプトチェーンを組み立てて自分自身を検索したところ、2016年の古いゲームコンテンツが発掘された。10年間見ていなかった、完全に忘れていたものだ。

**ステップ1：Claudeを開いて以下を貼り付ける**

```
インターネット上にまだ存在する、私に関する最も古いものを見つけてください。私の名前、メールアドレス、過去に使ったユーザーネームで検索し、削除されたページのアーカイブ版も含めてきちんと調べてください。最も古いアカウント、プロフィール、フォーラム投稿、写真、クラブや学校や職場のページでの言及、そして既に存在しないサイトからのものを探してください。古い順に並べて、それぞれがおよそ何年のものかを教え、リンクを示してください。私の名前は[あなたのフルネーム]、メールアドレスは[あなたのメール]、過去に使っていた古いユーザーネームは[リストを記載]です。
```

古いユーザーネームの部分が重要な役割を果たす。これは人々が省略しがちな部分だ。あなたの名前では明白なものしか見つからない。14歳の時に選んだユーザーネームこそが**他のすべてを見つける**鍵となる。なぜなら、当時実際に投稿していたのはそのユーザーネームだからだ。

**ステップ2：これを使って笑いから実用へ転換させる**

```
今度はそのすべてを、他人が見るように見てください。もし明日誰かが私の名前を検索したら——新しいクライアント、デートの相手、これから一緒に働く人——彼らは何を見つけ、どんな印象を持つでしょうか。正直に教えてください。それから、これらのうちどれを削除またはロックすべきか、どれは実際には問題ないか、そして各項目を正確にどうやって削除するかを教えてください。
```

戻ってくる結果のほとんどは無害で少し面白い。しかし通常、1つくらいは「これまだ残ってるの？」と思うものがある。見つかりたくない写真が載った古いプロフィール、2011年のページに残った住所、忘れていた議論で残したコメント。10分で消すことができる。

正直なところ、公開情報しか見つけられないため、非公開で投稿したものは出てこないし、すべてが見つかるわけではない。しかし予想以上のものが見つかり、自分の年表を読み返すのは奇妙な体験だ。

### ⚡ 一度だけ設定すれば済むこと

**Claudeを完全に別物に変える4つのコネクター**

ほとんどの人はClaudeを箱から出したままの状態で使っている。これはドリルを買ってハンマーとしてしか使わないようなものだ。単体では考えることができる。4つのものを接続すれば、実際に行動して実行できるようになる。

どのアカウントにも入れるべき4つがこれで、これらを組み合わせればClaudeに触れさせたいほぼすべてをカバーできる：

**Firecrawl**はウェブサイトを適切に読み取らせる。5つの競合サイトから価格を引き出して表にまとめられる。**Composio**は1つの接続で1,000以上のアプリ（Gmail、Slack、Notion、カレンダー、CRM）を開く。1つずつ追加する必要がない。**Playwright**は実際のブラウザを操作させ、コネクターが全くないサイトでクリック、入力、フォーム記入ができる。そして**Perplexity**はライブリサーチエンジンに接続し、記憶からではなくウェブからソース付きで回答させる。

セットアップの部分が人々を躊躇させているが、そうすべきではない。4つすべてのインストール方法が異なるが、何も学ぶ必要はない。適切に頼めばClaude自身がすべてやってくれる。

**ステップ1：Claudeデスクトップアプリを開き、上部のCodeタブをクリック。以下を貼り付ける**

```
これら4つのMCPサーバーを設定してください。すべて自分で実行し、何か必要な時だけ聞いてください：1. Playwright — npx @playwright/mcp@latest（無料）2. Composio — https://connect.composio.dev/mcp（指示されたらサインインします）3. Firecrawl — https://mcp.firecrawl.dev/v2/mcp（firecrawl.devの無料APIキーを聞いてください）4. Perplexity — https://api.perplexity.ai/mcp（perplexity.aiの有料キー — 必要か、スキップするか聞いてください）各項目が接続されたことを確認してから次に進み、それぞれのテストプロンプトを教えてください。
```

Claudeは自分でインストールを実行し、本当に必要な時だけ（サインインやキーが必要な時）止まって尋ねてくる。あなたはコマンドを入力するのではなく、答えるだけだ。

**ステップ2：Perplexityについて聞かれたら、スキップすると答える**

4つのうちお金がかかるのはこれだけで、違いを感じるのに必要ない。FirecrawlとComposioは無料アカウント、Playwrightは無料でオープンソース、この3つだけで飛躍的に変わる。毎日本格的なリサーチをClaudeで実行するようになったら、後でPerplexityを追加すればいい。

**各コネクターが解放する機能**
- **Firecrawl** → 「これら3つの競合サイトから価格を表にまとめて」
- **Composio** → 「私のGmailをチェックして返信が必要なものを要約して」
- **Playwright** → 「このページを開いてコンタクトフォームを記入して」
- **Perplexity** → 「これをリサーチしてソースを引用して」

正直なところ、Firecrawlは4つの中で唯一Claudeに既に組み込まれており、コネクターディレクトリで接続をクリックするだけで待機している。もしCodeタブがどうしても合わないなら、これだけ単独で実行すれば、約2クリックでClaudeをアップグレードできる。

### 🚨 誰も話していないこと

**ChatGPTがログイン画面を突破できるようになった**

これまでChatGPTに何かを実際に実行してもらおうとするたびに、同じ壁にぶつかってきた。ログイン画面に到達して止まる。これは重要なほぼすべてを除外する。なぜなら、あなたの銀行、電力会社のアカウント、保険、自治体、サプライヤー、請求書はすべてログイン画面の向こう側にあるからだ。

その壁がちょうど崩れた。**ChatGPT Workのブラウザは、サインインが必要なウェブサイトを使用でき**、そのログインをその後も保持する。

実際の仕組みを説明する。見出しはこの点について少し曖昧だった。**パスワードは入力しない**。エージェントがログイン画面に到達すると停止し、ブラウザをあなたに返す。あなたは普段と全く同じように自分でサインインし、銀行からテキストメッセージで送られてくるコードも含めて入力する。それからブラウザを返す。ChatGPTはユーザーネームもパスワードも見ず、この引き渡し中に入力した内容は収集されない。

状況を変えるのは次に起こることだ。**セッションが生き続ける**。一度サインインすれば、次に何かを頼んだ時もまだサインインしたままなので、タスクごとにその作業を繰り返す必要がない。Plus、Pro、Businessで展開中で、ウェブでもスマートフォンでも利用できる。

したがって、今引き受けられる仕事は、あなたが何ヶ月も先延ばしにしてきたものだ。電力会社のアカウントに入って、最安プランかどうか教えて。昨年の請求書を見つけてスプレッドシートにまとめて。予約を取って。キャンセルし忘れているものをキャンセルして。実際の作業は実行前に確認を求めてくるので、勝手にお金を使ったり気まぐれでフライトを予約したりはしない。

**知っておいてほしい部分がある**。OpenAIのサーバー上で生きているセッションは真剣に考えるべきことであり、これを避ける理由ではない。ノートパソコンを閉じていてもログインしたままで、OpenAI自身もチェックがすべてのリスクを排除するわけではないと述べている。だから**何か退屈なもので始めてほしい**。銀行ではなく電力会社のアカウントで。最悪のケースが無駄な午後で済むもので挙動を見て、それからどこまで許可するか決める。
