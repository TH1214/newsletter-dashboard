### 📌 今日やるべきこと

**Claudeはあなたの最古のオンライン痕跡を発見できる**

約15年前からインターネット上に存在する、あなたが完全に忘れ去った過去のバージョンがある。一度作って二度と戻らなかったアカウント、2回だけ投稿したフォーラム、名前が載った学校やクラブのページ、4つのエントリーを書いて放置したブログ。どれも何の成果も生まなかった。しかしすべてまだそこにあり、意図的に探しに行った人はほぼいない。

そこで、これをClaudeで試してみることにした。プロンプトチェーンを組み立て、自分自身で実行したところ、2016年の古いゲームコンテンツが掘り起こされた。10年間見ていなかった、正直完全に忘れていたものだ。

**ステップ1：Claudeを開いて以下を貼り付ける**

```
インターネット上にまだ存在する私に関する最も古いものを見つけてください。私の名前、メールアドレス、使用したことのあるユーザーネームで検索し、削除されたページのアーカイブ版も含めてしっかり調べてください。最も古いアカウント、プロフィール、フォーラム投稿、写真、クラブや学校や職場のページでの言及、もう存在しないサイトからのあらゆるものを探してください。古い順に並べ、それぞれがおよそ何年のものか教え、リンクをください。私の名前は[フルネーム]、メールアドレスは[メール]、過去に使ったユーザーネームは[リスト]です。
```

古いユーザーネームが重労働を担う部分であり、人々が省略する箇所だ。名前だけでは明白なものしか出てこない。14歳の時に選んだユーザーネームが、**それ以外のすべて**を引き出す。なぜなら、当時実際に投稿していたのはそれだからだ。

**ステップ2：次は笑い話から実用的なものに変える**

```
今度はこれらすべてを他人の目で見てください。もし誰かが明日私の名前を検索したら—新しいクライアント、デート相手、これから一緒に仕事をする人—何を見つけ、どんな印象を持つでしょうか。正直に教えてください。そして、どれを削除またはロックすべきか、どれは実際には問題ないか、それぞれを削除する正確な方法を教えてください。
```

戻ってくるものの大半は無害で少し面白い。しかし通常、「あれ、まだ公開されてるの？」と思うものが1つはある。誰にも見つけて欲しくない写真のある古いプロフィール、2011年のページに残った住所、忘れていた口論で残したコメント。10分あれば削除できる。

正直な注記を1つ。これは公開されているものしか見つけられないため、非公開で投稿したものは出てこないし、すべてを網羅するわけでもない。しかし予想以上のものが見つかり、自分のタイムラインを読み返すのは奇妙な体験だ。

### ⚡ 一度設定すれば完了

**Claudeを全く別物に変える4つのコネクタ**

ほとんどの人はClaudeをそのまま使っており、これはドリルを買ってハンマーとしてだけ使うようなものだ。単体では考えることができる。4つのものを接続すれば、実際に行動し実行できるようになる。

どのアカウントにも入れるべき4つがこれで、合わせればClaudeに届かせたいほぼすべてをカバーする：

**Firecrawl**はウェブサイトを適切に読み取れるようにし、5つの競合サイトから価格を引き出して表にまとめられる。**Composio**は1つの接続で1000以上のアプリ（Gmail、Slack、Notion、カレンダー、CRM）を開く、1つずつ追加する代わりに。**Playwright**は実際のブラウザを操作させ、コネクタが全くないサイトでクリック、タイピング、フォーム入力を行う。そして**Perplexity**はライブ研究エンジンに接続し、記憶からではなくソース付きでウェブから回答する。

セットアップが人々を躊躇させる部分だが、そうあるべきではない。なぜなら4つすべてが異なるインストール方法を持つが、何も学ぶ必要はないからだ。適切に頼めばClaude自身がすべてやってくれる。

**ステップ1：Claudeデスクトップアプリを開き、上部のCodeタブをクリック。以下を貼り付ける**

```
これら4つのMCPサーバーを設定してください。すべて自分で実行し、何か必要な時だけ聞いてください：
1. Playwright — npx @playwright/mcp@latest（無料）
2. Composio — https://connect.composio.dev/mcp（サインイン時に教えます）
3. Firecrawl — https://mcp.firecrawl.dev/v2/mcp（firecrawl.devから無料APIキーを聞いてください）
4. Perplexity — https://api.perplexity.ai/mcp（perplexity.aiからの有料キー—必要か、スキップしたいか聞いてください）
各接続を確認してから次に進み、それぞれのテストプロンプトをください。
```

Claude自身がインストールを実行し、本当に必要な時（サインインやキー）だけ止まって尋ねる。コマンドを打つのではなく、答えるだけだ。

**ステップ2：Perplexityについて尋ねられたら、スキップと言う**

これは4つの中で唯一コストがかかるもので、違いを感じるのに必要ない。FirecrawlとComposioは無料アカウント、Playwrightは無料でオープンソース、この3つだけで飛躍する。毎日Claudeを通じて本格的なリサーチを実行するようになったら、後でPerplexityを追加すればいい。

**各コネクタが解放するもの**
- **Firecrawl** → 「これら3つの競合サイトから価格を表にまとめて」
- **Composio** → 「Gmailをチェックして返信が必要なものを要約して」
- **Playwright** → 「このページを開いて問い合わせフォームに記入して」
- **Perplexity** → 「これを調査してソースを引用して」

正直な注記を1つ。**Firecrawl**は4つの中で唯一Claudeにすでに組み込まれており、コネクタディレクトリで接続クリックを待っているだけなので、Codeタブが全く合わない場合でも、これだけを単独で行えば約2クリックでClaudeをアップグレードしたことになる。

### 🚨 誰も話題にしていないこと

**ChatGPTがログイン画面を突破できるようになった**

ChatGPTに実際に何かをやってもらうよう頼むたびに、同じ壁にぶつかってきた。ログイン画面に到達して止まる。これは重要なほぼすべてを除外する。なぜなら銀行、エネルギーアカウント、保険、自治体、サプライヤー、請求書はすべてログイン画面の向こうにあるからだ。

その壁が今崩れた。**ChatGPT Workのブラウザがサインインが必要なウェブサイトを使用できるようになり**、その後もログインを保持する。

実際の仕組みはこうだ。見出しがこの点で少し曖昧だったので説明する。パスワードは入力しない。エージェントがログイン画面に到達すると停止し、ブラウザをあなたに返す。銀行がテキストで送るコードも含め、いつも通りに自分でサインインし、それから返す。ChatGPTはユーザーネームもパスワードも見ず、その引き渡し中に入力した内容は収集されない。

状況を変えるのは次に起こることだ。**セッションが生き続ける**。一度サインインすれば、次に何かを頼んだ時もまだサインインしたままなので、タスクごとにその手順を繰り返す必要がない。Plus、Pro、Businessで展開中で、ウェブでも電話でも使える。

つまり今引き受けられるジョブは、何ヶ月も先延ばしにしてきたものだ。エネルギーアカウントに入って最安プランかどうか教えて。昨年の請求書を見つけてスプレッドシートに入れて。予約を取って。キャンセルし忘れているものをキャンセルして。実際のことは何でもコミット前に確認を求めるので、勝手にお金を使ったりフライトを予約したりはしない。

知っておいて欲しい部分はこれだ。**OpenAIのサーバー上に置かれた生きたセッションは本当に考えるべきこと**であり、避ける理由ではない。ノートパソコンを閉じている時もログインしたままで、OpenAI自身がチェックがすべてのリスクを取り除くわけではないと述べている。だから退屈なものから始めよ。銀行ではなくエネルギーアカウント。最悪のケースが午後の無駄で済むもので動作を見て、どこまで許可するか決める。
