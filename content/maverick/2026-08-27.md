### 📌 Claudeでオンライン上の最古の自分を発見

インターネット上には、あなたが完全に忘れている約15年前のバージョンのあなたが存在している。一度作って二度と戻らなかったアカウント、2回だけ投稿したフォーラム、あなたの名前が載っている学校やクラブのページ、4回書いて放置したブログ。どれも大したことにはならなかった。しかしそれらはすべてまだそこにあり、意図的に探しに行った人はほとんどいない。

筆者はこのプロンプトチェーンを組み立て、自分自身に対して実行したところ、2016年の古いゲームコンテンツを掘り起こした。10年間見ていなかった、完全に考えることをやめていたものだ。

**ステップ1：Claudeを開いて以下を貼り付ける**

```
インターネット上にまだ存在する私に関する最も古いものを見つけてください。私の名前、メールアドレス、使用したことのあるユーザー名を検索し、削除されたページのアーカイブ版も含めて適切に調べてください。最も古いアカウント、プロフィール、フォーラム投稿、写真、学校や職場やクラブページでの言及、もう存在しないサイトからのものすべてが欲しいです。古い順に並べて、それぞれがおよそ何年のものかを教え、リンクを提供してください。私の名前は[あなたのフルネーム]、メールアドレスは[あなたのメール]、使用したことのある古いユーザー名は[リストアップ]です。
```

古いユーザー名が重要な働きをする部分であり、人々が省略しがちな部分だ。名前だけでは明白なものしか出てこない。14歳の時に選んだユーザー名があれば、それ以外のすべてが出てくる。なぜならそれが当時実際に投稿に使っていたものだからだ。

**ステップ2：次に、笑い話から実用的なものに変えるプロンプト**

```
今度はこれらすべてを他人の目で見てください。明日誰かが私の名前を検索したら、新しいクライアント、デート相手、これから一緒に働く人が、何を見つけ、どんな印象を持つでしょうか。正直に教えてください。それから、これらのうちどれを削除またはロックすべきか、どれが実際には問題ないか、そしてそれぞれを正確にどう削除するかを教えてください。
```

返ってくるもののほとんどは無害で少し面白い。しかし通常、「ああ、これまだ残ってるの?」と思わせるものが一つはある。誰にも見つけてほしくない写真のある古いプロフィール、2011年のページに載っている住所、忘れていた議論で残したコメント。10分もあればそれを消すことができる。

正直な注意点として、公開されているものしか見つけられないため、非公開で投稿したものは出てこないし、すべてを取得できるわけではない。しかし予想以上のものが見つかり、自分自身の年表を読み返すのは奇妙な体験だ。

### 📌 Claudeを完全に別物に変える4つのコネクタ

ほとんどの人はClaudeを箱から出したままの状態で使っているが、これはドリルを買ってハンマーとしてしか使わないようなものだ。単体では考えることができる。4つのものを接続すれば、実際に行動することができる。

以下は筆者がどのアカウントにも設定する4つで、これらを合わせればClaudeに届けたいほぼすべてをカバーする：

**Firecrawl**は任意のウェブサイトを適切に読み取れるようにし、5つの競合サイトから価格を引き出して表にまとめられる。**Composio**は一つの接続で千以上のアプリ（Gmail、Slack、Notion、カレンダー、CRM）を開き、一つずつ追加する必要がない。**Playwright**は実際のブラウザを操作させ、コネクタが全くないサイトでクリック、入力、フォーム記入を行う。**Perplexity**はライブ検索エンジンに接続し、記憶からではなくウェブから情報源付きで回答する。

セットアップが人々を遠ざける部分だが、そうであるべきではない。なぜなら4つすべてが異なる方法でインストールされ、何も学ぶ必要がないからだ。適切に尋ねればClaude自身がすべてを行う。

**ステップ1：Claudeデスクトップアプリを開き、上部のCodeタブをクリックして以下を貼り付ける**

```
これら4つのMCPサーバーを設定してください。すべて自分で実行し、何か必要な時だけ私に尋ねてください：
1. Playwright — npx @playwright/mcp@latest (無料)
2. Composio — https://connect.composio.dev/mcp (サインインが必要な時に教えて)
3. Firecrawl — https://mcp.firecrawl.dev/v2/mcp (firecrawl.devからの無料APIキーを尋ねて)
4. Perplexity — https://api.perplexity.ai/mcp (perplexity.aiからの有料キー — 欲しいかスキップしたいか尋ねて)
次に進む前に各接続を確認し、それぞれのテストプロンプトを提供してください。
```

Claudeはインストールを自分で実行し、本当に何か必要な時（サインインやキー）に止まって尋ねる。コマンドを入力しているのではなく、ただ答えているだけだ。

**ステップ2：Perplexityについて尋ねられたら、スキップすると言う**

これは4つの中で唯一お金がかかるもので、違いを感じるために必要ない。FirecrawlとComposioは無料アカウント、Playwrightは無料でオープンソース、この3つだけで飛躍を感じられる。毎日Claudeで本格的な調査を実行していると感じたら、後でPerplexityを追加すればよい。

**各コネクタが解放するもの**
- **Firecrawl** → 「これら3つの競合サイトから価格を引き出して表にして」
- **Composio** → 「Gmailをチェックして返信が必要なものを要約して」
- **Playwright** → 「このページを開いてお問い合わせフォームに記入して」
- **Perplexity** → 「これを調査して情報源を引用して」

正直な注意点として、Firecrawlは4つの中で唯一Claudeに既に組み込まれており、接続ディレクトリで接続をクリックするだけで待機しているため、Codeタブが全く合わない場合は、これだけを単独で行えば、約2クリックでClaudeをアップグレードしたことになる。

### 📌 ChatGPTがログイン画面を突破可能に

ChatGPTに何かを実際に行うよう頼むたびに、同じ壁にぶつかってきた。ログイン画面に到達して止まる。これはほぼすべての重要なものを除外する。なぜなら銀行、エネルギーアカウント、保険、自治体、サプライヤー、請求書はすべてその向こうに座っているからだ。

その壁が崩れた。ChatGPT Workのブラウザは現在、サインインが必要なウェブサイトを使用でき、その後ログインを保持する。

実際の仕組みは以下の通りで、見出しはこの点について少し曖昧だった。パスワードを入力しない。エージェントがログイン画面に当たると停止してブラウザをあなたに返し、あなたは常にしてきたように自分でサインインし、銀行がテキストで送信するコードも含めて、そしてそれを返す。ChatGPTはユーザー名もパスワードも見ず、その引き渡し中に入力したものは収集されない。

物事を変える部分は次に起こることだ。セッションが生き続ける。一度サインインすれば、次に何かを頼む時もサインインしたままなので、タスクごとにそのやり取りを繰り返す必要がない。Plus、Pro、Businessで展開されており、ウェブでも電話でも利用可能だ。

つまり現在引き受けられる仕事は、何ヶ月も先延ばしにしてきたものだ。エネルギーアカウントに入って、私が最安の料金プランにいるか教えて。昨年の請求書を見つけてスプレッドシートに入れて。予約を取って。キャンセルするのを忘れ続けているものをキャンセルして。実際のことは何でもコミットする前に尋ねるので、勝手にお金を使ったり気まぐれにフライトを予約したりはしない。

知っておいてほしい部分は以下だ。OpenAIのサーバー上にあるライブセッションは本当に考えるべきことであり、これを避ける理由ではない。ラップトップが閉じている時もログインしたままであり、OpenAI自身も彼らのチェックがすべてのリスクを取り除くわけではないと述べている。だから何か退屈なもので始めよう。銀行ではなく、エネルギーアカウントで。最悪の場合が無駄な午後で済むもので動作を見て、それからどこまで許可するか決めればよい。
