### 🧠 本日実行すべきこと

#### Claudeでネット上の最古の自分を発掘する

約15年前にあなたがインターネット上に残した痕跡で、完全に忘れ去っているものがある。一度作って二度と戻らなかったアカウント、2回だけ投稿したフォーラム、あなたの名前が載った学校やクラブのページ、4つのエントリーを書いて放置したブログ。どれも何の成果も生まなかった。しかしすべて今も残っており、意図的に探しに行った人はほとんどいない。

そこで私はこれをClaudeに任せることにした。プロンプトチェーンを組み立てて自分自身に実行したところ、2016年の古いゲームコンテンツが掘り起こされた。10年間見ていなかったもので、正直完全に忘れていた。

**ステップ1: Claudeを開いて以下を貼り付ける**

```
インターネット上にまだ存在する私に関する最古のものを見つけてください。私の名前、メールアドレス、使用したユーザーネームを検索し、削除されたページのアーカイブ版も含めて徹底的に調べてください。最も古いアカウント、プロフィール、フォーラム投稿、写真、クラブ・学校・職場ページでの言及、もう存在しないサイトからのあらゆるものを探してください。古い順に並べ、それぞれがおよそ何年のものかを示し、リンクを提供してください。私の名前は[あなたのフルネーム]、メールアドレスは[あなたのメールアドレス]、使用した古いユーザーネームは[リストアップ]です。
```

古いユーザーネームが重労働を担う部分であり、人々が省略しがちな箇所だ。あなたの名前は明白なものを見つけてくれる。14歳のときに選んだユーザーネームがその他すべてを見つけてくれる。なぜなら、それが当時実際に投稿に使っていたものだからだ。

**ステップ2: 次に、これを笑い話から有用なものに変えるプロンプト**

```
今度はこれらすべてを見知らぬ人の視点で見てください。明日誰かが私の名前を検索したら、新しい顧客、デート相手、これから一緒に働く人が、何を見つけてどんな印象を持つでしょうか。正直に教えてください。そして、これらのうちどれを削除またはロックすべきか、どれが実際には問題ないか、それぞれをどのように削除するかを正確に教えてください。
```

返ってくるもののほとんどは無害で少し面白い。しかし通常、その中に1つだけ「え、これまだ残ってるの?」というものがある。誰にも見つけてほしくない写真がある古いプロフィール、2011年のページに載った住所、忘れていた議論で残したコメント。10分あれば削除できる。

正直な注記。これは公開されているものしか見つけられないので、非公開で投稿したものは出てこないし、すべてを網羅するわけではない。しかし予想以上のものが見つかり、自分自身のタイムラインを読み返すのは奇妙な体験だ。

### ⚡ 一度設定すれば完了

#### Claudeを全く別のものに変える4つのコネクタ

ほとんどの人は箱から出したままのClaudeを使っているが、これはドリルを買ってハンマーとしてしか使わないようなものだ。単体では考えることができる。4つを接続すれば実際に行動できるようになる。

どのアカウントにも設定すべき4つがこれで、これらを合わせればClaudeに届いてほしいほぼすべてをカバーする:

**Firecrawl**はあらゆるウェブサイトを適切に読み取り、5つの競合サイトから価格を引き出して表にまとめられる。**Composio**は1つの接続で1,000以上のアプリ(Gmail、Slack、Notion、カレンダー、CRM)を開く、1つずつ追加する代わりに。**Playwright**は実際のブラウザを操作し、コネクタが全くないサイトでクリック、入力、フォーム記入ができる。**Perplexity**はライブリサーチエンジンに接続し、記憶からではなくソース付きでウェブから回答する。

セットアップが人々を躊躇させる部分だが、そうすべきではない。なぜなら4つすべてが異なる方法でインストールされ、何も学ぶ必要がないからだ。適切に頼めばClaude自身がすべてやってくれる。

**ステップ1: Claudeデスクトップアプリを開き、上部のCodeタブをクリック。以下を貼り付ける**

```
これら4つのMCPサーバーを設定してください。すべて自分で実行し、何か必要なときだけ尋ねてください: 1. Playwright — npx @playwright/mcp@latest (無料) 2. Composio — https://connect.composio.dev/mcp (指示されたらサインイン) 3. Firecrawl — https://mcp.firecrawl.dev/v2/mcp (firecrawl.devから無料APIキーを求める) 4. Perplexity — https://api.perplexity.ai/mcp (perplexity.aiの有料キー — 必要か、スキップするか尋ねる) それぞれ接続を確認してから次に進み、各々のテストプロンプトを提供してください。
```

Claude自身がインストールを実行し、サインインやキーなど本当に必要なときだけ止まって尋ねる。あなたはコマンドを打つのではなく、答えるだけだ。

**ステップ2: Perplexityについて尋ねられたら、スキップすると言う**

これが4つの中で唯一お金がかかるもので、違いを感じるのに必要ない。FirecrawlとComposioは無料アカウント、Playwrightは無料でオープンソース、この3つだけで飛躍を感じられる。毎日本格的な調査をClaudeで実行するようになったら、後でPerplexityを追加すればいい。

**それぞれが解放するもの**
- **Firecrawl** → "これら3つの競合サイトから価格を表に引き出して"
- **Composio** → "Gmailをチェックして返信が必要なものをまとめて"
- **Playwright** → "このページを開いてコンタクトフォームに記入して"
- **Perplexity** → "これを調査してソースを引用して"

正直な注記。Firecrawlは4つの中で唯一Claudeに既に組み込まれており、コネクタディレクトリで接続をクリックするだけで使える。もしCodeタブがまったく合わない場合は、これだけを単独で実行すれば約2クリックでClaudeをアップグレードできる。

### 🚨 誰も話題にしていないこと

#### ChatGPTがログイン画面を突破できるようになった

ChatGPTに実際に何かをやってもらおうとするたびに、同じ壁にぶつかってきた。ログイン画面に到達して止まる。これはほぼすべての重要なことを除外する。なぜなら、あなたの銀行、エネルギーアカウント、保険、自治体、サプライヤー、請求書はすべてログイン画面の向こうにあるからだ。

その壁が今崩れた。**ChatGPT Workのブラウザは、サインインが必要なウェブサイトを使用できるようになり、その後もログイン状態を保持する**。

これが実際にどう機能するかを説明する。見出しがこの点について少し曖昧だったからだ。パスワードを入力するわけではない。エージェントがログイン画面に到達すると停止し、ブラウザをあなたに返す。あなたは銀行がテキストで送ってくるコードも含めて、いつも通り自分でサインインし、それから返す。ChatGPTはユーザーネームもパスワードも見ず、その引き継ぎ中に入力したものは収集されない。

状況を変えるのは次に起こることだ。セッションが生き続ける。一度サインインすれば、次に何かを頼んだときもサインインしたままなので、タスクごとにそのダンスを繰り返す必要がない。Plus、Pro、Businessで展開中で、ウェブでも電話でも使える。

つまり今では数ヶ月間先延ばしにしてきた仕事を任せられる。エネルギーアカウントに入って最安のタリフかどうか教えて。去年の請求書を見つけてスプレッドシートにまとめて。予約を取って。キャンセルし忘れているものをキャンセルして。実際のものは何でもコミットする前に尋ねてくるので、勝手にお金を使ったり気まぐれでフライトを予約したりすることはない。

知っておいてほしい部分がここだ。**OpenAIのサーバー上に存在するライブセッションは真剣に考えるべき事項**であり、これを避ける理由ではない。ノートパソコンを閉じているときもログインしたままで、OpenAI自身がチェックですべてのリスクを除去できるわけではないと述べている。だから何か退屈なもので始めよ。銀行ではなくエネルギーアカウント。最悪のケースが午後の無駄遣いで済むもので動作を見て、それからどこまで任せるかを決める。
