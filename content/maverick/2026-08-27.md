### 📌 インターネット上の最古の「あなた」をClaudeで発掘する

約15年前、あなたがインターネット上に残した痕跡がある。一度だけ作って二度と戻らなかったアカウント、2回だけ投稿したフォーラム、名前が載っている学校やクラブのページ、4つの記事を書いて放置したブログ。どれも何も成し遂げなかった。だが、すべてまだそこに残っており、わざわざ探しに行った人はほとんどいない。

この作業にClaudeを使ってみた。以下のプロンプトチェーンを自分自身で実行したところ、2016年のゲームコンテンツが出てきた。10年間見ていなかったし、完全に忘れていた代物だ。

**ステップ1: Claudeを開いて以下を貼り付ける**

```
インターネット上にまだ存在する、私に関する最も古いものを見つけてください。私の名前、メールアドレス、過去に使用したユーザーネームで検索し、削除されたページのアーカイブ版も含めて徹底的に調べてください。最も古いアカウント、プロフィール、フォーラム投稿、写真、クラブ・学校・職場ページでの言及、もう存在しないサイトからのものなど、すべてを古い順に並べ、それぞれがおよそ何年のものか、リンクを教えてください。私の名前は[フルネーム]、メールは[メールアドレス]、過去のユーザーネームは[リスト]です。
```

古いユーザーネームの部分が最も重要で、多くの人が省略してしまう。名前では明白なものしか出てこない。14歳の時に選んだユーザーネームこそが、当時実際に投稿していた名義だからだ。

**ステップ2: 次に、笑いから実用へ転換するプロンプト**

```
これらすべてを、他人の視点で見てください。もし誰かが明日私の名前を検索したら——新しいクライアント、デート相手、これから一緒に働く人——何を見つけ、どんな印象を持つでしょうか。正直に教えてください。そして、どれを削除またはロックすべきか、どれは実際には問題ないか、それぞれをどう削除するかを具体的に教えてください。
```

出てくるものの大半は無害で少し笑える。だが通常、1つくらいは「えっ、これまだ残ってるの?」というものがある。残したくない写真のある古いプロフィール、2011年のページに載っている住所、忘れていた議論での投稿コメント。10分あれば削除できる。

正直に言うと、公開されているものしか見つけられないので、非公開で投稿したものは出てこないし、すべてが出るわけではない。しかし、予想以上に見つかるし、自分のタイムラインを読み返すのは奇妙な体験だ。

### 📌 Claudeを「別次元」に変える4つのコネクター

多くの人はClaudeを箱から出したままの状態で使っているが、これはドリルを買ってハンマーとしてしか使わないようなものだ。単体では考えることができる。4つを接続すれば、実際に行動できる。

以下は、どのアカウントにも入れるべき4つで、これらでClaudeがアクセスしたいほぼすべてをカバーできる:

**Firecrawl**（ファイアクロール）は、どんなウェブサイトも適切に読み取れるようにし、5つの競合サイトから価格を引き出して表にまとめられる。**Composio**（コンポジオ）は、1つの接続で1000以上のアプリ——Gmail、Slack、Notion、カレンダー、CRM——を開く。個別に追加する必要がない。**Playwright**（プレイライト）は実際のブラウザを操作し、コネクターが全くないサイトでクリック、入力、フォーム記入を行う。**Perplexity**（パープレキシティ）は、記憶ではなくソース付きでウェブから回答するライブ研究エンジンに接続する。

セットアップが人々を躊躇させているが、その必要はない。4つすべてインストール方法が異なるが、何も学ぶ必要はない。適切に頼めばClaude自身がすべてやってくれる。

**ステップ1: Claudeデスクトップアプリを開き、上部のCodeタブをクリック。以下を貼り付ける**

```
これら4つのMCPサーバーをセットアップしてください。すべて自分で実行し、何か必要な時だけ聞いてください: 1. Playwright — npx @playwright/mcp@latest (無料) 2. Composio — https://connect.composio.dev/mcp (サインイン指示が出たら行います) 3. Firecrawl — https://mcp.firecrawl.dev/v2/mcp (firecrawl.devから無料APIキーを求めてください) 4. Perplexity — https://api.perplexity.ai/mcp (perplexity.aiの有料キー — 必要か、スキップするか聞いてください) 各接続を確認してから次に進み、それぞれのテストプロンプトをください。
```

Claudeが自分でインストールを実行し、本当に必要な時——サインインやキーが必要な時——だけ止まって聞いてくる。あなたはコマンドを入力するのではなく、ただ答えるだけだ。

**ステップ2: Perplexityについて聞かれたら、スキップすると答える**

これが4つの中で唯一お金がかかるもので、違いを感じるのに必要ない。FirecrawlとComposioは無料アカウント、Playwrightは無料のオープンソースで、この3つだけで飛躍的な変化がある。毎日Claudeで本格的な調査を行うようになったら、後でPerplexityを追加すればいい。

**各コネクターが解放するもの**
- **Firecrawl** → 「これら3つの競合サイトから価格を表に引き出して」
- **Composio** → 「Gmailをチェックして返信が必要なものを要約して」
- **Playwright** → 「このページを開いて問い合わせフォームに記入して」
- **Perplexity** → 「これを調査してソースを引用して」

正直に言うと、Firecrawlは4つの中で唯一Claudeに既に組み込まれており、コネクターディレクトリで接続ボタンをクリックするだけで待機している。Codeタブが全く合わないなら、これだけを単独で行えば、約2クリックでClaudeをアップグレードできる。

### 📌 ChatGPTがログイン画面を突破できるようになった

ChatGPTに実際に何かをやってもらおうとするたびに、同じ壁にぶつかってきた。ログイン画面に到達して止まる。これで重要なものはほぼすべて除外されていた。なぜなら、銀行、エネルギー会社、保険、自治体、サプライヤー、請求書はすべてログイン画面の向こうにあるからだ。

その壁が崩れた。**ChatGPT Workのブラウザは、サインインが必要なウェブサイトを使えるようになり**、その後もログインを保持する。

実際の仕組みを説明しよう。見出しがこの点について少し曖昧だったからだ。パスワードは入力しない。エージェントがログイン画面に到達すると停止し、ブラウザをあなたに戻す。あなたが普段通りに自分でサインインする——銀行からのテキストコードも含めて——そして戻す。ChatGPTはユーザーネームもパスワードも見ず、その引き渡し中に入力したものは収集されない。

変化をもたらすのは、その次に起こることだ。**セッションが生き続ける**。一度サインインすれば、次に何かを頼む時もサインインしたままなので、毎回そのやり取りを繰り返す必要がない。Plus、Pro、Businessで展開中で、ウェブでもスマートフォンでも利用できる。

つまり、今引き受けられる仕事は、あなたが何ヶ月も先延ばしにしてきたものだ。エネルギー会社のアカウントに入って、最安の料金プランかどうか教えて。去年の請求書を見つけてスプレッドシートにまとめて。予約を取って。キャンセルし忘れているものをキャンセルして。実際のことは何でも、実行前に確認を求めるので、勝手にお金を使ったり、気まぐれにフライトを予約したりはしない。

ここで知っておいてほしいのは、**OpenAIのサーバー上に残るライブセッションは、真剣に考えるべき問題**だということ。回避する理由ではないが、考慮すべきだ。ノートパソコンを閉じていてもログインしたままで、OpenAI自身も、チェックがすべてのリスクを除去するわけではないと述べている。だから、つまらないものから始めること。銀行ではなく、エネルギー会社。最悪の場合が午後の無駄で済むもので動作を見て、それからどこまで任せるか決める。

### 💡 投資・ビジネスへの示唆

- **デジタルフットプリント管理の重要性**: 15年前の古いアカウントや投稿が、現在のビジネス・採用・取引の場面で予期せぬリスクとなる可能性。定期的な棚卸しと削除が必須。
- **AIエージェントの実行能力拡張**: 対話型AIから実行型AIへの進化により、ウェブスクレイピング、アプリ連携、ブラウザ自動操作が1つのプロンプトで可能に。業務効率化の大きな飛躍。
- **ログイン後セッション保持のセキュリティリスク**: ChatGPTが銀行・保険など機密性の高いサービスにアクセス可能になる一方、セッションがクラウド上に保持されるリスクを考慮し、段階的導入が賢明。
- **MCP（Model Context Protocol）エコシステムの台頭**: Anthropic主導のMCPが、AIエージェントと外部ツールの標準接続プロトコルとして普及の兆し。今後のAI統合戦略の要。
