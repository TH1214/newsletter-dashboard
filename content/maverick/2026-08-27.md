### 🔍 インターネット上の最古の自分をClaudeに発見させる

約15年前、あなたは完全に忘れ去ったバージョンの自分をインターネット上に残している。一度作って二度と戻らなかったアカウント、2回だけ投稿したフォーラム、あなたの名前が載っている学校やクラブのページ、4つのエントリーで放棄したブログ。どれも何も生み出さなかった。しかしすべてがまだそこにあり、意図的に探しに行った人はほとんどいない。

筆者はこのプロンプトチェーンを組み立て、自分自身に対して実行したところ、2016年の古いゲームコンテンツが掘り起こされた。10年間見ていなかった、完全に考えることをやめていたものだ。

**ステップ1：Claudeを開き、以下を貼り付ける**

```
インターネット上にまだ存在する私に関する最も古いものを見つけてください。私の名前、メールアドレス、使用したことのあるユーザー名を検索し、削除されたページのアーカイブ版を含めて適切に調査してください。最も古いアカウント、プロフィール、フォーラム投稿、写真、クラブや学校や職場のページでの言及、もはや存在しないサイトからのものすべてが必要です。古い順に並べ、それぞれがおよそ何年のものかを教え、リンクを提供してください。私の名前は[あなたのフルネーム]、メールアドレスは[あなたのメール]、使用していた古いユーザー名は[リスト]です。
```

古いユーザー名が重要な役割を果たす部分であり、人々が省略しがちな箇所だ。あなたの名前は明白なものを見つける。14歳のときに選んだユーザー名がそれ以外のすべてを見つけてくれる。なぜならそれが当時実際に投稿していた名前だからだ。

**ステップ2：笑い話から実用的なものに変える**

```
これらすべてを見知らぬ人が見るように見てください。明日誰かが私の名前を検索したら——新しいクライアント、デート相手、これから一緒に働く人——何を見つけ、どんな印象を受けるでしょうか。正直に教えてください。そして、これらのうちどれを削除またはロックすべきか、どれが実際には問題ないか、それぞれを削除する正確な方法を教えてください。
```

返ってくるものの大半は無害で少し面白い。しかし通常、「ああ、これまだ残ってるの?」と思わせるものが1つはある。見つかりたくない写真がある古いプロフィール、2011年のページに載っている住所、忘れていた論争で残したコメント。10分でそれらを消すことができる。

正直な注意点を1つ。公開されているものしか見つけられないため、非公開で投稿したものは出てこないし、すべては見つからない。しかし予想以上に見つかり、自分のタイムラインを読み返すのは奇妙な体験だ。

### ⚙️ Claudeを全く別物に変える4つのコネクタ

ほとんどの人はClaudeをそのまま使っているが、これはドリルを買ってハンマーとしてのみ使うようなものだ。単体では考えることができる。4つのものを接続すれば、実際に行動できるようになる。

どのアカウントにも設定したい4つがこれで、Claudeに届かせたいほぼすべてをカバーする：

**Firecrawl**はどんなウェブサイトも適切に読み取れるようにし、5つの競合サイトから価格を引っ張ってきて表にまとめられる。**Composio**は1つの接続で1,000以上のアプリ——Gmail、Slack、Notion、カレンダー、CRM——を開く。1つずつ追加する必要がない。**Playwright**は実際のブラウザを操作し、コネクタが全くないサイトでクリック、タイピング、フォーム入力を行える。**Perplexity**はライブ調査エンジンに接続し、記憶からではなくソース付きでウェブから回答する。

セットアップが人々を躊躇させる部分だが、そうあるべきではない。なぜなら4つすべてが異なる方法でインストールされ、何も学ぶ必要がないからだ。Claudeに適切に頼めば、全体を自分でやってくれる。

**ステップ1：Claudeデスクトップアプリを開き、上部のCodeタブをクリック。以下を貼り付ける**

```
これらの4つのMCPサーバーを設定してください。すべて自分で実行し、何か必要なときだけ尋ねてください：
1. Playwright — npx @playwright/mcp@latest（無料）
2. Composio — https://connect.composio.dev/mcp（サインインが必要になったら教えてください）
3. Firecrawl — https://mcp.firecrawl.dev/v2/mcp（firecrawl.devからの無料APIキーを尋ねてください）
4. Perplexity — https://api.perplexity.ai/mcp（perplexity.aiからの有料キー——必要かスキップするか尋ねてください）
次に進む前に各接続を確認し、それぞれのテストプロンプトを提供してください。
```

インストールを自分で実行し、本当に何か必要なとき——サインインやキー——に止まって尋ねてくる。コマンドを入力しているのではなく、ただ答えているだけだ。

**ステップ2：Perplexityについて尋ねられたら、スキップすると言う**

これが4つの中で唯一お金がかかるもので、違いを感じるために必要ではない。FirecrawlとComposioは無料アカウント、Playwrightは無料でオープンソース、この3つだけで飛躍的な変化がある。毎日Claudeで本格的な調査を実行するようになったら、後でPerplexityを追加すればいい。

**各コネクタが解放するもの**
- **Firecrawl** → 「これら3つの競合サイトから価格を引っ張って表にして」
- **Composio** → 「Gmailをチェックして、返信が必要なものを要約して」
- **Playwright** → 「このページを開いてお問い合わせフォームに記入して」
- **Perplexity** → 「これを調査してソースを引用して」

正直な注意点を1つ。Firecrawlは4つの中で唯一Claudeに既に組み込まれており、コネクタディレクトリで接続をクリックするだけで待機している。Codeタブがまったく合わない場合は、それだけを単独で行えば、約2クリックでClaudeをアップグレードしたことになる。

### 🔐 ChatGPTがログイン画面を突破できるように

ChatGPTに実際に何かをやってもらおうと頼むたびに、同じ壁にぶつかってきた。ログイン画面に到達して止まる。これはほぼすべての重要なものを除外する。なぜなら銀行、エネルギーアカウント、保険、自治体、サプライヤー、請求書はすべてログイン画面の後ろにあるからだ。

その壁が崩れた。**ChatGPT Workのブラウザがサインインが必要なWebサイトを使えるようになり**、ログイン後もそれを保持する。

実際にどう機能するかを説明する。見出しがこの点について少し曖昧だったからだ。パスワードを入力することはない。エージェントがログイン画面に到達すると止まり、ブラウザをあなたに返す。銀行がテキストで送るコードも含め、いつも通りに自分でサインインし、それから返す。ChatGPTはユーザー名もパスワードも見ることはなく、その受け渡し中に入力した内容は収集されない。

状況を変えるのは次に起こることだ。**セッションが生き続ける**。一度サインインすれば、次に何かを頼んだときもまだサインインしたままなので、タスクごとにそのやり取りを繰り返す必要がない。Plus、Pro、Businessで展開中で、ウェブでもスマホでも使える。

つまり、今引き受けられる仕事は何ヶ月も先延ばしにしてきたものだ。エネルギーアカウントに入って、最も安い料金プランになっているか教えて。昨年の請求書を見つけてスプレッドシートにまとめて。予約を取って。キャンセルし忘れているものをキャンセルして。実際のものはコミットする前に尋ねてくるので、勝手にお金を使ったり、気まぐれにフライトを予約したりすることはない。

**知っておいてほしい部分がこれだ。OpenAIのサーバー上に存在するライブセッションは、本当に考えるべきことであり**、これを避ける理由ではない。ノートパソコンを閉じていてもログインしたままで、OpenAI自身がチェックですべてのリスクを除去できるわけではないと述べている。だから退屈なもので始める。銀行ではなく、エネルギーアカウントで。最悪の場合が無駄な午後で済むもので動作を見て、それからどこまで任せるかを決める。
