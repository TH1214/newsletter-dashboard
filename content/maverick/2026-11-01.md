### 📌 ChatGPTが砂利の山から紛失したイヤホンを発見

これは今年見た中で最も驚くべきChatGPTの使用例の一つだ。

ある父親が日没時に息子と公園から駐車場へ向かっていた。息子が駐車場に向かって走り出したため、父親も後を追って走ったところ、フーディのポケットから白いBoseイヤホンが広大な白い砂利の中に落ちてしまった。白いイヤホン、白い石、薄暗くなる時間帯。10分間探したが見つからなかった。

そこで彼は砂利の写真を撮影してChatGPTにアップロードし、「私のヘッドホンを見つけられますか？白いBoseイヤホンです」と尋ねた。

ChatGPTは写真をズームインしてスキャンしたが、最初の試行では見つけられなかった。しかし何かをでっち上げる代わりに、確信が持てないと伝え、より近い写真を求めた。そこで彼はいくつかのズームイン写真を撮影して送信した。今回ChatGPTは正確な場所に赤い円を付けた写真を返信してきた。全体で5分未満しかかからず、彼のReddit投稿は大きな反響を呼んだ。

私は金曜日にこれを投稿したが、すでに240万回以上の再生回数に達しており、理由は理解できる。ChatGPTが実際に「見る」ことができると気づかせるタイプのものだ。読み書きだけではなく。

この仕組みを理解していない人のために説明すると、写真をアップロードしたとき、ChatGPTは人間のようにざっと見るのではない。画像を小さなセクションに分割して各部分をズームインし、あらゆる角度からイヤホンがどのように見えるかを知っている。そのため属さないもの、つまり荒く不規則な石の海の中にある滑らかで曲線的で光沢のあるプラスチック片を探す。人間の目はどこも「白」に見えて諦める。ChatGPTはその一つの形状を求めて隅々までチェックする。そして確信が持てないときは推測する代わりにより良い写真を求めた。ChatGPTが円で囲んだものが元の写真と一致するか確認すること、時々間違える可能性があるためだ。

これは時々しか必要としない特殊な使用例かもしれないが、この種の知能で他に何ができるか考えさせられる。写真で一つだけ異常なものを見つけることは、レンタカーを運転する前に傷を見つける、長いレシートのミスを発見する、ラベルの小さな文字を読む、または必要なコンセントを探すために部屋の写真をチェックすることと同じスキルだ。写真に撮れるものなら、ChatGPTに質問できる。

### 📌 ChatGPTがあなたに支払われるべき訴訟を見つける

今、企業があなたにお金を支払う義務があるのに、あなたがそれを知らない可能性が高い。

企業は常に集団訴訟で和解している。携帯電話会社、買い物をした店、データ漏洩があったアプリ。お金は資格があり請求を提出した人全員に支払われるが、ほとんどの人はそもそも知らないため請求しない。そこで私はChatGPTに自分が資格を持つすべての和解を見つけるよう依頼し、存在すら知らなかった和解から452ドルを得た。

以下がその方法だ。

**ステップ1:** Gmailを接続する。ChatGPTで左下の名前をクリックし、Settings → Integrations → Plugins → Browse directoryへ。Gmailを見つけて+をクリックしてサインインする。

**ステップ2:** 新しいチャットを開いて以下を貼り付ける：

「私のメールを調べて、購入したかアカウントを持っていたすべての企業を見つけ、それらをすべての公開中の集団訴訟和解と照合してください」

ChatGPTは何年分ものレシートとアカウントを調べ、現在支払いが行われているすべての訴訟と照合する。

**ステップ3:** 同じチャットで質問する：

「これらのうち実際に資格があるのはどれで、それぞれからいくら得られる可能性があり、期限はいつですか？」

**ステップ4:** ここがコツだ。ChatGPTの上部でChatからWorkに切り替えて言う：

「資格があるすべてのものについて請求を提出してください。それぞれの公式和解ウェブサイトのみを使用し、各請求を送信する前に停止して確認できるようにしてください」

ChatGPTは独自のブラウザを開き、あなたはただ座っているだけですべての請求フォームに記入する。ほとんどは名前、住所、メールアドレスのみを求め、購入証明は通常すでに受信トレイにある。

そしてボーナスがある。「毎週新しい和解をチェックして、資格ができた瞬間に教えてください」と言えば、ChatGPTが監視し続ける。

いくつかの簡単なルールがある。実際に購入または使用したもののみを請求すること、回答が真実であることを確認しているためだ。提出は常に無料なので、サイトが支払いを求めたり、社会保障番号や銀行ログインを求める場合は詐欺だ。そして支払いには数か月かかる、裁判所が最初にすべてを承認する必要があるためだ。

### 📌 AI検出器にフラグを立てられないよう書き方を変える人々

AI検出器は現在、人々の執筆が人間としてカウントされるかどうかを決定しており、それが全員の書き方を変えている。

Bloombergはこれに関する大きな記事を公開したばかりで、それは一冊の本から始まる。今年初め、世界最大の出版社の一つであるHachetteは、AI検出器Pangramが78%がAI執筆のように見えると述べた後、発売直前にShy Girlというホラー小説を撤回した。これは大手出版社からのAIをめぐって撤回された最初の小説と考えられている。著者のMia Ballardは、AIの使用を否定し、フラグが立てられた箇所は雇った編集者によるものだと述べている。しかしその時点でインターネットはすでに結論を出していた。

そして今、一般の人々が反応している。作家や学生は、検出器にフラグを立てられないよう書き方を変えている。エムダッシュ（長いダッシュ—）が大きなもので、AIが非常に頻繁に使用するため、検出器はそれを赤旗のように扱う。人々は、単一のエムダッシュを入れ替えるだけで、まったく同じテキストが「AI」から「人間」に反転することを示している。

正直に言うと、これはやや異常だと思う。人間がロボットのように聞こえないよう執筆を編集するところまで来た。このニュースレターで私がエムダッシュを決して使わないことに気づいたかもしれないが、正直なところ、それが大きな理由だ。

私の見解はこうだ。AI検出器は推測であり、証明ではない。パターンを見てパーセンテージを示す。それは有用だが、学生がクラスで不合格になるか本が撤回されるかを決定する唯一のものであってはならない。

したがって、学校や仕事で重要なものを書く場合、私がすることは以下だ：

**Google Docsで書く。** バージョン履歴を自動的に保存する（File → Version history → See version history）、これは数時間または数日にわたって行ったすべての編集を示す。これは誰かが機械が書いたと言った場合のレシートだ。

**AIを使用する場合、どのように使ったかを率直に述べる。** 「私が書いて文法をチェックするためにChatGPTを使った」は「ChatGPTが書いた」とはまったく異なるものであり、最初に言うことは後で自分を弁護するよりも良い。

### 📌 ClaudeがInstagram DMに自動返信できるようになった

ClaudeをInstagramに接続して、受信するすべてのDMに返信させることができるようになった。

これはManyChatと呼ばれるツールを通じて機能し、Metaによって公式に承認されているため、アカウントが禁止される心配はない。Claudeを一度接続し、自分が誰でどのように人々と話したいかを伝えれば、24時間年中無休で数秒でDMに答える。

仕組みは以下の通り：

**ステップ1:** Instagramはビジネスまたはクリエイターアカウントである必要がある（Instagram Settings → Account typeで無料で切り替え可能）。ManyChatにサインアップしてInstagramを接続する。AI部分にはManyChat Proが必要だ。

**ステップ2:** Claude APIキーを取得する。platform.claude.com → API Keys → Create Keyに移動してコピーする。これはClaude サブスクリプションとは別で使用量に応じて支払うため、5ドルまたは10ドルのクレジットを追加して月次制限を設定する。

**ステップ3:** ManyChatでSettings → Integrationsに移動し、Claudeカードにキーを貼り付けてConnectをクリックする。

**ステップ4:** 任意のDMまたはコメントで実行される自動化を構築し、アクションブロックを追加してClaudeを選択する。次に、自分が誰で、何をしていて、どのように人々と話したいかを正確に書き出す。これが実際に違いを生む部分なので、時間をかけること。

**ステップ5:** ここがコツだ。Claudeが約束したものを誰かに送信する前に、フォローしているかどうかを確認させる。フォローしていない場合は、最初にフォローするよう求め、その後送信する。これで全てのDMが新しいフォロワーを得るチャンスになる。

そして無料配布以上のものだ。毎日受ける同じ10の質問に答えさせたり、誰かに適切な製品を推奨したり、カレンダーに直接電話を予約したり、ビジネスのリードを選別したり、基本的なカスタマーサポートを処理したりできる、すべてあなたが眠っている間に。

クリエイターまたはInstagramでビジネスを運営している場合、ManyChatを強く推奨する。私は彼らと提携しており、2027年に予定している大きなことに本当に興奮している。ManyChatは正直なところ、おそらくあなたが最初にこのニュースレターにたどり着いた方法だ。つまり、InstagramでDMを送って2秒で返信を得たことがあるなら...残念ながら伝えるのは私だが、それは私ではなかった。ごめんなさい。
