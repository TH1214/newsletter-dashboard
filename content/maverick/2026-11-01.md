### 📌 ChatGPTが砂利の山の中から紛失したイヤホンを発見

これは今年見た中で最もクレイジーなChatGPTの使用例だ。

ある父親が息子と公園を出ようとしていた時、ちょうど日が沈みかけていた。息子が駐車場に向かって走り出したため、彼も後を追って走った。その際、パーカーのポケットから白いBoseのイヤホンが巨大な白い砂利のエリアに落ちてしまった。白いイヤホン、白い石、そして暗くなりつつある状況。彼は10分間探したが見つけられなかった。

そこで砂利の写真を撮り、ChatGPTにアップロードして「ヘッドホンを見つけられる? 白いBoseのイヤホンなんだ」と尋ねた。

ChatGPTはズームインして写真をスキャンしたが、最初の試行では見つけられなかった。しかし、でたらめを言う代わりに、確信が持てないと伝え、より近い写真を求めた。そこで彼はズームインした写真を数枚撮って送った。今度はChatGPTが正確な場所に赤い円を描いた写真を返してきた。全体で5分もかからなかった。彼のReddit投稿は大きな話題となった。

私は金曜日にこれを投稿したが、すでに240万回以上の視聴回数に達している。その理由は分かる。ChatGPTが実際に「見る」ことができる、単に読み書きするだけではないということを実感させるような事例だ。

何が起こっているのか理解できない方のために説明しよう。写真をアップロードすると、ChatGPTは人間のようにさっと見るのではない。画像を小さなセクションに分割し、それぞれにズームインする。そしてイヤホンがあらゆる角度からどのように見えるかを知っている。だから、属していないものを探す。ギザギザした粗い石の海の中にある、滑らかで曲線的で光沢のあるプラスチックの一片を。人間の目は「白」があちこちにあると認識して諦める。ChatGPTはその一つの形状を求めて隅々までチェックする。そして確信が持てなかった時は、推測する代わりにより良い写真を求めた。ただし、時折間違えることもあるので、ChatGPTが円で示した箇所を元の写真と照合して確認すること。

これはたまにしか必要としない特殊な使用例かもしれない。しかし、この種の知能で他に何ができるかを考えさせられる。写真の中で違和感のある一つを見つけることは、レンタカーに乗る前に傷を見つける、長いレシートの間違いを発見する、ラベルの小さな文字を読む、部屋の写真で必要なコンセントを確認するといったスキルと同じだ。写真に撮れるものなら、ChatGPTに尋ねることができる。

### 📌 ChatGPTがあなたに支払われるべき訴訟を発見

今この瞬間、企業があなたにお金を支払う義務があるかもしれないが、あなたはそれを知らない。そんな可能性が高い。

企業は常に集団訴訟で和解している。あなたの携帯電話会社、買い物をした店、データ漏洩があったアプリなど。和解金は資格がある人全員で、請求を提出した人に支払われる。ほとんどの人は請求しない。なぜなら、そのことを聞いたことすらないからだ。そこで私はChatGPTに、自分が資格を持つすべての和解金を見つけるよう依頼した。その結果、存在すら知らなかった和解金から$452を獲得した。

以下がその方法だ。

**ステップ1:** Gmailを接続する。ChatGPTで左下の自分の名前をクリックし、Settings → Integrations → Plugins → Browse directoryと進む。Gmailを見つけて+をクリックしてサインインする。

**ステップ2:** 新しいチャットを開き、以下を貼り付ける:

「私のメールを確認して、購入したことがある、またはアカウントを持っていたすべての企業を見つけ、それらを現在進行中のすべての集団訴訟和解と照合してください」

ChatGPTは何年分ものレシートとアカウントを調べ、現在支払いが行われているすべての訴訟と照合する。

**ステップ3:** 同じチャットで次のように尋ねる:

「この中で実際に資格があるのはどれで、それぞれからいくら受け取れて、期限はいつですか?」

**ステップ4:** ここからがコツだ。ChatGPTの上部で、ChatからWorkに切り替えて、次のように言う:

「資格があるすべての請求を提出してください。それぞれ公式の和解ウェブサイトのみを使用し、各請求を送信する前に停止して確認させてください」

ChatGPTは独自のブラウザを開き、あなたがただ座っている間にすべての請求フォームを記入してくれる。ほとんどは名前、住所、メールアドレスだけを尋ねるもので、購入証明は通常すでに受信トレイにある。

さらにボーナスがある。「毎週新しい和解金を確認して、資格が生じた瞬間に教えてください」と言えば、ChatGPTがあなたのために監視し続ける。

いくつかの簡単なルールがある。実際に購入または使用したものだけを請求すること。なぜなら、あなたは回答が真実であることを確認しているからだ。提出は常に無料なので、サイトが支払いを求めたり、社会保障番号や銀行ログインを求めたりする場合、それは詐欺だ。そして支払いには数ヶ月かかる。裁判所が最初にすべてを承認する必要があるためだ。

### 📌 人々がAI検出器にフラグを立てられないよう文章の書き方を変えている

AI検出器が人々の文章が人間のものかどうかを決定するようになり、それが誰もが文章を書く方法を変えている。

Bloombergはこの件について大きな記事を公表したばかりで、それは一冊の本から始まる。今年初め、世界最大の出版社の一つであるHachette(アシェット)は、AI検出器のPangramが78%がAIで書かれているように見えると判定した後、「Shy Girl」というホラー小説を発売直前に撤回した。大手出版社からの小説がAIを理由に撤回されたのは初めてと考えられている。著者のMia Ballard(ミア・バラード)はAIの使用を否定し、フラグが立てられた部分は雇った編集者によるものだと述べている。しかしその時点で、インターネットはすでに結論を出していた。

そして今、一般の人々が反応している。作家や学生は、検出器にフラグを立てられないよう文章の書き方を変えている。エムダッシュ(長いダッシュ—)が大きな問題だ。AIがそれを頻繁に使用するため、検出器はそれを警告フラグのように扱う。たった一つのエムダッシュを入れ替えるだけで、まったく同じテキストが「AI」から「人間」に判定が変わることを人々は示している。

正直に言うと、これはちょっとおかしいと思う。人間がロボットのように聞こえないよう文章を編集する段階に来ている。私がこのニュースレターでエムダッシュを使わないことに気づいたかもしれないが、正直なところ、それが大きな理由だ。

私の見解はこうだ。AI検出器は推測であり、証明ではない。パターンを見てパーセンテージを示す。それは有用だが、学生が授業で落第するか、本が撤回されるかを決定する唯一の要素であってはならない。

だから、学校や仕事で重要な文章を書く場合、私ならこうする:

Googleドキュメントで書く。自動的にバージョン履歴が保存される(File → Version history → See version history)。これにより、数時間または数日にわたって行ったすべての編集が表示される。もし誰かが機械が書いたと言った場合、これがあなたの証拠となる。

AIを使用する場合は、どのように使ったかを明確にする。「私が書いて、ChatGPTに文法をチェックさせた」と「ChatGPTが書いた」はまったく異なる。最初から言っておけば、後で自分を守る必要がなくなる。

### 📌 ClaudeがあなたのInstagram DMに自動応答できるようになった

ClaudeをInstagramに接続し、受け取るすべてのDMに返信させることができるようになった。

これはManyChatというツールを通じて機能する。これはMetaによって公式に承認されているため、アカウントが禁止される心配はない。Claudeを一度接続し、自分が誰で、人々とどのように話したいかを伝えれば、24時間365日、数秒でDMに応答する。

仕組みは以下の通り:

**ステップ1:** Instagramはビジネスまたはクリエイターアカウントである必要がある(Instagram Settings → Account typeで無料で切り替え可能)。ManyChatに登録してInstagramを接続する。AI部分にはManyChat Proが必要。

**ステップ2:** Claude APIキーを取得する。platform.claude.com → API Keys → Create Keyに行き、コピーする。これはClaudeサブスクリプションとは別で、使用量に応じて支払う。$5または$10のクレジットを追加し、月間制限を設定する。

**ステップ3:** ManyChatで、Settings → Integrationsに行き、Claudeカードにキーを貼り付けてConnectをクリックする。

**ステップ4:** 任意のDMまたはコメントで実行される自動化を構築し、アクションブロックを追加してClaudeを選択する。次に、自分が誰で、何をしていて、人々とどのように話してほしいかを正確に書き出す。これが実際に違いを生む部分なので、時間をかけること。

**ステップ5:** ここからがコツだ。Claudeが誰かに約束したものを送る前に、その人があなたをフォローしているかチェックさせる。フォローしていない場合は、まずフォローするよう依頼してから送る。これで、すべてのDMが新しいフォロワーを獲得するチャンスになる。

そして、無料配布だけではない。毎日受ける同じ10の質問に答えさせたり、誰かに適した製品を推奨したり、カレンダーに直接通話を予約したり、ビジネスのリードを選別したり、基本的なカスタマーサポートを処理したりできる。すべてあなたが寝ている間に。

クリエイターまたはInstagramでビジネスを運営している場合、ManyChatを強く推奨する。私は彼らとパートナーシップを組んでおり、2027年に向けて本当に楽しみにしている大きなことがある。正直なところ、ManyChatはおそらくあなたが最初にこのニュースレターを購読するきっかけとなったツールだ。つまり、もしあなたがInstagramで私にDMを送って2秒で返信を受け取ったことがあるなら...残念ながらお伝えしなければならないが、それは私ではなかった。ごめん。
