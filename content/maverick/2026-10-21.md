### 📌 今日すぐ実行すべきこと：ChatGPTが請求書と闘う

ある家族が最近、AIを使って19万5,000ドルの病院請求書を約3万3,000ドルまで削減した。病院は同じ処置を二重請求し、誤ったコードを使用していたが、AIが1行ずつ確認しなければ誰も気づかなかっただろう。

あなたもおそらくどこかで過払いしている。誰も教えてくれなかった値上げ、静かに終了したプロモーション、免除してもらえる延滞料、すでにキャンセルしたものへの請求、医療請求書の間違い。企業はあなたが決して反論しないことを見込んでいる。

今やChatGPTがあなたの代わりに闘ってくれる。支払っているすべての請求についてインタビューし、過払いしているすべての箇所を見つけ、Gmailから直接それぞれと闘うメールを書いてくれる。

**ステップ1**: ChatGPTを開き、以下を貼り付ける。Gmailがまだ接続されていない場合は、接続を求められる。

```
支払っているすべての請求についてインタビューしてください：家賃または住宅ローン、公共料金、電話、インターネット、保険、サブスクリプション、クレジットカード、医療費および歯科費。@Gmail 過去6ヶ月の請求書、領収書、明細書を検索して、私が覚えていない情報を埋めてください。次に、支払いすぎているすべての箇所を見つけてください：値上げ、期限切れプロモーション、免除可能な手数料、キャンセルまたは未使用のものへの請求、請求ミス、新規顧客が支払う金額を上回るもの。回収可能な金額順にランク付けした表にまとめ、何が間違っているか、何を求めるべきかを正確に示してください。
```

この表が現実を突きつける。通常、予想よりはるかに多くの金額になる。医療請求書がある場合は、まず処置コード付きの詳細請求書を医療提供者に求める。間違いはそこに隠れているからだ。

**ステップ2**: 同じチャットで以下を送信し、闘わせる：

```
表のすべての請求と闘ってください。@Gmail 各企業に個別のメールを書き、私のアカウント向けに作成し、何が間違っているか、何を求めているか（返金、クレジット、手数料免除または低料金）、いつまでに回答が必要かを正確に説明してください。各メールは短く、丁寧で、毅然としたものにしてください。すべてのメールを見せて、私のOKを待ってから送信してください。
```

**ステップ3**: 返信が来たら、同じチャットに戻る：

```
@Gmail これらのメールへの返信を確認してください。それぞれについて、彼らが何を提供したか、受け入れるべきかを教え、私の返信を書いてください。拒否された場合は、より強い2通目のメールを書くか、誰にエスカレーションすべきか教えてください。
```

すべてのメールは送信前にあなたが承認するので、あなたの許可なしに何も送信されない。すべての企業がイエスと言うわけではないが、尋ねて失うものは何もなく、イエスと言った企業は毎月あなたに払い戻し続ける。

正直な注意点。Gmailの接続は、すべてのプランやすべての国でまだ利用できない。利用できない場合は、代わりに最近の明細書をいくつかアップロードすれば、ChatGPTがメールを書いてくれるので、コピーして自分で送信できる。

### 📌 試してみよう：Claudeが動画を編集してくれる

Claudeが動画を編集してくれるようになった。あなたが話している動画を渡せば、字幕を追加し、すべての無音部分をカットし、画面上の重要な瞬間をアニメーション化する。その後、変更したいことを伝えるだけでよい。

Claudeをあなた専用のエディターに変える無料のVideo Editorプラグインを作成した。プラグインは基本的に、Claudeに新しいスキルを教える無料アドオンだ。1回インストールすれば、約1分で完了する。正確な手順は以下の通り。

**ステップ1**: claude.com/downloadで無料のClaude デスクトップアプリをダウンロードし、サインインする。これはMacまたはWindowsコンピューターのデスクトップアプリでのみ機能し、ウェブサイトやスマートフォンでは機能しない。Claude Pro（月額20ドル）以上が必要。

**ステップ2**: アプリで、左サイドバーの「Customize」をクリックし、「Plugins」をクリック。

**ステップ3**: 「Add」をクリックし、「Add marketplace」、次に「Add from a repository」をクリック。以下のアドレスを貼り付けて確認：

```
https://github.com/maverickmaltin/mavgpt-plugins
```

**ステップ4**: リストからVideo Editorを見つけて追加。これでインストールは完了で、1回だけ行えばよい。

**ステップ5**: デスクトップに「Video Edits」というフォルダを作成し、動画をドロップする。Claudeに戻り、上部の「Code」をクリックし、「Local」を選択し、「Select folder」をクリックして「Video Edits」を選ぶ。次にモデルメニューで「Opus 5.5」を選び、effortを「Max」に設定。

**ステップ6**: `/video-editor:start`と入力してエンターを押す。

Claudeがあとは引き継ぐ。必要な無料ツールをインストールし、スタイルについていくつか簡単な質問をし（字幕サイズ、色、カットの密度）、回答を保存するので、すべての動画があなたのスタイルで仕上がる。次に編集全体のストーリーボードを表示し、プレビューをレンダリングし、自分のフレームの間違いをチェックして引き渡す。

最高の部分は、普通の言葉で変更できることだ。「字幕を大きくして」「『insane』と言うときにズームインして」「価格の部分を戻して」。変更が気に入ったら「これを私のスタイルに追加」と言えば、以降のすべての動画で覚えてくれる。

いくつかのヒント。最初の編集には30〜90秒のクリップから始め、権利を持つ音楽のみを使用する。`/video-editor:start`が何もしない場合は、Codeタブで新しいセッションを開始してプラグインを読み込む。Claudeはあなたの代わりに何も投稿しないので、必ず自分で確認して投稿する。

### 📌 保存版：あなたをパワーユーザーにする5つのChatGPT秘密コード

ChatGPTの回答を完全に変える5つの秘密コードを紹介する。それぞれ1語を入力するだけで、ChatGPTがはるかに便利なものに変わる。

**1. /bodyguard**. リンク、契約書、知らない番号からのテキストなど、怪しいものを貼り付ければ、ChatGPTが罠にかかろうとしているか、すべての危険信号を教えてくれる。

**2. /flip**. 所有物の写真をアップロードすれば、ChatGPTが現在の転売価格と正確な販売方法を教えてくれる。

**3. SHOWME**. どんな質問にも追加すれば、文字の壁ではなく、ChatGPTが答えをビジュアルに変える：チャート、図、脳が実際に保持するもの。

**4. /interview**. 応募している仕事を貼り付ければ、ChatGPTが実際の採用担当者のように質問攻めにし、質問に次ぐ質問で、本当に準備ができるまで続ける。

**5. TRIPLECHECK**. 重要なことの最後にこれを付ければ、ChatGPTが答えを渡す前に3つの異なる方法で自分の答えを再検証するので、間違いがあなたを捕まえる前に捕まえられる。

コードを入力して、あなたのものを貼り付けるだけ。次に受け取る「うますぎる」テキストで/bodyguardを試してみよう。

### 📌 AI最新情報：Anthropicが6ヶ月で800億ドルを失った

Claudeを開発するAnthropicが、6ヶ月で800億ドルを失った。これは、Wall Street Journalが今週入手した上場準備書類からのものだ。昨年の同じ6ヶ月間では130億ドルを失った。そして、人々が次に何が起こるかに実際のお金を賭ける大手予測市場の1つでは、トレーダーは現在、Anthropicが2029年末までに破産を発表する確率を約4分の1（来年末までに9%）と見ている。

しかし、ほとんどの見出しが省略している部分がある。その損失の約720億ドルは、Anthropicが実際に使ったお金ではない。会計上の費用だ。Anthropicが調達した資金の多くは転換社債として入ってきた。これは基本的に後で株式に転換される融資だ。Anthropicの評価額が大幅に上昇したため、これらの社債は帳簿上ではるかに価値が高くなり、会計規則ではそれを損失として計上する。つまり、この「損失」の大部分は、会社がより価値あるものになったことから来ている。

実際のビジネスは急成長している：6ヶ月で163億ドルの収益、1年前の11億ドルから増加。しかし、同時期に計算能力に約90億ドルを費やし、6,000億ドル以上の計算契約に署名しており、早ければ11月に最大2兆ドルの評価額で上場することを目指していると報じられている。

私の見解は以下の通り。Apple、Google、Metaがすべて、AIで遅れを取っていると誰もが言うが、私は本当にそうは思わない。彼らは座って見守っていると思う。OpenAIとAnthropicは、このレースに勝つために稼ぐよりはるかに多く使っており、大企業はレースに勝たなくてもトップに立つことができる。Anthropicのお金が実際にどこに行くかを見てみよう：これらの計算契約のうち約1,110億ドルがGoogleに、1,100億ドルがAmazonに、310億ドルがMicrosoftに行く。つまり、Anthropicが次のClaudeを構築してお金を失うたびに、その大部分が彼らのポケットに入る。そして、検索広告、iPhone、Instagramがすでに彼らに大金をもたらしているため、待って、実際に何が機能するかを確認し、すでに彼らのものを使っている数十億人の前にそれを置くことができる。

したがって、Claudeは近いうちにどこにも行かないが、1つのツールに固執しないこと。AIファイルシステムを適切に設定し、AIエージェントの使い方を学んでおけば、必要に応じて午後のうちに動き続けて切り替えることができる。
