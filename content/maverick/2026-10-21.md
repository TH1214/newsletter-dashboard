### 📌 ChatGPTが請求書の交渉を代行

ある家族は最近、AIを使って19万5,000ドルの病院請求書を約3万3,000ドルまで減額した。病院は同じ処置を二重請求し、誤ったコードを使用していたが、AIが1行ずつ精査しなければ誰も気づかなかっただろう。

あなたもおそらくどこかで過剰に支払っている。誰も教えてくれなかった値上げ、静かに終了したプロモーション、免除してもらえる延滞料、既にキャンセルしたはずのサービスへの請求、医療請求書の誤り。企業はあなたが決して反論しないことを見込んでいる。

今やChatGPTがあなたの代わりに戦ってくれる。ChatGPTはあなたが支払う全ての請求書についてヒアリングし、過剰請求されている場所を全て見つけ出し、Gmail経由で各企業への交渉メールを作成する。

**ステップ1:** ChatGPTを開き、以下を貼り付ける。Gmailがまだ接続されていない場合は、接続を求められる。

```
私が支払っている全ての請求書についてヒアリングしてください：家賃または住宅ローン、光熱費、電話、インターネット、保険、サブスクリプション、クレジットカード、医療・歯科の請求書。@Gmail 過去6ヶ月の請求書、領収書、明細書をメールから検索して、私が覚えていない内容を補完してください。次に、私が本来より多く支払っている場所を全て見つけてください：値上げ、期限切れプロモーション、免除可能な手数料、キャンセルまたは未使用サービスへの請求、請求ミス、新規顧客が支払う金額を超えるもの。取り戻せる金額順にランク付けした表を作成し、何が間違っているか、何を要求すべきかを正確に示してください。
```

この表が警鐘となる。通常、予想よりはるかに多くの金額になる。医療請求書が含まれている場合は、まずプロバイダーに処置コード付きの詳細請求書を依頼すること。ミスはそこに隠れている。

**ステップ2:** 同じチャットで以下を送信：

```
今、その表の全ての請求書と戦ってください。@Gmail 各企業に個別のメールを作成し、私のアカウント用に書いてください。何が間違っているか、何を求めているか（返金、クレジット、手数料免除、または低料金）、いつまでに回答が必要かを正確に説明してください。各メールは短く、礼儀正しく、毅然とした内容にしてください。全てのメールを見せて、送信前に私の承認を待ってください。
```

**ステップ3:** 返信が届いたら、同じチャットに戻る：

```
@Gmail これらのメールへの返信を確認してください。それぞれについて、彼らが何を提案したか、それを受け入れるべきかを教えてください。その後、私の返信を作成してください。拒否された場合は、より強い2通目のメールを作成するか、誰にエスカレーションすべきかを教えてください。
```

全てのメールは送信前にあなたが承認するため、あなたの許可なしに送信されることはない。全ての企業が同意するわけではないが、要求することで失うものは何もなく、同意した企業は毎月あなたに払い戻し続ける。

正直に言うと、Gmailの接続は全てのプランや国で利用可能ではない。利用できない場合は、代わりに直近数ヶ月分の明細書をアップロードすれば、ChatGPTがメールを作成するので、自分でコピーして送信できる。

### 📌 Claudeがあなたの動画を編集

Claudeは今やあなたの動画を編集できる。話している動画を渡すと、字幕を追加し、全ての無音部分をカットし、画面上の重要な瞬間にアニメーションを追加する。その後、変更したい内容を伝えるだけでよい。

私はClaudeを自分専用のエディターに変える無料のVideo Editorプラグインを作成した。プラグインは基本的に、Claudeに新しいスキルを教える無料アドオンだ。一度インストールすれば約1分で完了し、手順は以下の通り。

**ステップ1:** claude.com/downloadで無料のClaudeデスクトップアプリをダウンロードしてサインインする。これはMacまたはWindowsコンピューターのデスクトップアプリでのみ機能し、ウェブサイトやスマートフォンでは機能しない。Claude Pro（月額20ドル）以上が必要。

**ステップ2:** アプリで左サイドバーのCustomizeをクリックし、次にPluginsをクリック。

**ステップ3:** Addをクリックし、Add marketplaceをクリックし、次にAdd from a repositoryをクリック。以下のアドレスを貼り付けて確認：

```
https://github.com/maverickmaltin/mavgpt-plugins
```

**ステップ4:** リストからVideo Editorを見つけて追加する。これでインストールは完了で、一度だけ行えばよい。

**ステップ5:** デスクトップにVideo Editsというフォルダを作成し、動画をドロップする。Claudeに戻り、上部のCodeをクリックし、Localを選択し、Select folderをクリックしてVideo Editsを選択。次にモデルメニューでOpus 5.5を選択し、effortをMaxに設定。

**ステップ6:** /video-editor:startと入力してEnterキーを押す。

Claudeが引き継ぐ。必要な無料ツールをインストールし、スタイルについていくつかの簡単な質問をし（字幕サイズ、色、カットの詰め具合）、回答を保存するため、全ての動画があなたのスタイルで仕上がる。次に編集全体のストーリーボードを表示し、プレビューをレンダリングし、自分のフレームにミスがないか確認して引き渡す。

最良の点は、変更を平易な言葉で伝えられることだ。「字幕を大きくして」「『insane』と言うときにズームイン」「価格についての部分を戻して」。変更が気に入ったら「これをスタイルに追加」と言えば、以降の全ての動画に記憶される。

いくつかのヒント。最初の編集には30〜90秒のクリップから始め、権利を持つ音楽のみを使用すること。/video-editor:startが何も起こさない場合は、Codeタブで新しいセッションを開始してプラグインを読み込む。Claudeはあなたの代わりに何も投稿しないので、必ず自分で視聴して投稿すること。

### 📌 ChatGPTをパワーユーザーにする5つの秘密コード

ChatGPTの秘密コードを5つ紹介する。これらは回答を完全に変える。各コードは1語を入力するだけで、ChatGPTをはるかに便利なものにする。

1. **/bodyguard**: リンク、契約書、知らない番号からのテキストなど、怪しいものを貼り付けると、ChatGPTが騙されようとしているか、全ての警告サインを教えてくれる。

2. **/flip**: 所有している物の写真をアップロードすると、ChatGPTが現在の転売価格と正確な販売方法を教えてくれる。

3. **SHOWME**: 任意の質問に追加すると、テキストの壁の代わりに、ChatGPTが回答を視覚化する：チャート、図、脳が実際に記憶するもの。

4. **/interview**: 応募する仕事を貼り付けると、ChatGPTが実際の採用担当者のように質問攻めにし、本当に準備が整うまで続ける。

5. **TRIPLECHECK**: 重要なことの最後に付けると、ChatGPTが自分の回答を3つの異なる方法で再検証してから提供するため、ミスに気づかれる前に自分で捕まえられる。

コードを入力して内容を貼り付けるだけ。次に「うますぎる話」のテキストが来たら/bodyguardを試してみよう。

### 📌 Anthropicが6ヶ月で800億ドルを損失

Claudeを開発するAnthropicは、6ヶ月で800億ドルを失った。これはWall Street Journalが今週入手した同社の上場に向けた書類草案からのものだ。昨年の同期間では130億ドルの損失だった。そして主要な予測市場の一つでは、人々が実際のお金を賭けており、トレーダーはAnthropicが2029年末までに破産を発表する確率を約4分の1（来年末までには9%）と見ている。

しかし、ほとんどの見出しが省略している部分がある。この損失の約720億ドルは、Anthropicが実際に支出した金額ではない。これは会計上の費用だ。Anthropicが調達した資金の多くは転換社債として入ってきており、これは基本的に後で株式に転換される融資だ。Anthropicの評価額が急上昇したため、これらの社債は書類上ではるかに価値が高くなり、会計規則ではこれを損失として計上する。つまり、この「損失」の大部分は、企業がより価値あるものになったことから来ている。

実際のビジネスは急成長している：6ヶ月で163億ドルの収益、前年の11億ドルから増加。しかし同期間に計算能力に約90億ドルを費やしており、6,000億ドル以上の計算契約に署名し、早ければ11月に最大2兆ドルの評価額で上場を目指していると報じられている。

私の見解はこうだ。誰もがApple、Google、Metaは AI で遅れを取っていると言うが、私はそうは思わない。彼らは座って見ているのだと思う。OpenAIとAnthropicは稼ぐ以上に費やしてこのレースに勝とうとしているが、大企業はレースに勝たなくても頂点に立つことができる。Anthropicのお金が実際にどこに行くか見てみよう：これらの計算契約の約1,110億ドルがGoogleに、1,100億ドルがAmazonに、310億ドルがMicrosoftに行く。つまり、Anthropicが次のClaudeを構築してお金を失うたびに、その大部分が彼らのポケットに入る。そして検索広告、iPhone、Instagramは既に彼らに大金を稼いでいるため、待つ余裕があり、実際に何が機能するかを見て、既に数十億人が使っている製品の前に配置できる。

つまり、Claudeはすぐにはなくならないが、一つのツールに固執しないこと。AIファイルシステムを適切にセットアップし、AIエージェントの使い方を学んでおけば、必要に応じて午後のうちに移行し続けられる。
