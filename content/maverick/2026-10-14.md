### 📌 ChatGPTの4つの秘密画像コード

数週間前に画像コードをいくつか紹介したが、今回は追加で4つを紹介する。自分の写真をアップロードして以下のコードを入力するだけで使える。ゴーストのように歩く効果、パパラッチ風の撮影、床から見上げたような奇妙なレンズ効果などが得られる。

同じ元写真を使って結果を比較するのがおすすめ。各スタイルで新しいチャットを開始すると、前回の効果が次に混ざるのを防げる。

**1. /ghost-walk**  
ぼやけた半透明の動き、カメラが歩いているあなたの複数の瞬間を一枚の写真に収めたような効果。効果が広がるスペースがあるよう、全身写真を使うのがベスト。

**2. /paparazzi-editorial**  
レストランから出てきて、準備ができていないうちに撮られたような雰囲気。少し混沌として、少しドラマチック。有名人になるよりかなり安上がり。

**3. /worms-eye-wide**  
靴が大きく見え、遠近感が引き伸ばされ、端で建物が曲がる効果。タイトにトリミングされた自撮りより、立っている写真の方が効果が出やすい。

**4. /fire-fade**  
画像の周囲にドラマチックな炎の効果がつきつつ、本人は元のまま。やりすぎた場合は「炎を減らして、光る燃えかすを増やして」と依頼可能。

これらのコード実行後も会話を続けられる。「元の服装を保持して」「効果をもっと控えめに」「元の写真と同じ照明を使って」などと指示できる。一度で完璧な結果を得る必要はない。

### 📌 OpenAI従業員がFBIに逮捕された事件

OpenAI社内のテレビの裏に録音機が隠されていたとされる。

FBIは10月9日、サンフランシスコのオフィス内の役員会議室で録音デバイスが発見された後、OpenAIのエンジニアを逮捕した。検察は昨日この事件を発表し、詳細は予算が怪しいスパイ映画のようだ。

訴状によれば、録音機はテレビの裏に接続され、**トイレットペーパーで隠されていた**。OpenAIは9月30日にこれを発見。検察によると、従業員は後日戻ってテレビの裏を確認し、警備スタッフは彼の財布とIDが入ったバッグの中から2台目の類似録音機を発見した。これらは容疑であり、有罪判決は出ていない。

さらに2026年らしい部分もある。検察によれば、その従業員の配偶者に関連するチャットボットアカウントが、録音機の製作と隠し方について質問するのに使われていた。そしてOpenAIは、**同社のAIがデバイスを調査し、どこから来たかを追跡するのを助けた**と述べており、従業員の特定につながった。

つまりAIが録音機の隠し方を誰かに教え、その後会社が誰が設置したかを突き止めるのを助けた可能性がある。OpenAIは従業員を解雇し、顧客データ、ソースコード、訓練済みモデルが不正にアクセスされたり持ち出されたりした兆候はないとしている。

Reddit上では、これがAIの有用性を示すのか、OpenAIがFBI逮捕を製品デモに変えたのかで議論が分かれている。私は両方とも真実だと思う。AIが調査を助けたなら有用だ。ただしChatGPTが単独で事件を解決したわけではない。同社はモデルが実際にどれだけの作業をしたか十分に説明していない。

対照的な部分が印象的だ。世界で最も先進的な技術を構築する企業の1つが、テレビの裏にトイレットペーパーで包まれた録音機という問題に直面している。AIをより賢くするために数十億ドルを費やしても、結局は誰が部屋に入れるかという問題に行き着く。

### 📌 Claudeからより良い回答を得る方法

Claudeが悪い回答ばかり返す場合、この方法を試す価値がある。

GitHub上で**Arena skill**というスキルを見つけ、テストしてみた。結果はかなり衝撃的だ。

基本的に、1つのタスクを与えると、100体のClaudeエージェントを起動し、それぞれ異なるアプローチでその正確なタスクに取り組む。

彼らは回答を比較し、弱点を指摘し、数回のラウンドを通じて作業を改善する。最強の回答が次に進み、最終的に勝者が残る。同じチャットに「改善して」と何度も頼むのではなく、異なるアイデアを互いにテストさせる仕組みだ。

これだけのClaudeを1つの問題に投入すると、**使用量を大きく消費する**。スキル自体は無料だが、まずは15エージェントから始めて、本当に詰まった問題に大規模実行を取っておくのが良い。

しかし、すでに何時間も費やした大きな問題がある場合、**100体全員を投入する価値はある**。特にClaude Max 5x（月額100ドル）やMax 20x（月額200ドル）を使っている場合、Proより多くの使用量があるため、その追加容量を重要なことに使う考え方だ。上限はあるが、その追加容量を意味のあることに使うのが狙いだ。

一般的すぎる提案、うまくいかない見出し、いくつかの方向性を比較したい計画などを考えてみてほしい。こうしたタスクこそ、追加の努力が何度もやり取りする午後を節約できる種類のものだ。

**セットアップ方法**

**ステップ1:** Claudeデスクトップアプリで Claude Code を開く。Claude Codeを含む有料プランが必要。執筆や計画にも使えるので、名前で敬遠しないように。

**ステップ2:** このリンクを貼り付けて、Claudeにスキルのインストールを依頼する：

```
https://github.com/Jakeschincariol/arena-skill Install this skill, then confirm /arena works. Don't start a tournament yet.
```

インストール後は、何か作業させたいときにいつでも /arena が使える。

**ステップ3:** 明確な指示を1つ与え、15エージェントに設定する。以下が出発点：

```
/arena --agents 15 Improve this draft: [ドラフトを貼り付け]. It's for [対象読者], and I want it to [目標]. Keep it under [文字数] words. Preserve these facts: [事実]. Avoid [元の嫌だった点]. Compare different approaches, then give me the winning version and explain why it won.
```

より大きな問題の場合、同じプロンプト内の `--agents 15` を `--agents 100` に変更する。

人に手伝ってもらうときと同じ文脈を与える。これは誰向けか？何を残す必要があるか？最初のバージョンで気に入らなかった点は？これらを明確にするほど、異なるアプローチがより有用になる。

最終判断は自分で下す。Claudeも回答を判定しているので、使う前に勝者を確認すること。しかし同じ回答の微妙なバリエーションばかり得ている場合、これにより何か違うものを試す理由が生まれる。
