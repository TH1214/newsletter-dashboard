### 📌 ChatGPTで実際に住むべき場所を見つける

ほとんどの人は、自分が住む場所を選んでいない。そこで生まれたか、仕事で移動したか、誰かについていったか、その年の家賃が安かったから——そして気づけば15年が経っている。地球上のあらゆる都市の中から、実際に座って選んだ人はほとんどいない。そして多くの人は、どこかもっと自分に合う場所があるのではないかという静かな疑念を抱いている。

そこでChatGPTが役立つかもしれない。筆者は2つのプロンプトを作成した。1つ目は出生時刻と場所を尋ね、アストロカートグラフィー（占星地図）を使ってその正確な瞬間の本物のチャートを計算する。2つ目はそれを使って**世界のインタラクティブマップ**を構築し、あなた専用のラインを引き、都市を1つずつクリックして詳細な分析を得られるようにする——その都市が何をもたらすとされているか、何が欠点か、実際に合うかどうかを教えてくれる。

約10分で完成し、マップが本当に優れているとは期待していなかった。しかし実際に優れていた。

**ステップ1**: ChatGPTを開き、以下を貼り付ける（質問は自動で聞いてくる）：

```
私の生年月日、可能な限り正確な出生時刻、生まれた町を聞いてください。それからその正確な瞬間の実際のチャートを計算してください。記憶からではなく、コードで適切に計算し、実行できない場合は推測せずに教えてください。それから、曖昧な占い言葉ではなく、平易な英語で何を意味するか教えてください。星座ではなく具体的なパターンを分析し、私が楽しめない部分も含めて正直に、どの部分が実際の天文学でどの部分が解釈なのかを教えてください。
```

出生証明書に記載されている通り、できる限り正確な時刻を入力すること。1時間ずれると半分が変わってしまう。返ってくる結果は星座ではなくパターンに基づいており、不快な部分も求めれば容赦なく示される。

**ステップ2**: それが完了したら、次を続ける：

```
次に私のアストロカートグラフィーラインを計算してください。すべてのラインが引かれた完全なインタラクティブ世界地図を作成してください。MCとICは垂直線、ASCとDSCは適切な曲線で、惑星ごとに色分けしラベルを付けてください。ラインの上または近くにあるすべての主要都市をマークしてください。各都市をクリック可能にし、クリックすると詳細な分析を表示してください：どのライン上にあるか、そのラインが何をもたらすとされているか、何が欠点か、実際に合うかどうかの率直な評価。最適な都市のランク付きリストを横に追加し、惑星ごとにマップをフィルタリングできるようにしてください。図ではなく本物のチャートのように見せてください。それから、あなたが私だったらどれを選ぶか、その理由を教えてください。
```

これが本番だ。**本物のインタラクティブマップ**が構築され、ラインが引かれ、理由付きの都市のランク付きショートリストが渡される。少なくとも1つは考えたこともない都市が含まれるだろう。また、どのラインが困難なものかも教えてくれるが、これは正直、良いラインよりも興味深い。

知っておくべきこと、そしてプロンプトが意図的に求めていることが1つある。位置は**実際の天文学**であり、すべての天文台が使うのと同じ数学で計算されるため、得られるマップは本当にあなた固有のもので他の誰のものでもない。それらのラインが何を意味するとされているかは、より古く柔らかいもので、科学というより伝統であり、ChatGPTは求めればどちらがどちらかを教えてくれる。正直なところ、それが面白さを生む。本物のマップ、適切なショートリスト、そして一度も考えたことのない都市を調べる非常に良い理由が手に入る。

### 📌 Anthropicが最高のモデルをリリース

AnthropicはFable 5.1を発表した。これは数ヶ月前にリリースしたFableモデルのより良いバージョンだ。それ自体は劇的ではないが、彼らにとっては大きなリリースであり、知っておくべきことが3つある。

**より安価**で、請求書に気づくというよりは、長い会話が本当にお金がかかり始める前にどこまで続くかという点で違いがある。また**文章が改善**されており、これは日常的に実際に気づく点だ。無駄話が減り、何も言わない段落が少なくなり、目の前に置かれたすべてに同意するのではなく、もっと反論してくるようになった。

そして、最近のClaudeモデルが完全に正常なことを時々拒否するのに気づいた人には、これがそれを修正することになっている。

最後の点が興味深いところだが、人々はまだ修正されていないと感じている。開発者が言っていることを読むと、同じ話が繰り返される——完全に通常の作業から撤退し、静かに弱いモデルに切り替わる。ある人は自分にコードを書かせ、その後そのモデルは自分が書いたばかりのコードのレビューを拒否した。方向性は正しいが、まだそこには到達していない。

言っておく価値があるのは、多くの人が探すだろうからだ。**Fableは無料プランにはない**。Proでは追加料金がかかり、Maxでのみ完全に含まれるため、見つからない場合、アカウントに問題はない。

興味深いのはタイミングだ。これはOpenAIが1ヶ月間棚上げしていたAstraモデルをついにリリースすると発表したのと同じ週に登場した。彼らは8月初めにそれを命名したが、1週間後に作業を停止した。理由は、サイバー能力に関する彼ら自身のレッドラインを越えた可能性を排除できなかったためだ——つまり、誰も監督していない状態で実際のセキュリティ脆弱性を独自に発見し構築できる可能性がある。

月曜日、彼らはそのラインを越えたことを確認した。計画していた最大のトレーニング実行を停止し、リリース前に独自の安全規則を書き直している。リリース日は未定で、何と呼ぶかさえ決まっていない。

### 📌 保存すべき3つの画像コード

ChatGPTで画像の前に入力すると、出力を完全に変える3つの短いコードを見つけた。これはここ最近AIで最も楽しんだ体験だ。写真を添付し、コードとその下の行を貼り付けるだけ。

ChatGPTでもClaudeでも、画像を添付できる場所ならどこでも機能する。

**/3D-billboard**

```
/3D-billboard この写真をフォトリアルな屋外ビルボードのモックアップに変換し、都市のストリートシーン、製品をヒーローショットとして拡大。
```

販売しているもの、あるいは正直に言って所有しているものなら何でもアップロードすれば、本物の通りの本物のビルボードに配置される。正しい角度、正しい光、誰かが車で通り過ぎて撮影したように見える。

**/time-machine**

```
/time-machine この写真を1950年代に見えたであろう形で再構築し、時代に正確な衣服、車、看板、フィルムグレインと時代の色彩で。
```

これが筆者を虜にしたものだ。あなたの通り、家、または古い写真を入力すれば、70年前に撮影されたかのように返してくれる。育った家でやってみて。

**/magazine-cover**

```
/magazine-cover この写真の被写体を光沢のある雑誌の表紙に配置し、マストヘッド、カバーライン、バーコードを含む完全なカバーレイアウトで。
```

見出しを含む完全なカバーを構築する。これはグループチャットで本当に送信を求められるものだ。

この先、さらに多くのコードに関する動画を公開予定だ。マーケティングに実際に使う価値があるか、友人に面白いものを送るだけでも使える。

**試すべき5つ追加**：
- /lego
- /giant
- /snow-globe
- /satellite-view
- /hologram

これは必ず保存しておこう。
