### 📌 今日やるべきこと

**ChatGPTがあなたが実際に住むべき場所を教えてくれる**

ほとんど誰も自分が住む場所を選んでいない。そこで生まれたか、仕事で移動したか、誰かについて行ったか、その年たまたま家賃が安くて15年が過ぎたか。地球上のあらゆる都市の中から、実際に座って選んだ人はほとんどいない。そして大半の人は、どこかもっと自分に合う場所があるはずだという静かな疑念を抱いているが、そう考える具体的な理由は一つもない。

そこでChatGPTが役立つのではないかと考えた。2つのプロンプトを作成した。最初のプロンプトは生年月日と出生時刻、出生地を尋ね、その正確な瞬間のアストロカートグラフィー（占星地図学）を用いて実際のチャートを計算する。2つ目のプロンプトはそれを使って**あなた専用のラインが描かれた世界のインタラクティブマップを構築**し、都市を一つずつクリックして各都市の詳細な説明、それがもたらすとされるもの、実際に自分に合うかどうかを確認できる。

所要時間は約10分で、マップが実際に優れたものになるとは期待していなかった。だが、実際に優れている。

**ステップ1:** ChatGPTを開いて以下を貼り付ける。質問は自動的に行われる。

```
私の生年月日、できるだけ正確な出生時刻、出生地の町を尋ねてから、その正確な瞬間の実際のチャートを計算してください。記憶ではなくコードで適切に計算し、実行できない場合は推測せずに教えてください。次に、曖昧な占星術用語ではなく平易な英語で、それが私について何を示しているかを教えてください。星座ではなく具体的なパターンを扱い、私が気に入らない部分も含めて正直に説明し、どの部分が本物の天文学でどの部分が解釈なのかを教えてください。
```

出生時刻はできるだけ正確に。出生証明書に記載されている。1時間ずれると半分が移動する。返ってくる結果は星座ではなくパターンを扱い、不快な部分を求めれば遠慮なく示される。

**ステップ2:** 完了したら、以下で続ける：

```
次に私のアストロカートグラフィーラインを計算してください。すべてのラインが描かれた完全なインタラクティブ世界地図を構築し、MCとICには垂直線、ASCとDSCには適切な曲線を引き、惑星ごとに色分けしてラベルを付けてください。ライン上またはライン近くにあるすべての主要都市をマークしてください。各都市をクリック可能にし、クリックすると完全な説明が表示されるようにしてください：どのライン上にあるか、そのラインがもたらすとされるもの、注意点は何か、そして自分が実際にそこに適合するかどうかの率直な評価。側面に最適な都市のランキングリストを追加し、惑星別にマップをフィルタリングできるようにしてください。図ではなく本物のチャートのように見せてください。次に、あなたが私ならどれを選ぶか、そしてその理由を教えてください。
```

これが注目に値する部分だ。**本物のインタラクティブマップ**が構築され、あなたのラインが横切り、理由付きの都市のランク付けされたショートリストが提示される。少なくとも一つは考えもしなかった都市が含まれるだろう。また、どのラインが困難なものかも教えてくれ、正直なところこれは良いラインより興味深い。

知っておく価値があることが一つある。プロンプトが意図的に求めているものだ。位置は**本物の天文学**で、すべての天文台が使用するのと同じ数学で計算されるため、得られるマップは本当にあなた専用であり、他の誰のものでもない。それらのラインが何を意味するとされているかは、より古く、より柔軟なもので、科学というより伝統であり、ChatGPTに尋ねればどちらがどちらかを教えてくれる。正直なところ、それが楽しい理由だ。最終的に本物のマップ、適切なショートリスト、そして一度も考えたことのない都市を調べる非常に良い理由が得られる。

### 🚨 AIアップデート

**Anthropicがこれまでのベストモデルをリリース**

Anthropicは**Fable 5.1**をローンチした。これは数ヶ月前にリリースしたFableモデルの改良版だ。それ自体は特別なものではないが、彼らにとっては大きなローンチであり、知っておく価値のあることが3つある。

より安価になり、請求書で気づくというより、長い会話が本当にお金がかかり始める前にどこまで進むかという点で違いがある。また、文章も改善された。これは日常的に実際に気づくものだ。無駄な文章が減り、何も言っていない段落が減り、あなたの前に提示されたすべてに同意する代わりに、より反論するようになった。

そして、最近のClaudeモデルが時折完全に正常なことを拒否することに気づいていれば、これはそれを修正することを意図している。

最後の点が興味深いところだ。なぜなら、人々はまだ修正されていないことに気づいているからだ。開発者が言っていることを読むと、同じ話が繰り返されている。完全に普通の作業から後退し、静かにより弱いモデルを代わりに渡す。ある人はコードを書いてもらったが、書いたばかりのコードのレビューを拒否された。方向性は正しいが、まだそこには到達していない。

言及する価値がある。多くの人が探すだろうから。Fableは無料プランにはない。Proではサブスクリプションに加えて追加料金がかかり、Maxにのみ適切に含まれているため、見つからなくてもアカウントに問題はない。

興味深いのはタイミングだ。これは、OpenAIが1ヶ月間棚に置いていたモデル**Astra**をついにリリースすると発表したのと同じ週に発表された。8月初めに名前を付けたが、1週間後に作業を停止した。なぜなら、サイバー能力に関する自社のレッドラインを越えた可能性を排除できなかったからだ。つまり、誰も監督せずに実際のセキュリティエクスプロイトを見つけて構築できる可能性があるということだ。

月曜日、彼らはそのラインを越えたことを確認した。計画していた最大のトレーニング実行を停止し、リリース前に独自の安全ルールを書き換えている。リリース日は未定で、何と呼ぶかさえ決まっていない。

### 💡 これを保存

**とんでもないことをする3つの画像コード**

ChatGPTで画像の前に入れると出力方法を完全に変える3つの短いコードを見つけた。これはAIで長い間最も楽しんだものだ。写真を添付し、コードとその下の行を貼り付けるだけ。それだけだ。

ChatGPTでもClaudeでも、画像を添付できる場所ならどこでも機能する。

**/3D-billboard**

```
/3D-billboard この写真をフォトリアリスティックな屋外広告看板のモックアップに変換、都市の街並み、製品を主役ショットとして拡大。
```

販売しているもの、または正直なところ所有しているものをアップロードすると、実際の通りの本物の広告看板に配置される。正しい角度、正しい光、誰かが車で通りかかって撮影したように見える。

**/time-machine**

```
/time-machine この写真を1950年代に見えたであろう形で再構築、時代に正確な服装、車、看板、当時のフィルムグレインと色。
```

これが私を捉えたものだ。自分の通り、家、または古い写真を入力すると、70年前に撮影されたかのように返してくれる。育った家でやってみて。

**/magazine-cover**

```
/magazine-cover この写真の被写体を光沢のある雑誌の表紙に配置、マストヘッド、カバーライン、バーコード付きの完全なカバーレイアウト。
```

見出しなどすべてを含む完全な表紙を構築する。これはグループチャットで実際に送信を求められるものだ。

これらのもっと多くを紹介するビデオを近日公開予定だ。マーケティングに使う、または単に友人に面白いものを送るために本当に使う価値がある。

**試すべきあと5つ**
- /lego
- /giant
- /snow-globe
- /satellite-view
- /hologram

必ず保存しておくこと。

今夜最初のものを実行し、出生時刻を正確に。マップが私を驚かせた部分で、リストに一度も考えたことのない都市があると賭けてもいい。
