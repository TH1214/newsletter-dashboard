### 📌 OpenAIが地球上で最もパワフルなAIモデルをリリース

水曜日、OpenAIが強力なモデルを保有しているものの、リリースに慎重になっていると伝えた。木曜日、実際にそれがリリースされた。**GPT-6 Astra**と呼ばれるこのモデルは、誰もが想像していた以上に優れており、現在**地球上で公開されている中で圧倒的に最もパワフルなAIモデル**となっている。

最大の注目点はベンチマークスコアだ。AstraはARC-AGI-3試験で**99.9%のスコア**を記録した。この試験は、AIが人間と同じように思考する能力を測定するために設計されており、過去に見たことのないパズルをその場で解く必要がある。6か月前、OpenAIの最良モデルはこの試験で8%未満のスコアだった。これは前モデルからのステップアップではなく、まったく異なるリーグに属するものであり、機械が人間のように新しい問題を推論することに最も近づいた成果だ。我々は基本的にそこに到達したと考えている。

しかし、誰もが驚いているのは**コンピューター使用機能**だ。指示を書くのではなく、アプリを開いて実際に作業を実行する。フォームに記入し、スプレッドシートを操作し、ウェブサイトをクリックして実際のソフトウェア内で作業を行う速度は以前の約2倍で、曖昧な指示を与えた場合でもはるかに優れた判断を下す。これは私のような人間にとっては大半の場合に当てはまる。今では実際のタスクを任せることができるので、以前コンピューター使用機能を試して不便だと感じた人は、もう一度試してみる価値がある。

このモデルで人々が構築しているものは絶対的に驚異的だ。X上の誰かが**Blenderで3Dハウスレンダリング全体**を構築させた——キッチン、家具、ガラスの壁、すべてだ。上の写真では片側がFable 5.1、もう片側がAstraで、その差を見てほしい。明らかに詳細が増え、信じられないほど良く見える。これは3Dアーティストが数週間かけて組み立てるようなもので、一度に完成させた。

あまり話題になっていない部分がある。確実に高価で、高速版は通常版の2倍のコストがかかり、Plusプランでは追加購入を求められる前に限られた量しか使えない。また、無料プランには一切含まれておらず、これはPlus以上のみであり、数日かけて展開されるため、まだ表示されていなくても慌てる必要はない。Plusでは通常のチャットには表示されず、左上のChatからWorkに切り替えることで使用できる。競争が激化するにつれて、これらすべてがより安価で優れたものになると予想しており、Anthropicが今後数週間で独自の何かを発表しても驚かない。

### 📌 Claudeがファーストクラスへのアップグレードを実現

そう、正しく読んだ。これはAIで私が遭遇した最もクールなユースケースの1つで、来月のフライトで試してみたところ、実際に機能した。Claudeにファーストクラスへのアップグレードをさせることができ、この成功率は驚異的だ。なぜなら、マイル、カード特典、ステータス、おそらく自分でも知らないすべてのものを調べ、航空会社のウェブサイトに行って実際に座席を取得する前に、完全なアップグレードケースを組み立ててくれるからだ。

**ステップ1:** Claudeを開いて以下を貼り付ける。できるだけ完全に質問に答える。

```
私は[航空会社]で、確認コード[コード]、[日付]に[都市]から[都市]へのフライトがあり、このフライトをファーストクラスまたはビジネスクラスにアップグレードしたい。あなたは私の予約を見ることができないので、私が話すことから作業してください。
まず私にインタビューしてください。クレジットカード、持っているマイルとポイント、エリートステータス、このチケットに支払った金額について必要なすべての質問を一度に尋ねてください。次に、このフライトに使用できるすべてのアップグレード通貨、マイル、証明書、銀行ポイント、カード特典、現金オファー、アップグレード入札をマッピングし、My Upgrade Power Dashboardというインタラクティブなアーティファクトを作成してください。通貨ごとに1つのカードで、コスト、成功の可能性、そして最初に行う単一の動きを示してください。
```

すべてを一度に尋ね、ダッシュボードを返してくる。所有するものごとに1つのカード、各フライトのコスト、成功の可能性が示される。私の場合、年会費を支払っていながら一度も使用したことのないカード特典が見つかった。**完全なインタビューを行い**、カード番号を貼り付けないこと、必要ない。

**ステップ2:** Chrome Web StoreからClaude in Chromeをインストールし、Claudeで左側のCustomizeを選択し、Connectorsを選択してClaude in Chromeをオンにする。チャットに戻り、メッセージボックスの横のプラスを押してそこでもオンにする。これは誰もが見逃すステップだ。

**ステップ3:** Chromeタブで航空会社にログインし、同じチャットに戻って以下を貼り付ける。

```
Chromeで[航空会社]のウェブサイトに移動してください。私はすでにログインしています。確認コード[コード]で予約を開き、フライトのファーストクラスキャビンを確認してください：残席数、現金およびマイルでのアップグレードコスト、入札オプションがあるかどうか。
それをMy Upgrade Power Dashboardと比較して、最適な経路を選択してください。価値が適切であればマイルを使用し、過払いせずに勝つ可能性が高い最も賢い数字で入札を行うか、できるだけ高い位置でアップグレードリストに載せてください。お金やマイルを使う確認をする前に、一時停止して、クリックしようとしているものを正確に見せてください。
```

そして見ているだけでいい。Claudeは自分のブラウザで航空会社のサイトを開き、予約を取り出し、ファーストクラスに何が残っているか、何を求めているかを確認し、マイルを使う価値があるか、入札がより賢い選択かを判断する。最終確認画面まで進み、そこで停止する。**お金やマイルを使うボタンは自分で押さない限り使用しない**からだ。コーヒーを持って座っている間に、物理的に座席を追いかけるのを見るのは、ちょっと現実離れしている。

### 📌 あらゆるものを記憶に定着させる5つのChatGPTコード

現在学校に通っている学生、または子供がいる場合、これを使いたくなるだろう。ほとんどの人の勉強方法は、テキストの壁を読み、忘れ、もう一度読む。そこで、作業しているものの写真を実際に脳が保持するバージョンに変える5つのコードを紹介する。ChatGPTにページの写真をアップロードし、コードを入力してEnterを押す。セットアップはこれだけだ。

**1. /generatehandwrittenimage**
アップロードしたものを取り込み、手書きのノート1ページ分、下線付き見出し、矢印など、すべてを返してくれる。手書きで書かれたものを見ることで、印刷版とは異なる方法で記憶に定着する。また、次回手書きで書くように言われたときに書きたくない場合にも非常に便利だ。

**2. /visualizelearning**
任意の概念を貼り付けると、視覚的な図に変換してくれるので、何かがどのように機能するかについての4つの段落を読み直す代わりに、1枚の画像を見ることになる。プロセスが含まれるもの、住宅ローン、ワクチン、オフサイドルールなどに最適だ。

**3. /makestickynotes**
教科書の章全体を取り込み、短い付箋の壁を返してくれる。テストに実際に出るものだけで、それ以外は何もない。

**4. /flashcards**
これが私のお気に入りだ。何かをアップロードすると、質問のリストではなく、チャット内に実際の小さなフラッシュカードアプリを構築してくれる。タップして裏返せるカードで、間違え続けたものを追跡するので、それらだけを再度実行できる。

**5. /examme**
勉強しているすべてから模擬テストを構築し、本物のように1つずつ質問してクイズを出し、最後に採点して間違えたものを並べてくれる。合格するまで実行する。

最初の3つについての簡単な注意事項。これらは画像として返されるため、時々単語のスペルを間違え、無料プランでは1日に数回しか使用できない。ガイドにはさらに95個ある。
