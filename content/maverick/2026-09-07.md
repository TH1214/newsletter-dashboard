### 📌 GPT-6 Astra — 地球上最強のAIモデルが登場

水曜日にOpenAIが強力なモデルを保有しているがリリースを躊躇していると伝えたが、木曜日に実際にリリースされた。**GPT-6 Astra**と呼ばれ、誰もが想像した以上に優れており、現在**地球上で公開されている最も強力なAIモデル**となっている。

主なハイライトはベンチマーク結果だ。AstraはARC-AGI-3試験で**99.9%**を記録した。これは、AIが人間のように考える能力をどれだけ持っているかを測定するテストで、初めて見るパズルをその場で解く必要がある。6ヶ月前、OpenAIの最良モデルはこのテストで8%未満だった。これは前モデルからの進化ではなく、**完全に別次元**であり、人間のように全く新しい問題を推論できる機械に最も近づいたものだ。基本的に到達したと言える。

しかし、誰もが興奮している機能は**コンピューター利用**だ。指示を書く代わりに、アプリを開いて実際に作業を行う。フォームに記入し、スプレッドシートを操作し、ウェブサイトをクリックし、実際のソフトウェア内で作業する。以前の約2倍の速さで、曖昧な指示を与えた際の判断も遥かに優れている。実際のタスクを任せられるようになったので、以前コンピューター利用を試して不格好だと感じた人は、もう一度試す価値がある。

人々が構築しているものは全く驚異的だ。X上の誰かがBlenderで3D住宅レンダリング全体を構築させた。キッチン、家具、ガラスの壁、すべてだ。上の写真は片側がFable 5.1で、もう片側がAstra。違いを見てほしい。明らかに詳細が多く、信じられないほど良く見える。これは3Dアーティストが組み立てるのに数週間かかるようなものを、一度で完成させている。

あまり語られていない部分もある。確実に高価で、高速版は通常版の2倍のコストがかかり、Plusプランでは追加購入を求められる前に限定的な使用量しかない。また、無料プランでは全く利用できず、Plusプラン以上のみで、数日かけて展開されている。まだ表示されていなくても慌てる必要はない。Plusプランでは通常のチャットには表示されず、左上の「Chat」から「Work」に切り替えることで利用できる。競争が激化するにつれて、これらすべてが安価で優れたものになると予想される。Anthropicが今後数週間で独自のものを出してこないと驚くだろう。

### 📌 Claudeでファーストクラスにアップグレードする方法

そう、正しく読んだ。これはAIで遭遇した最もクールなユースケースの1つで、来月のフライトで試したところ実際に機能した。Claudeにファーストクラスへのアップグレードをしてもらえる。成功率は驚異的だ。なぜなら、マイル、カード特典、ステータス、おそらく自分でも知らない特典をすべて調べ、完全なアップグレード申請を組み立ててから、航空会社のウェブサイトに行って実際に座席を取得するからだ。

**ステップ1**: Claudeを開いて以下を貼り付ける。できるだけ詳しく質問に答える。

```
[航空会社]で[日付]に[都市]から[都市]へ、確認コード[コード]でフライトする予定です。この正確なフライトをファーストクラスまたはビジネスクラスにアップグレードしたいです。あなたは私の予約を見ることができないので、私が伝えることから作業してください。
まず私にインタビューしてください。クレジットカード、持っているマイルとポイント、エリートステータス、このチケットに支払った金額について、必要なすべての質問を一度にしてください。次に、このフライトに使える可能性のあるすべてのアップグレード通貨(マイル、証明書、銀行ポイント、カード特典、現金オファー、アップグレード入札)をマッピングし、「My Upgrade Power Dashboard」というインタラクティブなアーティファクトを作成してください。各通貨ごとにカードを作り、コスト、成功の可能性、最初に行うべき単一の行動を示してください。
```

すべてを一度に質問され、ダッシュボードが返ってくる。所有している通貨ごとに1枚のカード、このフライトに各通貨がいくらかかるか、成功する可能性はどのくらいかが示される。私の場合、年会費を払っているのに一度も使ったことのないカード特典を見つけた。**完全なインタビューを行い**、カード番号は貼り付けないこと(必要ない)。

**ステップ2**: Chrome Web StoreからClaude in Chromeをインストールし、Claudeで左側の「Customize」を選択、次に「Connectors」を選び、「Claude in Chrome」をオンにする。チャットに戻り、メッセージボックスの横のプラスを押してそこでもオンにする。**この手順をみんな見逃す**。

**ステップ3**: Chromeタブで航空会社にログインし、同じチャットに戻って以下を貼り付ける。

```
Chromeで[航空会社]のウェブサイトに行ってください。すでにログインしています。確認コード[コード]で予約を開き、フライトのファーストクラスキャビンを確認してください:残席数、現金とマイルでのアップグレードコスト、入札オプションがあるかどうか。
Upgrade Power Dashboardと比較して、最良のパスを選んでください。価値が適切であればマイルを使用し、過払いせずに勝つ可能性が高い最適な金額で入札するか、できるだけ高い位置でアップグレードリストに載せてください。お金やマイルを使う何かを確認する前に、一時停止して、クリックしようとしているものを正確に見せてください。
```

そして見ているだけでよい。Claudeがあなた自身のブラウザで航空会社サイトを開き、予約を表示し、ファーストクラスに何が残っているか、何を求めているかを確認し、マイルを使う価値があるか、入札がより賢い選択肢かを判断する。最終確認画面まで進んで停止する。**ボタンを押さない限り、お金やマイルを使わない**からだ。コーヒーを飲みながら座席を物理的に追いかけるのを見るのは、ある種非現実的だ。

### 📌 あらゆることを記憶させる5つのChatGPTコード

今学校にいる学生、または子供がいる場合、これを使いたくなるだろう。ほとんどの人の勉強方法は、テキストの壁を読んで、忘れて、また読む、というものだ。そこで、取り組んでいるものの写真を、脳が実際に保持するバージョンに変換する5つのコードを紹介する。ChatGPTにページの写真をアップロードし、コードを入力し、エンターを押す。それが全設定だ。

**1. /generatehandwrittenimage**  
アップロードしたものを受け取り、手書きノートの完全なページを返してくれる。下線付きの見出し、矢印など。手書きで見ると、印刷版では得られない方法で記憶に定着する。また、次回手書きするよう言われたときにしたくない場合にも非常に便利だ。

**2. /visualizelearning**  
任意の概念を貼り付けると、視覚的な図に変換される。仕組みについての4段落を読み直す代わりに、1枚の絵を見るだけでよい。プロセスを含むもの、住宅ローン、ワクチン、オフサイドルールなどに最適。

**3. /makestickynotes**  
教科書の章全体を受け取り、短い付箋の壁を返してくれる。実際にテストに出るものだけで、それ以外は何もない。

**4. /flashcards**  
これが私のお気に入りだ。何でもアップロードすると、質問のリストではなく、チャット内で実際の小さなフラッシュカードアプリを構築する。タップして反転するカード、間違え続けるカードを追跡するので、それらだけをもう一度実行できる。

**5. /examme**  
勉強しているすべてから模擬テストを作成し、本物のように1問ずつクイズを出す。最後に採点し、間違えたものを並べて示す。合格するまで実行する。

最初の3つについて簡単な注意。画像として返ってくるので、たまに単語のスペルを間違える。無料プランでは1日に数回しか使えない。ガイドにはさらに95個ある。
