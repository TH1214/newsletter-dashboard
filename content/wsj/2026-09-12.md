 <p style="margin: 0 0 15px 0;"><strong>1. 国債市場の動揺と借入コスト上昇リスク</strong></p>
 <p style="margin: 0 0 20px 15px;">
 数ヶ月続く国債売りが危険水域に達し、借入コストが株式市場と経済に損害を与える水準に接近。不動産開発プロジェクトや大型M&Aのファイナンスコストが上昇する可能性があり、デットファイナンスに依存する案件のフィジビリティ再評価が必要。REITのキャップレート上昇圧力にも要警戒。
 </p>

 <p style="margin: 0 0 15px 0;"><strong>2. AI規制の不透明性と技術投資への影響</strong></p>
 <p style="margin: 0 0 20px 15px;">
 議会がAI規制（新規制機関、キルスイッチ、超知能禁止）を議論するも、法制化の見通しは不透明。国防総省のFluidstackへの50億ドル融資は政府のAIインフラ投資姿勢を示唆。ホテル・不動産テックへのAI導入においても、規制動向を注視しつつ、過度な先行投資は慎重に。
 </p>

 <p style="margin: 0 0 15px 0;"><strong>3. 住宅ローン市場の構造変化と不動産需要</strong></p>
 <p style="margin: 0 0 20px 15px;">
 VantageScore 4.0の導入により、従来FICOで不利だった借り手層の住宅購入機会が拡大。30年固定金利が7%超の環境下で、信用スコアリングの多様化は住宅需要の下支え要因に。ただし、金利上昇トレンドは継続しており、住宅・商業不動産市場の冷え込みリスクは依然高い。
 </p>

 <p style="margin: 0 0 15px 0;"><strong>4. 大学アスリートNIL市場と新興不動産需要層</strong></p>
 <p style="margin: 0 0 20px 15px;">
 大学アスリートが年間数十万〜数百万ドルを稼ぎ、95万ドル級の住宅を購入する現象は、学園都市周辺の高級住宅市場に新たな需要層を創出。チームメイトへの賃貸や不動産ポートフォリオ構築の動きは、学生向け高級賃貸物件への投資機会を示唆。
