<h2 style="color: #2c5aa0; border-bottom: 2px solid #2c5aa0; padding-bottom: 10px; margin-top: 40px;">📊 破られた記録たち</h2>

<h3 style="color: #1a1a1a; margin-top: 30px;">🚀 IPO記録の13年</h3>
<div style="background-color: #fff; padding: 20px; border: 1px solid #e0e0e0; border-radius: 6px; margin-bottom: 20px;">
 <p style="line-height: 1.8; margin: 0 0 15px 0;"><strong>史上最大のIPOが起きた。そしてまた起きた。何度も何度も。</strong></p>

 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 GTA Vがローンチした2013年、史上最大のIPO記録はVisaの179億ドル（2008年）だった。Alibabaが2014年に250億ドルでこれを破り、Saudi Aramcoが2019年に256億ドルで更新した。
 </p>

 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 そして2026年6月、<strong>SpaceXが750億ドルを調達</strong>し、Aramcoの2.5倍以上となった。株価は135ドルで始まり、初日に19%上昇。2002年に航空宇宙業界で冗談のように扱われていた企業が、今やあらゆる自動車会社、ほとんどの銀行、そしてほとんどの国のGDPを上回る価値を持つ。SpaceXのStarlink部門だけで、ロケット打ち上げ業界全体を合わせた以上の収益を生み出している。
 </p>

 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 GTA Vローンチ時、SpaceXはFalcon 9の打ち上げ成功をわずか3回しか達成していなかった。今では、巨大な箸でロケットをキャッチしている。
 </p>

 <p style="line-height: 1.8; margin: 0;">
 そしてGTA VIローンチの前日、<strong>AnthropicがSpaceXの記録を破った。</strong>11月18日に1株83ドルで価格設定し、813億ドルを調達。翌朝Nasdaqでティッカー「ANT」として111.50ドルで取引開始、34%上昇（ただしこれは長く続かなかった）。同社は2021年設立、つまり<strong>GTA VIの制作期間の半分以下で1.5兆ドルの価値を創造した。</strong>
 </p>
</div>

<hr style="border: none; border-top: 1px solid #e0e0e0; margin: 30px 0;">

<h3 style="color: #1a1a1a; margin-top: 30px;">💥 最大級の破綻劇</h3>

<div style="background-color: #fff3cd; padding: 20px; border-left: 4px solid #ffc107; margin-bottom: 20px;">
 <h4 style="color: #856404; margin-top: 0;">WeWork：470億ドル→破産</h4>
 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 <strong>一世代で最も期待されたテックIPOが、470億ドルでピークを迎え、4年後に破産申請した。</strong>
 </p>

 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 WeWorkは約8年でゼロから470億ドルの評価額に到達。日本のコングロマリット・SoftBankが最も積極的なテック投資家となり、連続したラウンドで毎回より高い価格で数十億ドルを注入した。創業者Adam Neumannはカリスマ的で、シェアオフィスを通じて世界の意識を高めるという壮大な主張を好んだ。投資家たちは、靴を履かず「コミュニティ調整済みEBITDA」を提示する男が470億ドルの価値を創造したと同意した。
 </p>

 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 2019年、WeWorkは上場申請を提出。Neumannが「We」という言葉を商標登録し、WeWorkに590万ドルでライセンスバックしていたことを開示。彼がWeWork株を担保に借り入れ、その資金で物件を購入し、それをWeWorkにリースバックしていたことも開示。そして2018年に18億ドルの売上に対し19億ドルの損失を計上していたことも開示された。
 </p>

 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 IPOは撤回された。Neumannは解任された。SoftBankが救済パッケージを組織し、過半数支配権を取得。WeWorkは2021年、ピークから80%減の90億ドル評価でSPAC経由で上場し、2023年11月に186億ドルの負債を抱えて破産申請した。
 </p>

 <p style="line-height: 1.8; margin: 0;">
 Neumannは問題の対価としてSoftBankから17億ドルを受け取った。そして彼はすでに復活している：新しい不動産スタートアップ「Flow」は現在約25億ドルの評価を受け、Andreessen Horowitzが主要バッカーとなっている。
 </p>
</div>

<div style="background-color: #fff3cd; padding: 20px; border-left: 4px solid #ffc107; margin-bottom: 20px;">
 <h4 style="color: #856404; margin-top: 0;">FTX：72時間で崩壊した世界第2位の暗号通貨取引所</h4>
 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 FTXは2019年、当時27歳のSam Bankman-Fried（元Jane Streetトレーダー、暗号トレーディング会社Alameda Research創業者）により設立された。世界第2位の暗号通貨取引所に成長し、1日数十億ドルの取引高を処理していた。
 </p>

 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 SBFは雑誌の表紙を飾り、議会で証言し、数億ドルを政治的原因に寄付し、暗号通貨を尊敬されるものにする可能性が最も高い人物として広く評されていた。
 </p>

 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 2022年11月、CoinDeskのレポートで、SBFのトレーディング会社Alameda Research（FTXとは別とされていた）のバランスシートが主にFTT（取引所独自のトークン）で構成されていることが判明。これは2つのエンティティが開示以上に絡み合っていることを示唆した。FTXの主要競合Binanceが保有FTTを売却すると発表。FTT価格は崩壊した。
 </p>

 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 顧客がFTXから引き出しを殺到させた。72時間で60億ドルの引き出しが取引所を圧倒し、顧客資金を保管しているはずだったことが判明しなかった。
 </p>

 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 FTXは2022年11月11日に約80億ドルの不足を抱えて破産申請。SBFはバハマで逮捕され、米国に引き渡され、裁判にかけられ、詐欺と共謀の7つの罪で有罪判決を受けた。
 </p>

 <p style="line-height: 1.8; margin: 0;">
 彼は25年の刑を宣告された。彼が最も著名な公的資金提供者だった効果的利他主義運動は、翌年、何が起きたかを説明するのに費やした。<br><br>
 <strong>ちなみに、彼が明白な詐欺を犯していなければ、IPO時に400億ドル超の価値があるAnthropicの株式を持っていただろう。</strong>
 </p>
</div>

 <strong>Bitcoinの価格：</strong> GTA Vローンチ時 約$130 → GTA VIローンチ時 約$95,000

<h3 style="color: #1a1a1a; margin-top: 30px;">🌍 世代を定義する瞬間</h3>

<div style="background-color: #fff; padding: 20px; border: 1px solid #e0e0e0; border-radius: 6px; margin-bottom: 20px;">
 <h4 style="color: #2c5aa0; margin-top: 0;">SpaceX × xAI：史上最大の買収（$250B）</h4>
 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 <strong>史上最大の買収は、一人の男が自分の会社を買収するものだった。</strong>
 </p>

 <p style="line-height: 1.8; margin: 0;">
 2026年2月、SpaceXはElon MuskのAI企業xAI（Xも所有）を全株式取引で約2,500億ドルで買収、史上最大の買収を記録した。統合後の企業価値は1.25兆ドル。SpaceXはGrok、データセンター、Colossusスーパーコンピューターを取得。xAIはStarlinkのグローバルネットワークとSpaceXの打ち上げインフラを取得。両社を支配していたMuskは「次の章ではなく、次の本だ」と述べた。<br><br>
 従来の記録はVodafoneによる約1,800億ドルのMannesmann買収（2000年）。GTA Vローンチと同月、Verizonは1,300億ドルでVodafoneのVerizon Wireless 45%株式を買収、当時の3大ディールの一つだった。
 </p>
</div>

<div style="background-color: #fff; padding: 20px; border: 1px solid #e0e0e0; border-radius: 6px; margin-bottom: 20px;">
 <h4 style="color: #2c5aa0; margin-top: 0;">Yahoo：$446B拒否→$45Bで売却</h4>
 <p style="line-height: 1.8; margin: 0;">
 2008年、MicrosoftはYahooを446億ドルで買収提案。Yahoo取締役会はこれを拒否し、「企業価値を大幅に過小評価している」と述べた。2016年、Verizonは45億ドルでYahooのコアインターネット事業を買収、Microsoftの提案の約10分の1。この取引は現在、個別には防御可能だが、集合的には株主価値の破壊という壊滅的結果を招いた一連の決定に関するビジネススクールのケーススタディとなっている。
 </p>
</div>

<div style="background-color: #fff; padding: 20px; border: 1px solid #e0e0e0; border-radius: 6px; margin-bottom: 20px;">
 <h4 style="color: #2c5aa0; margin-top: 0;">AB InBev × SABMiller：$107B、地球上のビール30%を支配</h4>
 <p style="line-height: 1.8; margin: 0;">
 2015年、Anheuser-Busch InBevは1,070億ドルでSABMillerを買収、ビール業界史上最大、当時の企業買収史上3番目に大きな取引となった。統合企業は50カ国で約500のビールブランドを支配。Budweiser、Corona、Stella Artois、Castle、Aguilaは今や一つの企業となった。<br><br>
 最悪のクラフトビール好きVPがどこかで「ビッグイースト」について泣いている。規制当局は米国および他の市場で資産売却を強制したが、取引は成立。同社は現在、世界で消費されるビール3本に1本を販売している。<br><br>
 これは750億ドルの借入で資金調達された。金利が上昇したため良くなく、株価は取引成立以来市場をアンダーパフォームしている。地球上のビール30%を買うことが自動的に良い株にするわけではなく、真の不況耐性など存在しないことが判明した。
 </p>
</div>

<div style="background-color: #fff; padding: 20px; border: 1px solid #e0e0e0; border-radius: 6px; margin-bottom: 20px;">
 <h4 style="color: #2c5aa0; margin-top: 0;">Silicon Valley Bank：48時間で起きた2008年以来最大の銀行破綻</h4>
 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 Silicon Valley Bankはスタートアップエコシステムの銀行だった。ベンチャー支援企業が運転資金を預け、創業者が住宅ローンを組み、シリコンバレーの金融配管が走る場所。2023年3月時点で2,090億ドルの資産を持ち、米国第16位の銀行だった。
 </p>

 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 SVBは低金利時代に長期国債と住宅ローン担保証券を購入していた。2022年と2023年に金利が急激に上昇すると、これらの債券は価値を失った。
 </p>

 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 銀行は2023年3月8日に債券売却で18億ドルの損失を開示し、同時に資金調達を発表。この発表は苦境と解釈された。
 </p>

 <p style="line-height: 1.8; margin: 0 0 15px 0;">
 Peter ThielのFounders Fundがポートフォリオ企業に預金引き出しを助言。引き出し助言はSignalグループチャットを通じて史上最速で拡散した。顧客は3月9日の1日で420億ドルの引き出しを試みた。銀行は3月10日、市場開場前にFDICに差し押さえられた。ハッピーフライデー。
 </p>

 <p style="line-height: 1.8; margin: 0;">
 これは米国史上2番目に大きな銀行破綻だった。政府は25万ドルのFDIC保険限度額を超える預金を含むすべての預金を保証し、連鎖を防いだが、Signature Bankは2日後に破綻した。FRBは緊急融資制度を立ち上げ、取り付け騒ぎを鎮静化させ、銀行システムは持ちこたえた。<br><br>
 皮肉なのは、SVBの債券が無価値ではなかったことだ。これらは米国政府が裏付ける長期国債であり、満期保有ベースでは銀行は健全だった。不良債権ではなく取り付け騒ぎによって殺され、取り付け騒ぎはSignalグループチャットで組織された。
 </p>
</div>
