### 1. 最重要トピック：AIハッキングツールの恐るべき台頭

*Sam Sabin著*

広く利用可能な新種のAIツールがハッカーによる24時間体制のサイバー攻撃を支援し、企業ネットワークに数時間で侵入し、防御側を圧倒している。

**重要な理由：** AI対応ハッキングはまだ黎明期だが、無料でダウンロードできるオープンソースツールがサイバー犯罪の経済学を根本的に変えつつある。ハッカーは自己調整型の攻撃計画を起動でき、エージェントが脆弱性を発見し認証情報を盗む—時には人間の防御側がシステムが調査されていることに気づく前に。

**最新動向：** 公開されている「AIエージェントフレームワーク」を使った最近のサイバー攻撃が、ハッカーがいかに迅速に企業ネットワークに侵入できるかについて警告を呼んでいる。

- FBIは金曜日、ハッカーがArtexと呼ばれるAIフレームワークを使って世界中の組織を攻撃し、一部の侵入では初期ターゲティングから特権アクセスまでが3時間未満で進行したと警告した。
- 別の金曜日の報告書で、Amazonはハッカーがartexを使ってAIモデルの認証情報を盗み、その盗んだリソースを使って追加攻撃を実行したと述べた。
- 先週、開発者プラットフォームのRailwayとブロックチェーンインフラプロバイダーのChainstackもArtexを使った攻撃を報告した。
- Palo Alto Networksは木曜日、中国語圏のハッカーが別のオープンソースフレームワークCairnを使い、8月から9月にかけて少なくとも19組織に対して25回の作戦を実施したと述べた。
- 月曜日の別の報告書で、Googleはハッカーが米国の航空宇宙セクターへの侵入時にCairnを使用したと述べた。
- CrowdStrikeも、先月の11日間で1つのグループがArtexを使って世界中の200以上の組織を標的にしたのを確認した。

**現実的な見方：** サイバー攻撃は依然として恐ろしく、技術レジリエンスは依然として欠陥のあるインターネット基盤の上に構築されており、AI支援ハッキングの明確な証拠がなくても事故は起こりうる。

- Microsoft、Apple、Chase、United、Workday、連邦航空局（FAA）、国家安全保障局（NSA）を含む多数の人気サービスがすべて先週中に障害を報告した。
- Report URIによると、未知のグループがOptimizely Web Experimentationプラットフォームを通じて約178の主要ウェブサイトを暗号通貨窃取マルウェアに1日足らずで感染させた。
- 影響を受けたウェブサイトにはZoom、BBC、CNN、Salesforce、GitLab、Ikeaが含まれ、現時点ではAIが関与しているようには見えない。

**関係者の発言：** 「私たちは今、これまで以上に活発な攻撃を目にしています」とPalo Alto NetworksのUnit 42脅威インテリジェンス・コンサルティング部門のシニアバイスプレジデントSam Rubinは Axiosに語った。

**仕組み：** ArtexとCairnは、ハッカーが従来自分で実行していたタスクを自動化するためにAIエージェントを使用する。

- ハッカーはフレームワークに標的と目的（企業ネットワークへの侵入など）を与える。
- AIエージェントが攻撃計画を立案し、脆弱性を探し、ハッキングツールを使って可能な侵入ポイントをテストする。
- エージェントは発見を共有し、何かが失敗した時に戦術を調整し、人間の常時監視なしで24時間体制で稼働できる。

### 3. Microsoft、6つのAIモデルを発表

*Ina Fried著*

MicrosoftのAI CEO、Mustafa Suleymanは、同社が独自のフロンティア汎用AIモデルの構築に向けて大きな進歩を遂げていると Axiosに語った。同時に、OpenAIやAnthropicの主要製品に匹敵しながらコストはその数分の一だと主張する6つの特化モデルを発表した。

**重要な理由：** Microsoftは長らく最先端モデルをOpenAIやその他のAI企業に依存してきた。今、同社は独自に競争力のある技術を開発できることを実証しており、新製品は同テック大手が価格面でいかに積極的に競争する計画かを示している。

**最新動向：** Microsoftは昨日サンフランシスコでのIgniteカンファレンスで6つの新しいAIモデルを発表した。モデルはコーディング、サイバーセキュリティ、画像生成、音声にまたがる。

- **MAI Code 2：** Microsoftによると、新しいコーディングモデルはGPT-6.1 Solの性能の98%を価格の40%で実現し、AnthropicのClaude Opus 5.5の性能の96%をわずか5%のコストで実現する。
- **MAI Code 2 Flash：** より小型で高速なモデルで、MicrosoftによるとGPT-6 Lunaに価格の65%で匹敵し、Claude Haiku 5.5に価格の20%で匹敵する。
- **MAI Cyber 2 Flash：** サイバーセキュリティモデルで、Microsoftによるとセキュリティベンチマークでタスクあたりコストの2%未満でGPT-6 Astraを上回る。

**行間を読む：** Microsoftの戦略は特定のタスクに特化したモデルを構築することで、大幅に低いコストで同等の性能を達成できるようにすることだ。

「基本的には、同じパラメータ量により多くのトークンと知識と専門性を詰め込むことを意味します」とSuleymanはAxiosに語る。

トレードオフは、日常的なコーディングタスクに最適化されたモデルは、高度な数学や科学研究では同じように能力を発揮しないことだ。

Microsoftの性能比較は選択されたベンチマークに依存しており、一部の価格優位性はプロモーション割引を反映している。

**全体像：** Microsoftが業界リーダーをターゲットにする一方、フロンティアAIは前進し続けている。OpenAIは昨日GPT-6.2 AstraとGPT-6.2 Solを発表し、新しいAstraは旧バージョンより20%安く価格設定されている。

### 4. 民主党がAnthropicの1兆ドルIPOを遅らせたい理由

*Maria Curi著*

民主党主導の5州の選出議員グループが、Anthropicに対し、壊滅的リスクの警告と上場計画の整合性を求める圧力をかけている。

**重要な理由：** 同社への質問はIPOを止めることはなさそうだが、中間選挙後の「青いAI大地震」の後、テック大手が直面する可能性のある精査のプレビューとなっている。

民主党はまだ包括的なAI政策プラットフォームを構築していないが、多くが加速に賛成しないことはすでに明らかだ。

メリーランド、イリノイ、コロラド、コネチカット、ニューメキシコの選出議員と財政管理者は、取引開始前にAnthropicが重要な問題に取り組むよう要求している、とCEOのDario Amodeiと Anthropic取締役会に送られた書簡によると。

「イノベーションは説明責任と透明性を犠牲にしてはなりません。特に私たちの教師、消防士、警察官、すべての州職員の退職金が懸かっている時は」とメリーランド州会計監査官Brooke Liermanは声明で述べた。

州当局者が提案する解決策は、創業者の権利のサンセットを組み込み、Long-Term Benefit Trustの受託者が取締役を選出することを考えると、Anthropicの同信託がどのように運営されるかについて「はるかに多く」開示することだ。

### 1 big thing：ワーシュがサンフランシスコで聞いたこと

**写真：** サンフランシスコ連銀で昨日開催されたAI、雇用、生産性に関する会議で講演するワーシュFRB議長。Photo: David Paul Morris/Bloomberg via Getty Images

もしかすると、極端なテクノロジー楽観主義者もAI終末論者も、AIの経済的影響について間違っているのかもしれない。

これが、ベンチャーキャピタリストのマーク・アンドリーセン（Marc Andreessen）——同テーマに関するFRBタスクフォースの共同リーダー——が昨日、注目を集めたパネルで主張した内容だ。

**なぜ重要か：** この主張は、FRBがAIの経済的影響をどう評価するかを形作る可能性があり、成長、インフレ、金利の見通しに重大な影響を及ぼす。アンドリーセンの主張は、彼が中央銀行のリーダーたちに提言する内容の基礎となる考え方を早期に垣間見せるものだった。

**彼らの主張：** 「私の見解は、ユートピア論者も終末論者も失望することになる、特に現実世界への影響の範囲と規模、とりわけ経済的影響について失望するだろう、というものです」とアンドリーセンはサンフランシスコ連銀で述べた。

ワーシュの「雇用と生産性タスクフォース（Jobs and Productivity Task Force）」の共同リーダーであるアンドリーセンは、元商務長官ジーナ・ライモンド（Gina Raimondo）とともにベイエリアでの公聴会で講演した。ワーシュはスタンフォードで学び、その後15年間教鞭を執り研究を行った。（タスクフォースのもう一人のメンバーで、Anthropicに休職中のスタンフォード経済学者チャド・ジョーンズ（Chad Jones）も聴衆として参加していたが、同社が上場準備中のため発言しなかったとアンドリーセンは述べた。）

**ズームイン：** アンドリーセンはタスクフォースの報告書への貢献内容を予告し、経済は2つのグループに分かれていると主張した：

- **変化の速い産業：** テクノロジーやメディアなど、イノベーションが生産性向上と価格低下を推進する分野。
- **変化の遅い産業：** 医療、教育、住宅など、規制、限定的な競争、その他の障壁が技術的進歩を困難にする分野。

**興味深い点：** これらの変化の遅いセクターは、アメリカ人の最大の支出項目の一部を占めている。

経済のこれらのセクターは「法的に急速な変化が許されていない」とアンドリーセンは述べた。

アンドリーセンは、規制やその他の障壁がAIによる経済の大部分の変革を妨げる可能性があり、それが雇用喪失と生産性向上を制限するだろうと主張した。

「これは良いニュースと解釈できるかもしれません。なぜならAI革命がすべての仕事を破壊したり、全員を殺したりすることはないからです」と彼は述べた。「しかし、これを非常にネガティブなこととして見ることもできます。生産性の伸びは単純にそれほど伸びないかもしれない。経済成長も単純にそれほど伸びないかもしれない。私たちは停滞し続けるかもしれない」と付け加えた。

**大局観：** ワーシュは、中央銀行が経済についてどう考えるかに挑戦するため、影響力のある外部専門家に頼っている。

- Affirm CEO マックス・レヴチン（Max Levchin）は、AIによって同社のエンジニアの生産性が5倍になり、新機能開発コストが80%削減されたとワーシュに語った。
- Stripe CEO パトリック・コリソン（Patrick Collison）は、プラットフォーム上で毎週立ち上がる新規ビジネスが1年前から倍増しており、15年の歴史で前例のない急増だと述べた。既存企業と異なり、スタートアップはAIに製品開発やバグ修正を独立して任せる意欲が高く、より少ない従業員でより速く成長できる可能性がある。

**注目すべき点：** 経営者たちは、AIがすでに伝統的産業——アンドリーセンが技術変化に抵抗しやすいと述べたセクターを含む——で生産性向上をもたらしていると述べた。

大規模非営利医療システムProvidence（プロビデンス）のCEO、エリック・ウェクスラー（Erik Wexler）は、患者の診察を文字起こしするAIツールが一部の医師の事務作業時間を1日2～4時間節約していると述べた。ウェクスラーによると、ある医師はこれを「人生を変えるもの」と呼んだという。

**次のステップ：** ワーシュは5つのタスクフォースすべてに対し、年末までにFRBの政策立案を改善する方法を提言するよう求めているが、先月、一部は期限に間に合わない可能性があると警告した。

### 2. リサ・クックがホワイトハウスの審問をスキップへ

**写真：** FRB理事リサ・クック。Photo: David Paul Morris/Bloomberg via Getty Images

FRB理事リサ・クックの弁護士は、彼女の解任を試みる12月14日に予定されたホワイトハウスの公聴会に参加しないと述べた。これは不公正なプロセスであり、結論は既に決まっていると主張している。

**最新動向：** クックの弁護士は、ホワイトハウスのプロセスは依然として彼女に不利なものであり、「クック理事を解任するという事前に決定された決定を覆い隠すために設計された見せかけ」だと主張している、と弁護士のアベ・デイビッド・ローウェル（Abbe David Lowell）は書いている。

最高裁判所が、住宅ローン詐欺の疑惑が調査されている間、クックは職に留まることができるとの判決を下した後、ホワイトハウスは法的正当性をもって彼女を解任しようとするプロセスを確立した。

**彼らの主張：** 「クック理事は不公正な公聴会に参加する法的義務はなく、実際、同機関の独自の地位と独立性を損なうような手続きへの参加を拒否する義務が連邦準備制度に対してある」とローウェルは書いている。

ホワイトハウスは「あなたが主張する『実質的で公正な公聴会』の招集には関心がない」ことを示している、とローウェルは付け加えた。「その代わり、あなたは事前に決定された解任結果のための『正当な理由』を製造しようとしているだけだ。」

**ズームイン：** 特に、彼はホワイトハウス経済顧問ケビン・ハセット（Kevin Hassett）がホワイトハウスによって組織された3人委員会のメンバーであり、クックは辞任すべきだと公に繰り返し述べていると指摘している。また、ホワイトハウスはクックに自己弁護を裏付ける証拠の提出を求めながら、彼女の弁護士に対して既に収集したという証拠への同等のアクセスを与えていないとも述べている。

**反対側の意見：** ホワイトハウスはコメント要請に即座に応答しなかった。

**現実確認：** トランプ大統領がクックの解任に成功したとしても、彼は金利引き下げへの願望を満たしつつ、1月に上院の支配権を握る民主党上院議員にも受け入れられる代替候補を見つけるのに苦労するだろう。

これは、強力な理事会（Board of Governors）に生じるいかなる欠員もかなり長期間空席のままになる可能性を高めている。

## Axios Markets：「ミニバブル」について | 2026年11月18日水曜日

### 1. 重要トピック：Nvidiaのバックストップ効果による反発

執筆：Matt Phillips

Nvidiaの好調な決算、予想を上回るガイダンス、そしてAIエコシステムへの継続的な支援表明が、テック株取引を活気づけています。

**なぜ重要か：** Nvidiaと財務的に結びついた企業群の上昇は、同社の独特な財務取り決めを推進してきた原動力であるHuangの辞任が、市場全体により広範な影響を及ぼしていたことを明らかにしています。

**経緯：** Nvidiaは昨夜、第3四半期の利益と売上高が予想を上回ったと発表し、来期の売上高ガイダンスを引き上げました。Nvidiaは現在、来年の年間売上高が75%増加すると予想しています（以前は70%成長を見込んでいました）。

株価は時間外取引で3%以上上昇し、本日早朝も同水準を維持しており、同社の財務的な影響圏にある企業も急騰しました。

**数字で見ると：** NvidiaのAI業界全体のプレーヤーへの財務的な結びつきと義務は相当なものです。Mizuhoのアナリストは、NvidiaがAIラボ、サプライヤー、ネオクラウドを含む他の事業体に約1,000億ドル相当の潜在的株式持分を持つと推定しています。

**現実的な見方：** これはAIの世界においても実質的な金額です。

**関係者の発言：** Nvidiaの決算後カンファレンスコールで、暫定CEOのColette Kress（コレット・クレス）は、このような財務的な結びつきが切断されることはないと市場を安心させました。

**ただし：** 同時に、同社は毎四半期作成されるCFOコメンタリーに興味深い新しいセクションを追加し、特にネオクラウドに対するそうした支援の限界を定義しました。

「それらすべてが始まり、残念ながら遅延したり、建設に問題が生じた場合、私たちの保証は存在しなくなります」とKressは述べました。

**結論：** これはAIデータセンター建設への公的な反発が高まる中での示唆に富む追加事項です。

「私たちはそれが非常に明確であることを確認したかっただけです」とKressはアナリストに語りました。「それが正確にどのように機能するかについて、いくつか質問を受けていましたので。」

### 2. Goldman Sachsの投資銀行部門グローバル共同責任者が語る「ミニバブル」の所在
