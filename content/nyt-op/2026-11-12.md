 <h3 style="font-size: 18px; font-weight: 700; color: #000; margin: 0 0 10px 0;">トランプ後の共和党：2つの道</h3>
 <p style="font-size: 14px; color: #666; margin: 0 0 15px 0;"><strong>著者：</strong>Oren Cass（オピニオン寄稿者）</p>

 <div style="background-color: #fff; border-left: 4px solid #667eea; padding: 15px; margin-bottom: 15px;">
 <p style="margin: 0; font-size: 15px; color: #333; font-style: italic;">
 「大統領は古い正統性を打ち壊したが、新しい知的基盤も、志を抱かせるビジョンも、持続可能な統治多数派も決して構築しなかった」
 </p>
 </div>

 <p style="font-size: 15px; color: #333; line-height: 1.8; margin: 0;">
 <strong>要旨：</strong>トランプ大統領の退任後、共和党は重大な岐路に立たされている。トランプは従来の保守主義の教義を破壊したが、それに代わる明確なイデオロギー的基盤や長期的な政治的ビジョンを確立することはできなかった。共和党は今、トランプ流のポピュリズムを継承するのか、それとも新しい保守主義の知的枠組みを構築するのか、2つの道から選択を迫られている。
 </p>
 </div>

 <!-- 記事2 -->
 <div style="margin-bottom: 30px; padding: 20px; background-color: #fafafa; border-radius: 6px;">
 <h3 style="font-size: 18px; font-weight: 700; color: #000; margin: 0 0 10px 0;">暖房費高騰の理由</h3>
 <p style="font-size: 14px; color: #666; margin: 0 0 15px 0;"><strong>著者：</strong>Skip York（ライス大学ベーカー研究所エネルギー研究センター フェロー）</p>

 <div style="background-color: #fff; border-left: 4px solid #667eea; padding: 15px; margin-bottom: 15px;">
 <p style="margin: 0; font-size: 15px; color: #333; font-style: italic;">
 「現在の議会が供給を増やすためにできることはもうあまりない。この冬は、より多くの石油を採掘することではなく、既存の石油を効率的に輸送することが重要になる」
 </p>
 </div>

 <p style="font-size: 15px; color: #333; line-height: 1.8; margin: 0;">
 <strong>要旨：</strong>米国の家庭で暖房費が急騰している主な原因は、原油生産量の不足ではなく、物流・輸送インフラのボトルネックにある。現在の議会には新たな供給源を開発する時間的余裕がなく、この冬を乗り切るには既存の石油をいかに効率的に配分・輸送するかが鍵となる。エネルギー政策は短期的な物流改善に焦点を当てるべきだ。
 </p>
 </div>

 <h3 style="font-size: 18px; font-weight: 700; color: #000; margin: 0 0 10px 0;">イスラエルは自国のトランプを追放すべき時</h3>
 <p style="font-size: 14px; color: #666; margin: 0 0 15px 0;"><strong>著者：</strong>Thomas L. Friedman（オピニオンコラムニスト）</p>

 <div style="background-color: #fff; border-left: 4px solid #667eea; padding: 15px; margin-bottom: 15px;">
 <p style="margin: 0; font-size: 15px; color: #333; font-style: italic;">
 「ネタニヤフに叫ばせればいい、『非シオニストのイスラエル系アラブ人に依存する政府を作っている』と。イスラエルの政治的中道派が、ネタニヤフの人種差別に正面から立ち向かう時が来た」
 </p>
 </div>

 <p style="font-size: 15px; color: #333; line-height: 1.8; margin: 0;">
 <strong>要旨：</strong>フリードマン氏は、ベンヤミン・ネタニヤフ首相を「イスラエルのトランプ」と位置づけ、イスラエルの中道政党に対し、アラブ系政党との連立を含むあらゆる手段を使ってネタニヤフ政権を倒すよう促している。ネタニヤフ首相の人種差別的なレトリックや権威主義的傾向に対抗するため、イスラエルの民主主義を守る勇気ある行動が求められている。
 </p>
 </div>
