 <h2 style="font-size: 28px; color: #000; border-left: 6px solid #000; padding-left: 15px; margin-bottom: 30px;">📌 Notable — 注目の論考</h2>

 <!-- Article 1 -->
 <div style="background-color: #fafafa; padding: 25px; margin-bottom: 25px; border-left: 4px solid #4a90e2; border-radius: 4px;">
 <h3 style="font-size: 22px; color: #000; margin: 0 0 10px 0; font-weight: 600;">ブティジェッジとエルサイェドが民主党員に共和党の話し方を教えている</h3>
 <p style="font-size: 14px; color: #666; margin: 0 0 15px 0; font-style: italic;">筆者: Frank Bruni（寄稿オピニオンライター）</p>

 <div style="background-color: #fff; padding: 20px; border-left: 3px solid #4a90e2; margin: 15px 0;">
 <p style="margin: 0; font-size: 16px; line-height: 1.7; color: #333;">
 <strong>要旨:</strong><br>
 「資本主義」という言葉を例に取ろう。左派、特に最近の民主党予備選で勝利した候補者の中には、資本主義を非難し、社会主義者またはそれに近い立場を自認する者がいることで大きな騒ぎになっているが、トランプ大統領とMAGA支持者とは異なる真の資本主義者であると主張する民主党員に対する注目は不十分である。
 </p>
 </div>

 <p style="font-size: 14px; color: #999; margin: 15px 0 0 0;">💡 <strong>示唆:</strong> 民主党内で経済政策の言説が再定義されつつあり、「資本主義対社会主義」という単純な二項対立から、「誰のための資本主義か」という問いへとシフトしている。</p>
 </div>

 <!-- Article 2 -->
 <div style="background-color: #fafafa; padding: 25px; margin-bottom: 25px; border-left: 4px solid #e74c3c; border-radius: 4px;">
 <h3 style="font-size: 22px; color: #000; margin: 0 0 10px 0; font-weight: 600;">シリコンバレーが爆弾と再び恋に落ちている</h3>
 <p style="font-size: 14px; color: #666; margin: 0 0 15px 0; font-style: italic;">筆者: Sharon Weinberger（著書『Valley of Death: How Big Tech Is Fueling the Future of War』の著者）</p>

 <div style="background-color: #fff; padding: 20px; border-left: 3px solid #e74c3c; margin: 15px 0;">
 <p style="margin: 0; font-size: 16px; line-height: 1.7; color: #333;">
 <strong>要旨:</strong><br>
 連邦政府は、本質的には購入代理人である。シリコンバレーの軍事への転換、そしてトランプ氏への転換は、政治的改宗の物語というよりも市場適応の物語である。シリコンバレーの価値観は変わっていない。変わったのは顧客だけだ。
 </p>
 </div>

 <p style="font-size: 14px; color: #999; margin: 15px 0 0 0;">💡 <strong>示唆:</strong> テック企業の軍需産業参入は、イデオロギー的転換ではなく、政府調達という巨大市場への適応。国防テックは今後の主要成長分野となる可能性。</p>
 </div>

 <!-- Article 3 -->
 <div style="background-color: #fafafa; padding: 25px; margin-bottom: 25px; border-left: 4px solid #f39c12; border-radius: 4px;">
 <h3 style="font-size: 22px; color: #000; margin: 0 0 10px 0; font-weight: 600;">キューバの時間は尽きた</h3>
 <p style="font-size: 14px; color: #666; margin: 0 0 15px 0; font-style: italic;">筆者: Michael J. Bustamante（マイアミ大学キューバ・キューバ系アメリカ人研究教授）</p>

 <div style="background-color: #fff; padding: 20px; border-left: 3px solid #f39c12; margin: 15px 0;">
 <p style="margin: 0; font-size: 16px; line-height: 1.7; color: #333;">
 <strong>要旨:</strong><br>
 米国によるキューバの完全占領を真剣に予想する観察者はほとんどいない。しかし、歴史が古い帝国主義的な調べと韻を踏むために、それほど文字通りに繰り返される必要はない。トランプ大統領は、この島の「友好的な買収」を公に示唆している。
 </p>
 </div>

 <p style="font-size: 14px; color: #999; margin: 15px 0 0 0;">💡 <strong>示唆:</strong> カリブ海地域の地政学的緊張が高まる中、キューバ情勢は新たな転換点を迎えている。経済崩壊と政治的不安定性が外部介入の口実となるリスク。</p>
 </div>
 </div>

 <h2 style="font-size: 28px; color: #000; border-left: 6px solid #e74c3c; padding-left: 15px; margin-bottom: 30px;">🔦 Spotlight — 今日の焦点</h2>

 <div style="background: linear-gradient(135deg, #f093fb 0%, #f5576c 100%); color: #fff; padding: 30px; border-radius: 8px;">
 <h3 style="font-size: 24px; margin: 0 0 10px 0; font-weight: 600;">研究所事故から次のパンデミックを防ぐ方法</h3>
 <p style="font-size: 15px; margin: 0 0 15px 0; opacity: 0.95; font-style: italic;">筆者: Hélène Blanc</p>

 <div style="background-color: rgba(255,255,255,0.15); padding: 20px; border-radius: 4px; margin: 15px 0;">
 <p style="margin: 0; font-size: 17px; line-height: 1.8;">
 <strong>要旨:</strong><br>
 新型コロナウイルス感染症の出現から6年以上が経過した今、パンデミックを引き起こす可能性のある危険なウイルス実験を追跡している者は誰もいない。
 </p>
 </div>

 <div style="margin-top: 20px; padding-top: 20px; border-top: 1px solid rgba(255,255,255,0.3);">
 <p style="margin: 0; font-size: 15px; line-height: 1.7;">
 <strong>💡 重要な示唆:</strong><br>
 COVID-19パンデミックの起源に関する議論が続く中、機能獲得実験（gain-of-function research）などの高リスク研究に対する国際的な監視・規制体制が依然として整備されていない。生物学的安全保障（biosecurity）は、気候変動や核拡散と並ぶグローバルリスクとして、より強固なガバナンスフレームワークを必要としている。研究の自由と公衆衛生上のリスク管理のバランスをどう取るかが、今後の重要な政策課題となる。
 </p>
 </div>
