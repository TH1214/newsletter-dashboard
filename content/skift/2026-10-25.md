 <div style="background: #fff3cd; border-left: 5px solid #fd7e14; padding: 25px; border-radius: 4px;">
 <h3 style="margin: 0 0 15px 0; font-size: 18px; color: #856404;">🏨 ホスピタリティ・不動産投資への含意</h3>

 <div style="margin: 20px 0;">
 <p style="margin: 0 0 10px 0; font-weight: 600; color: #856404;">📌 インバウンド需要への影響</p>
 <p style="margin: 0; color: #856404;">Airbnb × Amex提携により、富裕層の短期賃貸利用が加速。ラグジュアリーホテルは高級Airbnb在庫との競争激化に直面。日本のホテル・旅館も、クレジットカードポイント経済圏への対応が急務となる。</p>
 </div>

 <div style="margin: 20px 0;">
 <p style="margin: 0 0 10px 0; font-weight: 600; color: #856404;">🏢 ホテルオペレーター・ブランド動向</p>
 <p style="margin: 0; color: #856404;">Kempinski、Rosewood、Kerznerなど主要ブランドの幹部人事が活発化。特にKempinskiの大量幹部退職は、ラグジュアリーセグメントの戦略転換期を示唆。日本展開を検討するブランドにとって、提携先選定の重要タイミング。</p>
 </div>

 <div style="margin: 20px 0;">
 <p style="margin: 0 0 10px 0; font-weight: 600; color: #856404;">✈️ 航空・アクセス環境の変化</p>
 <p style="margin: 0; color: #856404;">航空会社のロイヤルティプログラム競争が激化（American、oneworld、Air France-KLM）。日系航空会社のマイレージプログラムも、ホテル提携戦略の見直しが必要。</p>
 </div>

 <div style="margin: 20px 0;">
 <p style="margin: 0 0 10px 0; font-weight: 600; color: #856404;">💰 投資・M&A・資本市場への示唆</p>
 <p style="margin: 0; color: #856404;">Airbnbのグロス予約シェア42%（2026年予測）は、短期賃貸アセットクラスの機関投資適格性を裏付け。日本の不動産ファンドも、ホテルREITに加えて短期賃貸適格物件の取得を検討すべき局面。</p>
 </div>

 <div style="margin: 20px 0;">
 <p style="margin: 0 0 10px 0; font-weight: 600; color: #856404;">⚠️ リスク・モニタリング事項</p>
 <p style="margin: 0; color: #856404;">AI旅行プランナーはOTAの認知バイアス（選択肢過多による手数料収益）を持たない — 流通チャネルの破壊的変化が2027年以降加速する可能性。ホテル直販強化とAI対応が生存条件となる。</p>
