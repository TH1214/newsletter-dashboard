### 1. 大きな話題：トランプの「大統領ペイウォール」

データ：Financial Modeling Prep、Binance。チャート：Erin Davis/Axios Visuals

長年、Truth Social はトランプ大統領にとって赤字続きの拡声器だった。しかし今、同氏の企業は、世界の市場を揺さぶりうる（そして実際に頻繁に揺さぶっている）投稿を一瞬早く受け取れるライセンスを、ウォール街の顧客に年間最大120万ドルで販売している——Axios の Dan Primack と Zachary Basu が報じる。

**なぜ重要か**：トランプ氏は2期目を、自身のキャリア全体で最も収益性の高い事業へと転換させ、2025年には一族の暗号資産事業、法的和解、各種ライセンス契約から22億ドル超を稼いだ。このデータ配信の商品名である **Truth API** は、そうした利得追求の論理的な到達点だ。市場を動かす比類なき大統領権力が、サブスクリプションとして商品化され販売されている。

🔎 **詳しく見る**：この商品は、ほぼ即座にその価値を実演してみせた（上のチャート）。

- Truth API のローンチから数時間後、トランプ氏はイランへの大規模な攻撃計画を中止したと発表。市場再開時に原油価格は約5%下落した。
- 3月23日、イランのエネルギーインフラへの攻撃を延期するとの投稿で、ブレント原油は約11%急落した。
- 2025年3月の米国の暗号資産準備に関する発表で、XRP は27%上昇し、世界の暗号資産市場に約3,000億ドルが加わった。
- 昨年10月の中国への大規模な新関税を課すという威嚇で、S&P500 は2.7%下落した。

🔄 **仕組み**：Trump Media & Technology Group（TMTG）のリアルタイム配信は土曜に稼働を開始し、Truth Social の投稿をミリ秒単位で機関投資家の顧客に直接届ける。

- 事情に詳しい関係者が Axios に語ったところでは、同プラットフォームのトレンド上位10アカウントへのアクセスは月額6万〜10万ドル。より幅広いアカウントを求める顧客は追加料金を支払う可能性がある。
- ウォール・ストリート・ジャーナルによれば、少なくとも5社の高頻度取引会社が契約している。Trump Media は、顧客には金融報道機関も含まれるとしている。

💸 **カネの流れ**：Trump Media は上場企業で、トランプ氏が筆頭株主。同氏は、会社の41.5%を保有する撤回可能信託の唯一の受益者だ。信託の唯一の受託者である Donald Trump Jr. が株式を管理している。

- Trump Media の売上高は2026年第1四半期でわずか87万1,000ドル、2025年通年で368万ドルだった。
- 株価は API 発表前日から7%上昇し、トランプ氏の持ち分の評価額に約7,700万ドルを上乗せした。

**行間を読む**：顧客が買っているのは、コンマ数秒の優位性だ。Truth API は取引アルゴリズムに、機械可読の直接配信を提供し、大半の投資家がプッシュ通知を受け取ったり画面を更新したりする前に行動できるようにする。

🥊 **現実チェック**：TMTG は、投稿が API に届く時点ですでに公開されていると主張する。同社が売っているのはレイテンシーの差——公表から広く知れ渡るまでの短い間隔だ。同社は「情報の遅れのコスト」が最も大きい企業に向けて、明示的にこのサービスを売り込んでいる。

TMTG の広報担当者は Axios にこう述べた。「上下両院の民主党議員は、自由市場へのイデオロギー的な反対からか、公開情報と非公開情報の区別を理解できていないためか、Truth API を誤って描写し続けている」

### 2. 🌰 共和党のオハイオ大混乱

イラスト：Aïda Amer/Axios、写真素材：Getty Images

**3. 知事選。** 世論調査では、元共和党大統領候補の Vivek Ramaswamy が民主党の Amy Acton と互角の情勢。アイビーリーグ出身で元バイオテク投資家の Ramaswamy 氏は、ブルーカラー層の支持獲得に苦戦している。

### 3. 🗳️ 衝撃のテキサス世論調査：タラリコがパクストンをリード

写真：先月テキサス州ラレドでの選挙集会で演説する民主党上院候補 James Talarico。撮影：Brandon Bell/Getty Images

3つの世論調査が連続して、テキサス州の重要な上院選で民主党の James Talarico が同州司法長官 Ken Paxton をわずかにリードしていると示した——Axios の Hans Nichols と Marc Caputo が報じる。

- 最新のものは今朝発表されたテキサス・サザン大学の調査で、Talarico が47%対45%でリード。
- この1週間で、Fox News の調査は Talarico が51対48でリード、Texas Public Opinion Research の調査では45対40でリードという結果だった。

**なぜ重要か**：Talarico 氏のリードは誤差の範囲内だ。しかし、共和党主流派がまだ動揺していないとしても、共和党候補にとって不安な兆候がある。

Paxton 陣営の顧問 Nick Maddux は次のように語った。「Talarico の選挙戦は、テキサスでこれまでのすべての民主党候補が行き着いたのとまったく同じ場所——夢物語——に行き着くだろう」

🔬 **詳しく見る**：テキサス・サザン大の調査によれば、人口動態的に Paxton 氏はダブルパンチを受けているように見える。白人有権者（想定される中間選挙有権者の60%）とラテン系有権者（同21%）の双方で大きく振るわない。

- 調査によれば、Paxton 氏の白人有権者でのリードはわずか14ポイントで、テキサスの共和党候補としては低い。出口調査によると、トランプ氏は2年前のテキサスで白人有権者を33ポイント差で制した。
- トランプ氏はヒスパニック系有権者を10ポイント差で制した。テキサス・サザン大の調査では、Talarico 氏が19ポイント差でリードしている。

データ：S&P Capital IQ、Wharton WRDS。チャート：Erin Davis/Axios

## Axios Finish Line：休み時間が復活する

🌄 加えて：ドイツの夕日 | 2026年8月3日（月）

こんにちは、月曜日！今夜は、AxiosのCarly Mallenbaumが休み時間（recess）を擁護する説得力ある議論を展開します。Smart Brevity™ カウント：430語……1分半。編集：Natalie Daher、校閲：Amy Stern。

### 1 big thing：休み時間がカムバック

*イラスト：Sarah Grillo/Axios。素材：Getty Images*

何十年もの間、学校は一日の中から遊びの時間を削り取ってきたが、いま休み時間が再び動き出している、とAxiosのCarly Mallenbaumは書く。

🎒 **なぜ重要か**：休み時間は学習からの中断のように見えるかもしれない。しかし研究者たちは、自由な遊びは子どもたちがより健康に、より落ち着いて、より集中できる状態で教室に戻る助けになると言う。「休み時間はあなたをリフレッシュさせる。休み時間は、いま起きていることに対して少しだけ皮肉な気持ちを和らげてくれる」と、近刊書『Restoring Childhood』の著者で心理学者のPeter Grayは語る。

🧩 **数字で見ると**：ジョンズ・ホプキンス（Johns Hopkins）の研究によれば、12月時点で12州とワシントンD.C.が学校の休み時間を義務づけており、さらに12州が何らかの形での身体活動を義務づけていた。そして最近、学校のある日ごとに40分の休み時間を求めるオクラホマ州の新法が7月に施行された。

🧠 **全体像**：構造化されていない遊びは、子どもが社会的スキルを練習し、ストレスに対処し、学校とのより強いつながりを築く助けになる。研究はまた、休み時間を、より良い行動、出席、教室での意欲、学業成績とも関連づけている。

🤸 **現実チェック**：あらゆる運動が休み時間なわけではない。より広い「身体活動」に関する法律には、放課後のスポーツや体育の授業が含まれ得る。推進派は、子どもにはやり方を指示されずに遊ぶ時間も必要だと言う。「一日でも子どもと過ごしたことがある人なら誰でも分かる。一日中座らせておいたら、子どもはおかしくなってしまうし、周りの皆をおかしくさせるだろう」と、カリフォルニア大学バークレー校（University of California, Berkeley）の身体活動疫学者Hannah Thompsonは語る。

**視野を広げると**：2000年代初頭以降の休み時間の減少は、しばしば2002年の「落ちこぼれ防止法」（No Child Left Behind）に続くテスト重視の時代と結びつけられる。当時、学校は遊びよりも読解と算数により多くの時間を割いた。教育コンサルティング会社EABによれば、米国の学校における週あたりの休み時間は2001年から2019年の間に1時間減少した。

🔔 **だが振り子は戻りつつある**。米国小児科学会（American Academy of Pediatrics）は最近、休み時間に関する推奨を小学校の枠を超えて拡大し、中学生・高校生にも少なくとも20分を求めた。保護者主導の団体Say Yes to Recessは全国的な非営利団体となり、この運動への支持はいまや政治的立場を超えて広がっている。

**結論**：「もっと休み時間を」は、もはや生徒会の選挙公約にとどまらない。それは学校の一日に欠かせない要素になりつつある。
