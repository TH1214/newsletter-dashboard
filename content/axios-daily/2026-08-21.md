### 1 big thing：アメリカの債務爆発

*イラスト：Brendan Lynch/Axios*

アメリカは歴史的な資本の板挟みに陥っている、と Axios の Zachary Basu が書いている。一方には、**過去**の支払いのためにワシントンが借り入れねばならない数兆ドル。もう一方には、**未来**を築くために経済が必要とする数兆ドル。

**なぜ重要か：** 次期大統領は、数十年かけて積み上がってきた財政的な清算を引き継ぐことになる。それが課す代償は——税金、給付、借り入れ、投資に及び——アメリカの繁栄と力を何世代にもわたって形づくりうる。

🔎 **ズームイン：** トランプ大統領は2016年、当時およそ19兆ドルだった国家債務を8年以内に解消できると述べた。火曜日、債務は40兆ドルを突破した。過去1年だけで3兆ドル増えた結果だ。

- うち約32兆ドルは投資家やその他の外部保有者に対する債務。残りは、社会保障やその他の連邦信託基金を含む政府自身の勘定に対して政府が負う債務だ。
- 財務省は今会計年度に満期を迎える9.7兆ドルの債務を借り換えねばならず、同時に議会予算局（CBO）が現在およそ2.1兆ドルと見込む財政赤字も賄わねばならない。
- これが過酷な循環を生む。古い債務が満期を迎え、ワシントンはより高コストの債務でそれを置き換え、結果として生じる利払い費が将来の赤字をさらに膨らませる。
- CBOは、年間赤字が2036年まで平均2.4兆ドルになり、民間保有債務をGDPの120%——第二次世界大戦後に記録した水準を上回る——へ押し上げると予測している。
- 米国は今会計年度の最初の10か月で、すでに9,630億ドルを利払いに費やした。これは同期間の軍事支出を2,000億ドル上回る。

*データ：CBO。チャート：Sara Wise/Axios*

🔭 **ズームアウト：** 長年、シリコンバレーのAI建設投資はほぼ全額が現金で賄われてきた。今やビッグテックは、世界の債券市場における最大級の新たな担い手のひとつになりつつある。

- AIインフラを構築する「ハイパースケーラー」による社債発行は、2026年におよそ倍増するペースにある。
- ゴールドマン・サックスは、来年までにAI建設投資の3分の1超が債務で賄われると予測している。
- Nvidia は BlackRock、ゴールドマン・サックス、KKR ほかウォール街の大手と組み、AIインフラ向けに5,000億ドル超を動員する計画を進めている。

💰 **驚きの数字：** 主要テック企業9社は、過去1年ですでにおよそ6,000億ドルを設備投資プロジェクトに費やした。ウォール・ストリート・ジャーナルの分析によれば、さらに3兆ドルの将来のコミットメント（大半はAI関連）があり、それらはまだバランスシートに反映されていない。

👀 **注目点：** アメリカの財政的選択肢が狭まる一方で、政治的野心は拡大している。

- 左派では民主社会主義と経済ポピュリズムが台頭し、より安価な住宅・医療・保育の約束と、富裕層への増税の要求とを組み合わせている。
- 右派では、トランプ時代の共和党が社会保障とメディケアを政治的に守りつつ、減税と国防費の増額を追求している。トランプが推す1.5兆ドルの国防総省予算もその一環だ。

### 2. 🛢️ 石油市場、トランプを聞き流す

*データ：Roll Call、Financial Modeling Prep。チャート：Erin Davis/Axios Visuals*

イラン戦争についてのトランプ大統領のソーシャルメディア投稿は、石油市場を動かす力を失いつつある、と Axios の Erin Davis と Ben Geman の分析は示す。

**なぜ重要か：** 石油価格の変動は米国と世界の経済全体に波及する——そしてこの紛争は前例のない供給の途絶をもたらしてきた。

⏱️ **数字で見る：** Axios は、2月28日から8月19日までの間に Truth Social に投稿された、イランまたはホルムズ海峡に言及した269件の投稿を追跡した。

- これら Truth Social の投稿が出た後の5分間、または次の市場開始後の5分間における平均変動率（0.73%）は、通常時のほぼ4倍だった。
- その効果は現在弱まりつつある（上のチャート）。

**ズームアウト：** 初期の数週間は「情報の空白」があり、米国の政策と目的についての不確実性が高かった、と石油アナリストの Ben Cahill は述べる。市場はしばしばそれに「過剰反応」した、と彼は言う。

👀 **注目していること：** トランプが石油市場に「口先介入（jawbone）」する力の衰えには政治的な帰結がある。民主党が中間選挙でエネルギー価格を共和党への攻撃材料として使っているからだ。

### 3. 🥊 ワシントンの経済的衝突コース

*写真イラスト：Sarah Grillo/Axios。写真は Getty Images 経由*

トランプ大統領の周辺で最も力を持つ経済当局者2人——FRB議長の Kevin Warsh と財務長官の Scott Bessent——が、互いに逆向きに働く戦略を追求している、と Axios の Courtenay Brown が書いている。

**なぜ重要か：** 2人はワシントンで最も影響力のある経済政策担当者だ。だが投資家は、金融市場における政府の役割について矛盾したシグナルを受け取っている。

🔬 **ズームイン：** Warsh は一歩引いて、経済に対して市場がより自由に反応できる余地を与えたい考えだ。

- 彼は、中央銀行が何をするかについて明示的なガイダンスを減らすという新しい立場をFRB議長として打ち出した——長年のFRBの慣行からの大きな転換だ。
- 先月記者団に語った際、Warsh は長期借入コストが急上昇したにもかかわらず、その取り組みの成果に満足している様子だった。「市場参加者は、審判ではなくボールを見てプレーすることを学びつつある」と彼は述べた。

**もう一方の側：** 今週の債券市場への財務省の介入は、ワシントンが市場主導の変動をどこまで容認するかに限度があることを示している。

- Bessent は昨日CNBCに対し、財務省にはさらに手を打つ余地があると語った。「我々には大きな道具箱がある。だから、様子を見よう」
- 彼はこの動きを、債券市場の混乱は経済の基礎的な条件（ファンダメンタルズ）を反映していないと財務省が考えている、という「シグナル発信」だと位置づけた。

### 4. 🐊 フロリダの民主党候補、「社会主義者」のレッテルを振り払う

*先週フォートローダーデールの集会で演説するフロリダ州の民主党上院候補 Angie Nixon。写真：Dave Decker/ZUMA Press Wire via Reuters*

フロリダ州の民主党上院予備選での衝撃的な番狂わせの直後、州下院議員の Angie Nixon は Axios の Andrew Pantazi と Marc Caputo に対し、自分は本当は社会主義者ではないと語った——アメリカ民主社会主義者（DSA）に加入したばかりであるにもかかわらず。

**なぜ重要か：** Nixon の勝利はDSAの勝利として描かれているが、同組織は彼女を推薦しておらず、勝利を予期してもいなかった。彼女は幅広い連携を志向する左派として選挙戦を戦い、進歩派の運動と党の組織を、ありそうにない同盟として結びつけた。

勝利以降、Nixon は素早くDSAの正統路線から距離を取ってきた。

- 社会主義者かと問われると「いいえ」と彼女は笑った。「私は事業を持っています」（Cafe Resistance という書店だ）
- 「いいえ」、すべての刑務所の廃止は支持しない——営利刑務所についてのみだ。
- 警察の「予算撤廃（defunding）」も、いわゆる「国境開放」も支持しない。
- 「いいえ」、「私は（フィデル・）カストロを称えたりしません」と彼女は述べ、DSA全国組織による物議を醸したキューバの故独裁者の追悼に異を唱えた。
- 「はい」、彼女は進歩派とも穏健派とも一緒に選挙運動をする。元共和党員で現在は民主党の知事候補として出馬している David Jolly も含めてだ。

🖼️ **全体像：** 社会主義は民主党の支持基盤と若年層の間で支持を伸ばしている。だがフロリダでは、本選挙では「毒」と見なされてきた。

- 社会主義を抑圧と暴力に結びつける、南フロリダの規模の大きいキューバ系、ベネズエラ系、コロンビア系、ニカラグア系のコミュニティでは、特に強い反感がある。
- 親イスラエル派のユダヤ系有権者は、パレスチナ人の扱いをめぐるイスラエル批判というDSAの立場ゆえに同組織に反対する傾向がある。Nixon はその立場を掲げており、イスラエルのネタニヤフ首相を戦争犯罪人と呼んでいる。

### 5. 🗳️ 主要選挙区、民主党優位に動く

🗳️ **中間選挙の衝撃：** Cook Political Report は昨日、テキサス州とアイオワ州の上院選をいずれも「共和党やや優勢」から「接戦（トスアップ）」に変更した、と Axios San Antonio の Megan Stringer が書いている。

## Axios PM：がんワクチン治験が有望な結果

（2026年8月20日木曜日／Mike Allen著、編集：Alex Fitzpatrick、633語・2分半で読める分量）

### 1 big thing：がんワクチン治験が有望な結果

Moderna（モデルナ）とMerck（メルク）による新しい個別化mRNA治療が、後期段階の治験で皮膚がんの再発・転移を防いだと、AxiosのTina Reedが報じている。この結果は、トランプ政権の保健当局者が連邦資金を打ち切り、mRNAは利益よりリスクが大きいと主張した後、この技術に垂れ込めていた暗雲を晴らす一助となる可能性がある。

🔬 intismeran（インティスメラン）と呼ばれるこの実験的治療法は、外科的に切除された高リスクのメラノーマ（悪性黒色腫）患者1,100人超を対象に、Merckのがん治療薬Keytruda（キイトルーダ）との併用で試験された。この併用療法は、Keytruda単剤治療に対して「臨床的に意味のある改善」を示した。

🧬 mRNAベースの薬剤は、腫瘍を引き起こす変異を見つけ出すよう免疫系を訓練する。これは、がん細胞を損傷または破壊する化学療法とは対照的である。

Moderna社長のStephen Hoge氏はAxiosにこう語る。「mRNAをワクチンのプラットフォームだと決めつけたり、あるいはもっと誤ったことに、この技術とは何の関係もないパンデミック時代の気に入らなかった事柄と結びつけたりすることから、これが人々を遠ざけることを本当に願っている」

「これによって我々がそこから前に進み始めることを願っている。というのも、これはがん治療における変革的な瞬間だと我々は考えているからだ」

📊 次の展開：治験の完全な結果は、今後開催される医学会議で公表される予定。

### 2. 🇸🇾 シリア外相：イスラエルの爆撃は正当化できない

シリアのAsaad Hassan al-Shaibani（アサド・ハッサン・アル＝シャイバニ）外相は、自国政府はシリアの空軍基地に軍事的プレゼンスを集結させるべくトルコと協働してはいないとイスラエルに明確に伝えていたが、それでもイスラエルはこの拠点を攻撃した——と、AxiosのBarak Ravidに語った。

火曜朝のAbu al-Duhur（アブ・アル＝ドゥフール）空軍基地への攻撃は、トランプ政権がさらなるエスカレーションの阻止を図っているさなかに、この地域における米国の緊密なパートナー3者の間の緊張を高めた。

🇹🇷 al-Shaibani氏はAxiosにこう語る。「そこにトルコの基地を設置する意図も、恒久的なトルコ軍のプレゼンスを構築したり同地にトルコ軍部隊を展開したりする意図もなかった」

トランプ大統領は昨日の電話でAxiosに対し、イスラエルの攻撃について説明を受けたと述べたが、コメントは控えた。「それについては話せない」と同氏は述べた。

💥 イスラエルは、トルコ国境から約45マイル（約72キロ）離れたシリア北部の同基地に、少なくとも8発の爆弾を投下した。攻撃により、最近再建されたばかりの滑走路が損傷した。死傷者はいなかった。

### 4. 🍸 締めの1本：ユニオン駅の華やかな新バー

ワシントンのUnion Station（ユニオン駅）に、洒落た新しいカクテルバーが到着したと、Axios D.C.のAnna Spiegelが報じている。駅のそびえ立つボザール様式のメインホールにある天井の高いカクテルラウンジ「Continental Club」が、本日から年末までオープンする。

🚂 創業者のRochelle Julich氏はAxiosに対し、駅を見下ろす細長い部屋が鉄道車両を思い起こさせ、それがヴィンテージのパーラーカーをモデルにした外観と、「鉄道の黄金時代」を想起させる飲食物の着想源になったと語った。マホガニー、真鍮、青いベルベットを思い浮かべてほしい。背景にはユニオン駅の金箔装飾の建築と歴史あるレジオネア（軍団兵）像がある。

🥃 ドリンクメニューは、Bee's Knees（ビーズ・ニーズ）やManhattan（マンハッタン）といった禁酒法時代の定番をアレンジしたものに加え、キュウリとバジルを使ったCapitol Gimlet（キャピトル・ギムレット）のような現代的な工夫を凝らした一杯も並ぶ。バースナックには、フライドチキンのビスケットバイト、トリュフポップコーン、マスタード・レリッシュ・オニオンを添えた「鉄道スタイル」のホットドッグがある。
