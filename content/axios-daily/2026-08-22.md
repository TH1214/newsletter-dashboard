## Axios AM：スクープ — ロジャース陣営とAIPACの決裂、ミシガン州上院選を揺るがす

Mike Allen 著 · 2026年8月22日

🏎️ 土曜日、こんにちは！Smart Brevity™ カウント：1,751語……6分半。取りまとめを担当した Erica Pandey に感謝。編集は Katie Lewis。

🇨🇦 米国とカナダの通商交渉が昨夜遅くに決裂し、双方とも大幅な新関税が発効すると表明した。米国第2位の貿易相手国との関係における前例のない破綻だと、Axios の Ben Berkowitz と Courtenay Brown が報じている。

🪖 陸軍長官 Dan Driscoll は、国防長官 Pete Hegseth との緊張関係を経て、今後数カ月のうちに民間部門へ移る見通しだと、ウォール・ストリート・ジャーナルがスクープした。

### 1 big thing — スクープ：ロジャースとAIPACの決裂がミシガン州上院選を揺るがす

*Mike Rogers。写真イラスト：Sarah Grillo/Axios。写真：Sarah Rice/Getty Images*

ミシガン州の連邦上院選共和党候補である元下院議員 Mike Rogers の盟友たちが、AIPAC に対し彼のための広告を出さないよう要請し、強力だが世論を二分する親イスラエル団体との決裂を引き起こした、と Axios の Alex Isenstadt が報じる。

ロジャースは先週ロサンゼルスで AIPAC 会長の Michael Tuchin と会談した。その翌日、AIPAC は、ロジャースの民主党側対立候補で歯に衣着せぬイスラエル批判者である Abdul El-Sayed を標的にした、すでに完成していた動画広告をお蔵入りにした。

**なぜ重要か**：この異例の緊張は、ガザでの戦争をめぐる有権者の怒りの中で、AIPAC の政治的立場がいかに低下したかを浮き彫りにしている。断固たる親イスラエル派の共和党員であるロジャースでさえ、同団体の公然たる支援が11月3日の選挙で足かせになりかねないと懸念している。

⚡ **ニュースの背景**：ロジャース陣営の動きは AIPAC 関係者を怒らせた。会話に詳しい関係者によれば、AIPAC は民主党予備選で El-Sayed を落選させようと3,000万ドル超を投じ、さらにロジャースの当選を後押しするために数百万ドルを追加投入する用意をしていた。

**視野を広げると**：El-Sayed は AIPAC を自らの勝利した予備選キャンペーンの中心に据え、同団体が自分に対して支出したことを逆手に取り、民主党の対立候補 Haley Stevens を親イスラエル・ロビーの言いなりだと描き出した。

El-Sayed はイスラエルを「ならず者国家（rogue state）」と呼び、ジェノサイドとアパルトヘイトを行っていると非難し、イスラエルがユダヤ人国家として存在する権利があるかどうかについては明言を避けてきた。そのため彼を倒すことは AIPAC にとって最優先事項となった。同団体が本選挙で大規模な支出キャンペーンを展開することはめったにない。

👀 **舞台裏**：ロジャース陣営は8月4日の民主党予備選の前に、El-Sayed が Stevens を破るとみていると AIPAC に警告していたが、AIPAC は Stevens が勝つことに望みをつないでいた。双方は協議を続けることで合意した。

El-Sayed が僅差で勝利した後、AIPAC はロジャースの盟友たちに、11月3日の本選挙まで広告攻勢を続けたいと伝えた。

しかしロジャース陣営は、AIPAC の予備選広告は El-Sayed に強力な「敵役」を与えてしまい逆効果だったと考えていた——そして彼はそれを再び喜んで利用しようとしていた。「AIPAC、聞いているなら、また戻ってきて燃やしてくれ」と El-Sayed は予備選勝利の前に語っていた。

ロジャースの盟友たちは、団体名を前面に出さずに関与するよう AIPAC に促した、と協議に詳しい関係者は Axios に語った。選択肢の一つは、AIPAC 自身が広告を打つ代わりに、同団体の献金者を親ロジャースのスーパーPAC、あるいはロジャース陣営が全国共和党組織と設立した共同資金調達団体へ誘導することだった。ロジャース陣営はまた、AIPAC の政治戦略家を雇って取り組みを指導してもらうことも提案した。

しかし AIPAC 側は満足しなかった。同団体は El-Sayed を倒す上で目に見える役割を望んでおり、ロジャースが強固な親イスラエル派である以上、いずれにせよ El-Sayed は彼を親イスラエル・ロビー団体と結びつけるだろうと主張した。

🔎 **現状**：ロジャース陣営と AIPAC の直接協議は今や冷え込んでおり、より広範な共和党側の仲裁の動きを促している。双方につながりを持つユダヤ系の共和党献金者が仲介役を務めている、と協議に詳しい関係者は語った。

一部の全国的な共和党関係者は今、AIPAC——そのスーパーPAC は7月末時点で6,000万ドル近くを保有——が本選挙を完全に見送るのではないかと懸念している。

「親イスラエル・コミュニティからのあらゆる支援を歓迎するし、彼らの関与を誇りに思う」とロジャースは Axios に語った。AIPAC の担当者はコメント要請に応じなかった。

### 2. ⛽ 中間選挙 対 市場

*トランプ大統領。写真イラスト：Sarah Grillo/Axios。写真：Alex Grimm/Getty Images*

トランプ大統領は、消費者物価を引き下げようと個別の市場へより深く手を伸ばしている。

**なぜ重要か**：中間選挙を前に「手ごろさ（affordability）」がより大きな政治的弱点となる中、政権は救済策を打ち出す圧力の高まりに直面している、と Axios の Courtenay Brown が書いている。

**その施策**：

🥩 **牛肉**：トランプは昨日、追加の牛肉輸入を最大30万トンまで90日間、一時的に関税免除にすると述べた。この期間は中間選挙まで続くことになる。

💰 **借入コスト**：政権は財務省の債券買い入れや住宅ローン金利の引き下げ策を通じて長期金利を押し下げようとしてきた。今週の当初の緩和は長続きしなかった。

⛽ **ガソリン**：イランでの戦争が原油価格を高騰させる中、トランプはエネルギー企業に給油所価格の引き下げを働きかけてきた。

🛍️ **小売**：ホワイトハウスは大手小売業者に値下げを迫り、Walmart などによる直近の値下げを宣伝している。

**その一方で**：処方薬は明るい材料であり、トランプ政権期とバイデン政権期の政策の組み合わせ、そして市場要因により、価格は過去60年で最も速いペースで下落している。

### 3. ✨ ウォール街のAI盲点

*イラスト：Brendan Lynch/Axios*

データセンターをめぐるビジネスと政治の間の乖離が広がっている、と Axios の Dan Primack が書いている。

**ビジネスは活況**。上場・非上場いずれの株式も右肩上がりで、実際のプロジェクト運営者だけでなく、関連するエネルギーやベンダー関連銘柄も同様だ。

**政治は急速に否定的**になっており、しばしば超党派で。モラトリアムや禁止措置を導入した、または検討している州が増えている。

🪧 **舞台裏**：データセンター投資家はこの反対を嘆き、しばしば是正可能な「地域社会への啓発」の問題として捉えている。また、政治的な反発の多くは中間選挙後に消えていくとみている。

しかしウォール街とシリコンバレーは有権者ではない。「中国にAI競争で勝たせるわけにはいかない」は、大半の一般人にとって、特に電気料金が上がり続けている中では、心に響く主張ではない。

この分野で活動するウォール街の幹部は我々にこう語った。「時間軸の問題がある。……資本は数十年分の需要を引き受けている一方、政治は次の選挙までしか走らない。この二つは時として容易には折り合わない」

### 4. 💃 舞踏場、再開へ

*昨日、新しいホワイトハウス舞踏場の建設現場の上空を飛ぶ、トランプ大統領を乗せたマリーンワン。写真：Julia Demaree Nikhinson/AP*

命令はプロジェクトの適法性には触れておらず、最高裁がいつ判断を示すかの時期も示していない、と Axios の Avery Lotz と Josephine Walker が書いている。

*木曜日、ホワイトハウスのローズガーデンで、里親制度イニシアチブの拡大を発表するイベントに到着するトランプ大統領とメラニア・トランプ大統領夫人。写真：Finn Gomez/Getty Images*

**全体像**：ホワイトハウスは、7月のホワイトハウスでのUFC戦に対するとされる陰謀と、ホワイトハウス記者晩餐会での襲撃事件を、脅威環境が高まっている証拠として挙げ、それが舞踏場とその下にある安全な地下壕の改修の必要性を高めていると主張している。

ホワイトハウス当局者は最高裁に送られた提出書類に、プロジェクトはすでに65%完成しており、地下施設の建設はほぼ完了していると記した。

**視野を広げると**：舞踏場と地下壕の合計費用は少なくとも6億ドルと見込まれており、プロジェクトが最初に発表された時点から4億ドル増加している。

### 5. 🐊 フロリダ州民主党の衝突

*今週、フロリダ州ハランデールビーチの Ebenezer Missionary Baptist Church で選挙運動をする Angie Nixon。写真：Joe Raedle/Getty Images*

フロリダ州の民主党上院選新指名候補 Angie Nixon と同州党の議長が昨日、激しいやり取りを交わし、社会主義の影響やフロリダのような共和党優勢州で選挙戦を戦う難しさをめぐって怒鳴り合いになった、と会話に詳しい3人が Axios の Holly Otterbein、Marc Caputo、Andrew Pantazi に語った。

**なぜ重要か**：この対立は、Nixon が体現する進歩派の支持基盤と、州党議長 Nikki Fried が代表する主流派との間にある党内の断層を露呈させている。

🗳️ **詳しく見ると**：アメリカ民主社会主義者（DSA）のメンバーであり、今週初めに Alex Vindman を破る衝撃的な番狂わせで予備選を制した Nixon は、州党から十分な支援を受けていないと Fried に不満を表明した。

これに対し Fried は、Nixon の DSA とのつながりが共和党に彼女を攻撃する隙を与えかねないと警告した、と情報筋は我々に語った。

Nixon と話した2人によれば、通話中に彼女と Fried は互いに怒鳴り合った。Fried と話した別の人物は、議長は怒鳴っておらず、怒鳴られた側だと述べた。

「Nikki は彼女に DSA から、社会主義から距離を置いてほしいと思っている」と Nixon と話した1人は述べた。「彼女は、怖い、恐ろしいと言う人たち——ユダヤ系メンバーやヒスパニック系議員連盟——の声に耳を傾けている。しかし Angie にしてみれば、Nikki は Angie が Angie らしくあることを望んでいないということだ。Angie はすでに距離を置いてきた」

📞 情報筋によれば、通話の中で Nixon は Fried にこう言った。「あなたは最初から私のことなんて全く気にかけていなかった。それなのに今になって私の選挙戦のやり方を指図するの？」ある時点で Nixon は「私をガスライティングするのはやめて！」と怒鳴った、とその情報筋は語った。

### 6. 💼 CEOたちのAIダンス

*イラスト：Eniola Odetunde/Axios*

コミュニケーション業界の最大のトレンドを扱う週刊ニュースレター Axios Communicators の新しい執筆者、Simon Hernandez-Arthur が書いている。

CEOたちはかつて、AIが何人の労働者を置き換えられるかという数字でAIの進歩と効率性を売り込んでいた。今や経済不安が高まる中、彼らはAIと人員削減を結びつけることにより慎重になっている。

🤖 **具体例**：2024年、Klarna は自社のAIアシスタントがフルタイム担当者700人分の仕事をこなしていると述べた。昨年、Salesforce の CEO Marc Benioff は、AIのおかげでサポート人員を9,000人から約5,000人に減らせたと述べ、「必要な人数が減ったからだ」と語った。

🔎 現在、経営者たちは「AIは働き方を作り変えている」と「AIは労働者を置き換えている」を区別するよう、発言を慎重に言葉選びしている。

Etsy の CEO Kruti Patel Goyal は、今月の220人の人員削減は「AIによって引き起こされたものではない」と述べつつ、この技術が Etsy に必要とされるスキルと能力を変えつつあることは認めた。

Microsoft の最高人事責任者 Amy Coleman は、先月廃止された4,800のポジションは「AIに置き換えられるのではない」と述べる一方で、AIが仕事の進め方を変えていると付け加えた。

## Axios PM：トランプ氏、牛肉の値下げを約束

By Mike Allen · 2026年8月21日

### 1 big thing：トランプ氏、牛肉の値下げを約束

イラスト：Sarah Grillo/Axios

トランプ大統領は本日、牛肉の無関税輸入を一時的に拡大すると述べ、現在の市場価格より25％安く食肉を販売するという確約を取り付けたと明らかにした、とAxiosのNathan Bomeyが報じている。世界的な牛の不足が赤身肉のコストを押し上げ、ハンバーガーやステーキの価格を高くしている。

🤳 トランプ氏はTruth Socialで、「働くアメリカの家庭のために、挽き肉の価格を大幅に引き下げる取引をまとめた」と述べた。さらに「この牛肉が現在の市場価格より25パーセント安く販売されるという確約を得ている」と付け加えた。

「この牛の群れを再建し、牧場主を支援する取り組みを進める間、今後90日間、米国は挽き肉向けの製品について最大30万トンまで、関税割当枠外の関税なしでの輸入を認める」

🤔 現実チェック：トランプ氏は、より安い価格で牛肉を販売するという確約を誰が行ったのかを明示しなかった。ホワイトハウス当局者によれば、確約は外国の牛肉輸出業者からのもので、25％の割引は米国の消費者に還元されるという。

### 4. 🐿️ 1 fun thing：ファット・マーモット・ウィーク

9という名のマーモットが8月6日、コロラド州ゴシックで巣穴の外に座っている。写真：Brittany Peterson/AP

ファット・マーモット・ウィークは、コロラドの山岳高地に生息する毛むくじゃらのジリスの研究に向けて、科学者たちが寄付を募る助けとなっている。「ファット・ベア・ウィーク」をもじったこの企画は月曜日に始まり、連邦資金の削減が研究者らの活動を脅かす中で行われる。

🔬 アスペンの約20マイル南でUCLAの研究者たちが実施している地元のマーモット研究は1962年から継続しており、個体単位の哺乳類研究としては世界で最も長く続いているものの一つとなっている。研究者たちは来夏も活動を続けるため、3年分の資金——20万ドル超——を確保する必要がある。
